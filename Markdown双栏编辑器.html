Markdown 双栏编辑器 · 使用说明

能做什么

  • 即时渲染：左侧输入，右侧按 CommonMark + GFM 子集实时渲染，输入即刷新。
  • 工具栏插入：粗体 / 斜体 / 删除线 / 行内代码 / 标题 / 三种列表 / 引用 / 链接 / 图片 / 表格 / 代码块 / 分隔线，全部走 execCommand 保留 Ctrl+Z 撤销栈。
  • 大纲导航：自动扫描标题生成目录，点击跳转到对应位置。
  • 导出：下载 .md 源文件，或导出内嵌样式、可单独打开的 .html；也可直接打印成 PDF。
  • 自动保存：正文与偏好写入本机 localStorage，关掉浏览器再打开还在。

语法支持范围

块级ATX 与 Setext 标题、围栏代码块（含语言标记）、缩进代码块、引用（可嵌套）、有序 / 无序列表（可嵌套）、任务列表、GFM 表格（含对齐）、分隔线、段落
行内粗体、斜体、粗斜体、删除线、行内代码、链接（含 title）、图片、自动链接（<https://…>）、反斜杠转义、两空格硬换行
不支持脚注、定义列表、数学公式、流程图 / Mermaid、HTML 块级排版、引用式链接 [x][1]

能力边界

  • 不是完整 CommonMark 实现：嵌套强调、列表与代码块的极端交错、惰性续行等边角行为可能和参考实现有差异。日常写作够用，出版级排版请用真正的 Markdown 引擎。
  • 原始 HTML 默认关闭：关闭时所有 < > 都被转义，因此不存在脚本注入。勾选「允许原始 HTML」后，文档里的标签会原样进入预览与导出文件——只对你自己信任的内容开启。
  • 图片用远程地址：本工具不内嵌图片，![](url) 会按地址加载。离线环境下图片不显示属正常。
  • 单文档：不支持多标签页、不支持版本历史。保存靠下载 .md，本机自动保存只留最新一份。

快捷键

  • Ctrl+B 粗体　Ctrl+I 斜体　Ctrl+K 链接
  • Ctrl+N 新建　Ctrl+O 打开　Ctrl+S 保存 .md
  • Ctrl+Shift+S 导出 HTML　Ctrl+Shift+C 复制 HTML　Ctrl+P 打印
  • Ctrl+Enter 循环切换 双栏 / 编辑 / 预览
  • Tab 插入两个空格（选中多行时整体缩进）　Shift+Tab 反缩进
  • Esc 关闭本面板

隐私

零网络请求，无外部 CSS / JS / 字体，file:// 双击即可用。正文与偏好只写进本机 localStorage，不上传任何内容；导出的 HTML 是纯静态文件，不含任何跟踪代码。
