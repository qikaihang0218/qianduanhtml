时间计算台 · 使用说明

四个分区

  • 番茄钟：专注 / 短休 / 长休三段循环，默认 25 / 5 / 15，每 4 轮一次长休。时段结束自动进入下一段，可关。
  • 倒计时：自定义时分秒，到点提示；实时给出「到点时刻」。
  • 时间差：两个时间点之间差多少，拆成天 / 时 / 分 / 秒，并给出总小时、总分钟、工作日数。
  • 日期推算：基准时间加减天 / 周 / 月 / 年 / 小时 / 分钟 / 秒 / 工作日。

计时准确性

  • 所有计时都基于 Date.now() 的时间戳差值，不是靠 setInterval 累加。浏览器把后台标签页的定时器降频到每分钟一次时，累加式计时会越走越慢，本工具不会。
  • 切回标签页时立即重算并刷新显示，不会出现「显示 3 分钟实际已过 5 分钟」。
  • 计时状态只存在内存里，刷新页面即丢。跨页面的持续计时需要浏览器通知权限与 Service Worker，超出单文件工具的范围。

能力边界

  • 提示音是现场合成的：Web Audio 振荡器按音符序列发声，不加载任何音频文件，因此离线可用。浏览器要求首次交互后才能出声，点过「开始」即满足。
  • 不做法定节假日：「工作日」只跳过周六周日，不识别春节 / 国庆与调休。要精确排班请用专门的日历库。
  • 月份加减按自然月：1 月 31 日加 1 个月得到 2 月 28 / 29 日（自动收口到月末），不会溢出成 3 月 3 日。
  • 不处理时区：全部按本机本地时区计算，不做 UTC 转换、不显示其他时区。
  • 不写 localStorage：时长设置与勾选项每次打开都是默认值，避免「上次设成 90 分钟忘了改」。

快捷键

  • Space 开始 / 暂停当前计时
  • R 重置当前计时
  • 1~4 切换分区
  • Esc 关闭本面板

隐私

零网络请求，无外部 CSS / JS / 字体 / 音频，file:// 双击即可用。不读日历、不读定位、不申请任何权限，所有计算只在内存中完成，关掉页面即清空。
