正则测试台 · 使用说明

左侧粘贴文本，顶部输入正则，结果实时刷新。所有匹配与替换都在浏览器本地完成，不发起任何网络请求。

基本用法

  • 正则不要加两侧斜杠，直接写 \d+ 而不是 /\d+/。
  • flags 用工具栏的 gimsuy 开关，默认 g。
  • 「匹配详情」里点任意一行，高亮区会把那一处展开成彩色捕获组。
  • 「替换预览」实时显示 replace 结果，可复制或下载。

快捷键

  • Ctrl+Enter 立即重算（跳过防抖）
  • Ctrl+K 聚焦正则输入框
  • Ctrl+Shift+C 复制替换结果
  • Ctrl+S 下载替换结果
  • Alt+1 / 2 / 3 切换 高亮 / 详情 / 替换
  • Esc 关闭弹出面板

实现细节

  • 若浏览器支持 d flag，工具会自动附加它以获取每个捕获组的精确位置，无需手动打开。
  • 零宽匹配（如 a*）会显示为 ∅ 并自动前进一位，不会死循环。
  • 未开 g 时只匹配第一处，状态栏会提示。
  • 匹配与替换在 Web Worker 里执行，页面不会被卡住。

上限与保护

  • 文本上限 200,000 字符；高亮渲染上限 20,000 字符，超出只渲染前段（替换结果仍是全文）。
  • 匹配数上限 5,000 条；详情表只渲染前 800 行。
  • 灾难性回溯：形如 (a+)+b 的正则遇长串 a 会指数级爆炸。工具在两次匹配之间检查 1.2 秒预算；单个匹配内部无法打断，由 3 秒看门狗强制终止并重建计算线程，页面不会假死。
