图片压缩台 · 使用说明

能做什么

  • 批量压缩：一次拖入几十张，按统一质量重编码，逐行给出压缩率。
  • 格式转换：PNG → WebP / JPEG、JPEG → WebP、任意格式 → PNG（无损保留）。
  • 目标体积：填一个 KB 上限，自动搜索质量；最低质量仍超标时按比例缩尺寸重试。
  • 限制尺寸：按最长边等比缩放，采用逐级减半降采样，避免一步缩放产生走样。
  • 打包下载：结果打成一个 .zip。图片本身已是压缩格式，ZIP 用「存储」模式不二次压缩，打包速度接近瞬时。

能力边界

  • 输出格式取决于浏览器：WebP 编码由浏览器提供，标题栏徽标显示是否可用；不可用时会自动退回 JPEG 并说明。
  • PNG 没有质量参数：canvas.toBlob 对 image/png 忽略质量，PNG 只能靠缩尺寸压。
  • HEIC / HEIF / AVIF 解码看浏览器：解不开会明确报错，不会静默产出空图。
  • 不做抠图与有损调色板量化：不改变像素内容，只做重编码与缩放。
  • GIF 只取首帧：动图重编码后变成静态图。
  • EXIF 方向已自动转正，但 EXIF 元数据不会保留（含 GPS、拍摄时间），重编码后一并丢失。

快捷键

  • Ctrl+O 添加图片　Ctrl+V 粘贴剪贴板图片
  • Ctrl+Enter 开始处理　Esc 停止 / 关闭本面板
  • Ctrl+Shift+C 复制当前结果文件名
  • Ctrl+S 下载当前选中结果　Ctrl+Shift+S 下载 ZIP
  • ↑ / ↓ 在列表中上下选择　1~4 切换右侧视图

隐私

零网络请求，无外部 CSS / JS / 字体，图片只在浏览器内存中处理，file:// 双击即可用。只有输出参数会写进 localStorage，图片字节一律不留存，关页面即清空全部图片。
