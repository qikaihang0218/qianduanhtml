File Diff · 说明

怎么用

  • 把两个文件分别拖到左右两侧，或点 ✎ 编辑 后粘贴文本，内容一变就自动重算。
  • 点击某一行即可选中它所属的差异块，此时「← 采用右侧 / 采用右侧 →」可把整块内容写到另一侧。
  • 折叠条「⋯ N 行相同」点击可就地展开。

快捷键

  • Alt+↓ / Alt+↑　下一处 / 上一处差异
  • Ctrl+Enter　立即重新对比
  • Ctrl+Shift+C　复制统一差异报告
  • Ctrl+S　下载 .diff
  • Esc　退出编辑屏 / 关闭弹层

容量上限

  • 单侧最大 2 MB；两侧总行数超过 20000 行时改用快速对齐。
  • 编辑距离超过 1500 时降级为快速对齐，状态栏会标注「快速对齐」。
  • 单次最多渲染 3000 行，超出时复制 / 下载仍可获得完整报告。

隐私

  • 无 fetch / 无外部资源 / 不写 localStorage，断网与 file:// 双击均可用。
  • 内容只存在于当前页面内存，刷新即清空。
