# qianduanhtml · 前端 HTML 工具集

一个**纯前端、零依赖、单文件**的 HTML 工具合集。每个页面都是独立的 `.html` 单文件，全部在浏览器本地运行，无需构建、无需后端、数据不上传，双击即可使用。

## ✨ 特性

- 🚀 **即开即用**：浏览器直接打开，或部署到任意静态托管即可
- 🔒 **本地运行**：所有处理均在浏览器端完成，隐私安全
- 📦 **单文件架构**：无构建步骤、无第三方运行时依赖，便于携带与分发
- 📱 **响应式适配**：桌面与移动端均有良好体验

## 📚 工具清单

| 文件 | 类型 | 功能简介 |
| ---- | ---- | ---- |
| `全能格式化工具箱.html` | 格式化工具 | 嵌套 JSON 增强版：JSON / XML 等格式化、校验、压缩 |
| `全能格式化工具箱url.html` | 格式化工具 | cURL 批量智能拆分版：批量导入、拆分与整理 cURL 命令 |
| `DeepSeek-颜色选择器HTML代码.html` | 设计辅助 | 颜色 & 渐变选择器：自定义色标、实时预览与复制 |
| `离子选择器.html` | 特效工作台 | Neon Particle Studio Pro：多风格粒子特效，支持实时调参、文字/图片粒子化、场景导入导出 |
| `千问代码_专属二维码工坊.html` | 生成器 | 高级二维码生成器：自定义样式与参数生成二维码 |
| `储物间导航.html` | 导航页 | 森系储物间导航：个人收藏与常用链接聚合入口 |

## 🚀 快速开始

**方式一：直接打开**

双击任意 HTML 文件，在浏览器中打开即可。

**方式二：本地启动服务**

```bash
# Python 方式
python -m http.server 8080

# 或 Node 方式
npx serve .
```

**方式三：静态托管部署**

将本目录内容上传到 GitHub Pages、Vercel、Netlify 等任意静态平台即可。

## 🛠️ 技术说明

- 纯 HTML / CSS / JavaScript 实现，无第三方运行时依赖
- 个别页面通过 `<link>` 引入 Google Fonts 字体（需联网），其余功能完全离线可用
- 采用响应式布局与现代化视觉风格（渐变、毛玻璃、粒子效果等）
