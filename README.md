# qianduanhtml · 前端 HTML 工具集

一个**纯前端、零依赖**的 HTML 工具合集。每个页面都是独立的 `.html` 文件（仅 `汉字转拼音` 额外带一个词典 JS），全部在浏览器本地运行，无需构建、无需后端、数据不上传，双击即可使用。

## ✨ 特性

- 🚀 **即开即用**：浏览器直接打开，或部署到任意静态托管即可
- 🔒 **本地运行**：所有处理均在浏览器端完成，隐私安全
- 📦 **单文件架构**：无构建步骤、无第三方运行时依赖，便于携带与分发
- 📱 **响应式适配**：桌面与移动端均有良好体验

## 🚀 快速开始

**方式一：直接打开**

双击任意 HTML 文件，在浏览器中打开即可。

**方式二：本地启动服务**

```bash
# Python 方式
python -m http.server 8080

# 或 Node 方式
npx serve .
```

**方式三：静态托管部署**

将本目录内容上传到 GitHub Pages、Vercel、Netlify 等任意静态平台即可。

## 📝 更新日志

### 时间计算台.html

**v1**

- ⏱ **四个分区共用一套时间内核**：番茄钟 / 倒计时 / 时间差 / 日期推算集中在同一页面，标签页切换（`1`~`4`），共用同一套格式化与差值函数，不再需要桌面右下角堆两个窗口
- 🎯 **计时靠时间戳差值，不靠累加**：每次 tick 算 `endAt - Date.now()`，`endAt` 在启动那一刻固定为绝对时间戳。浏览器把后台标签页的 `setInterval` 降频到每分钟一次时，`left -= 1` 式计时会越走越慢，本工具不会；`visibilitychange` 里切回页面立即重算刷新，不出现「显示还剩 3 分钟、实际已超时」
- 🍅 **番茄钟三段循环**：专注 / 短休 / 长休默认 25 / 5 / 15 分钟，每 N 轮（默认 4，可设 2~12）一次长休。SVG 进度环**专注琥珀 `#ffc861`、休息绿色 `#57c26b`**，颜色本身即阶段指示；轮次点在休息段保持已完成轮次实心，不会全变空看不出进度。改时长不打断正在跑的计时，点「重置」才按新值重来
- ⏲ **倒计时**：时 0–99 / 分 0–59 / 秒 0–59，5 个预设（1/3/5/10/30 分钟），实时给出「到点时刻」；全 0 时报错「倒计时时长不能为 0」而非静默不动
- ↔️ **时间差**：两个时间点拆成天 / 时 / 分 / 秒，附总天数、总小时、总分钟、总秒数、总毫秒、**工作日数**、周数；「结束早于开始」不静默取绝对值，错误条明确说明并统一用 U+2212 负号（工作日与周数也带负号，不出现 ASCII 减号混排）
- 📅 **日期推算**：加减天 / 周 / 月 / 年 / 小时 / 分钟 / 秒 / 工作日，结果附 ISO 8601、当年第几天、是否闰年、当月起止、**ISO 8601 周号**。月份加减**按自然月收口**：1 月 31 日 + 1 月 = 2 月 28 日（闰年 2 月 29 日），不溢出成 3 月 3 日
- 🔔 **提示音现场合成**：Web Audio 振荡器按音符序列发声（专注结束上行三音、休息结束下行两音、倒计时到点单音三连），**不加载任何音频文件**，断网可用。每个音符 8 ms 淡入 + 指数衰减包络，不爆音
- 🏷 **标题栏倒计时**：浏览器标签页标题被剩余时间接管，**不要求当前停在计时分区**（价值就在于切走也能看见）；两个计时同时在跑时优先显示当前分区那一个
- ⌨️ 快捷键：`Space` 开始 / 暂停、`R` 重置、`1`~`4` 切分区、`Esc` 关帮助、`Enter` 在日期推算数字框内立即计算。**焦点在输入框内时快捷键全部让位**，避免在「分」输入框里敲空格误启动
- 🔒 **零网络请求**：无外部 CSS/JS/字体/音频，全文无 `fetch`；**不写 `localStorage`**（刻意的：避免「上次设成 90 分钟忘了改」），计时状态只在内存，刷新即重置
- ⚠️ **不识别法定节假日与调休**：「工作日」只跳过周六周日；**不做时区换算**，全部按本机本地时区；不保留跨刷新计时状态（需 Service Worker + 通知权限，超出单文件范围）；不做专注历史统计

### Markdown双栏编辑器.html

**v1**

- ✍️ **双栏实时渲染**：左侧输入，右侧 90 ms 防抖后刷新，标题栏徽标显示本次渲染耗时（示例文档 0.7 ms，9.5 万字 64 ms）。支持 ATX / Setext 标题、围栏与缩进代码块、可嵌套引用、三种列表、任务列表、GFM 表格（含 `:` 对齐）、分隔线
- 🧩 **行内解析走占位符**：所有产出 HTML 的结构先摘成 `\u0001n\u0001` 占位，剩余文本统一 `esc()` 后再还原，因此 `**粗**` 不会退化成字面标签、`<script>` 也不会被当标签执行。强调支持三层嵌套，`~~**粗删**~~` 正确得到 `<del><strong>粗删</strong></del>`，`snake_case_word` 不误判斜体
- ↩️ **工具栏不毁撤销栈**：所有插入走 `document.execCommand('insertText')`，每步工具栏操作都能 `Ctrl+Z` 撤回；直接改 `textarea.value` 会清空撤销历史，这是分水岭
- ⌨️ **列表语义化输入**：列表项末回车自动续 `- ` / `2. ` / `- [ ] `，空列表项回车**退出列表**；`Tab` 单行插两空格、多行整体缩进，`Shift+Tab` 反缩进
- 🧭 **大纲与编号**：扫描 `h1`~`h6` 生成目录，点击平滑滚动并高亮目标；标题自动编号 `1` / `1.1` / `1.2.1`，大纲同步显示编号
- 🎨 **预览与导出同源**：`cssRules(scope, palette)` 一份规则，预览套 `#mdRoot[data-theme]`、导出套 `.md`，所见即所得；暗 / 亮主题各一套调色板
- 📤 **四种出口**：下载 `.md`（带 UTF-8 BOM）、导出内嵌样式的独立 `.html`、复制完整 HTML 到剪贴板（`clipboard` 不可用时降级 `execCommand`）、打印成 PDF（打印样式已隐藏全部工具栏并强制白底）
- 📊 **字数与阅读时长**：中日韩字符 + 拉丁词计数，字符 / 行 / 段并列显示，按中文 400 字/分、英文 200 词/分估算阅读时长
- 🔄 **滚动同步**：按滚动比例双向联动，`syncing` 标志 + 40 ms 定时器防抖动
- 💾 **自动保存**：正文写 `mdstudio.doc.v1`（停止输入 500 ms 后），偏好写 `mdstudio.prefs.v1`；正文上限 2 MB，配额超限时状态栏红字报「保存失败（超出本机配额）」而不假装成功
- ⌨️ 快捷键：`Ctrl+N` 新建、`Ctrl+O` 打开、`Ctrl+S` 保存、`Ctrl+Shift+S` 导出 HTML、`Ctrl+Shift+C` 复制 HTML、`Ctrl+P` 打印、`Ctrl+B` / `Ctrl+I` / `Ctrl+K` / `` Ctrl+` `` 格式、`Ctrl+Enter` 循环切视图、`Tab` 缩进、`Esc` 关面板
- 🔒 **零网络请求**：无外部 CSS/JS/字体，全文无 `fetch`；可拖入 `.md` 文件打开，也支持 `file://` 双击直用。**原始 HTML 默认关闭**，关闭时 `<` `>` 全部转义，无脚本注入面；开启后标签原样进入预览与导出文件，界面上有明确提示
- ⚠️ **不是完整 CommonMark**：脚注、定义列表、数学公式、Mermaid / 流程图、引用式链接 `[x][1]` 均不支持；惰性续行、表格内换行等边角行为与参考实现有差异；单文档，无多标签与版本历史

### 图片压缩台.html

**v1**

- 🗜 **批量压缩**：拖入 / 选择 / `Ctrl+V` 粘贴三种入口，单次上限 200 张、单文件 50 MB，默认 3 张并发；逐张增量刷新，实时给出新尺寸、新大小与压缩率（变大如实标红，不粉饰）
- 🔁 **格式互转**：输出 JPEG / PNG / WebP / 保持原格式；「保持原格式」按原始类型 + 是否含透明像素决策，显式选 WebP 而浏览器不能编码时**自动退回 JPEG 并在说明里写明**，标题栏徽标实时显示 WebP 编码能力（实际调用 `toDataURL` 探测，不猜 UA）
- 🎯 **目标体积**：填一个 KB 上限即接管质量滑块，用**已探测点插值引导**搜索质量（非纯二分），命中即收手；最低质量仍超标则按 `(目标/实际)^0.75` 比例缩尺寸重试最多 3 轮，最终仍不够时**明确报告「已缩到 W×H，仍超过目标 X KB」**而非静默交超标文件。1.11 MB 噪声图压到 60 KB 实测 11.0 s（纯二分需 14.3 s）
- 📐 **高质量缩放**：限制尺寸按最长边等比缩放且只缩不放；缩放走**逐级减半降采样**再精修，2400×1600 → 640×427 这类大幅缩减不出现一步缩放的锯齿与摩尔纹
- 🔍 **透明通道实测**：`hasAlpha()` 采样 200×200 判断是否真有透明像素，不按扩展名 / MIME 猜；转 JPEG 时用自选底色填充，透明区与不透明区像素级验证正确
- 📦 **ZIP 打包**：自写 ZIP（本地头 + 中央目录 + EOCD + 查表 CRC-32），图片本身已压缩故用 `method=0` 存储模式不二次压缩，打包接近瞬时；同名输出自动 `xxx-opt(2).jpg`；6 条目 629 KB 解包逐条 CRC 校验通过
- 🧭 **停止与重试**：`Esc` / 停止按钮在当前张完成后收尾，已完成结果保留；失败项计入待处理可直接重跑
- 🧠 **资源释放**：`ImageBitmap.close()` + `revokeObjectURL` 在成功与失败两条路径上都执行，批量大图不会把解码内存吃满
- ⌨️ 快捷键：`Ctrl+O` 添加、`Ctrl+Enter` 处理、`Ctrl+S` 下载当前、`Ctrl+Shift+S` 下载 ZIP、`Ctrl+Shift+C` 复制结果文件名、`Ctrl+Backspace` 清空、`↑↓` 选择、`1~4` 切视图、`Esc` 停止
- 🔒 **零网络请求**：无外部 CSS/JS/字体，全文无 `fetch`；图片只存在于内存，仅输出参数写入 `localStorage` 的 `imgopt.prefs.v1`（不含图片数据与文件名）
- ⚠️ **不保留 EXIF**：重编码后元数据（含 GPS、拍摄时间）全部丢失，方向已自动转正；PNG 无质量参数（`toBlob` 忽略 quality），只能靠缩尺寸压；HEIC / HEIF 能否解码看浏览器；GIF 只取首帧

### 编码转换台.html

**v1**

- 🔁 **编码类 7 种模式**：Base64（可 76 字符换行）、Base64URL（可去/补 `=`）、URL 百分号编码（`encodeURIComponent` / `encodeURI` / 全字节三种口径）、Hex（5 种分隔符 + 大小写）、`\uXXXX` 转义、HTML 实体、字节解码；前 6 种支持编码 ⇄ 解码双向切换
- 🧬 **字节解码定位乱码**：同一份字节用 UTF-8 / GB18030 / GBK / Big5 / Shift_JIS / EUC-KR / UTF-16LE / BE / Windows-1252 / ISO-8859-1 各解一遍，按「U+FFFD×4 + 控制符数」打分排序并标出推荐，状态栏直接给结论
- #️⃣ **摘要与签名**：MD5 为页面内置纯 JS 实现（`crypto.subtle` 不支持 MD5），SHA-1/256/384/512 与 HMAC 走 Web Crypto；输出可选 Hex / Base64 / Base64URL，字节来源可选 UTF-8 文本 / Hex / Base64（用于校验二进制文件哈希）
- 🔑 **JWT 本地解析与验签**：`Bearer ` 前缀自动清理，`exp` / `nbf` / `iat` 转成「已过期 3228.3 天」式人性化时间；HMAC 系列用密钥**重算**签名并做定长比较，`alg=none` 直接判为可伪造，RS/ES 系列明确标注只解析不验签
- 🛡 **宽容但不装懂**：Base64 忽略非法字符、容忍缺失填充、尾部不足一字节按 RFC 4648 丢弃；URL 逐段尽力解码保留残缺 `%`；实体落在代理区按 HTML 规范转 U+FFFD——所有有损处理都在结果区上方报出数量与具体字符
- 🎲 **随机串 / UUID v4**：`crypto.getRandomValues` + 拒绝采样消除取模偏置，可选字符池与易混淆字符排除，强制包含已勾选的字符类别；输出可选每行一个 / JSON 数组 / JS 字面量
- 🧭 **能力检测徽标**：标题栏实时显示 `WebCrypto` / `GBK 解码` / `MD5` 三项可用性，环境不支持时明确报错而非静默失败
- 📥 输入上限 20 万字符、字节上限 4 MB；结果超过 30 万字符仅框内截断显示，**复制与下载始终完整**；下载文件名含模式与时间戳并带 UTF-8 BOM
- ⌨️ 快捷键：`空格` 切方向、`Alt+1/2/3/4` 切大类、`Ctrl+Enter` 立即重算、`Ctrl+Shift+C` 复制、`Ctrl+S` 下载、`Ctrl+K` 聚焦输入、`Esc` 关帮助
- 🔒 **零网络请求**：无外部 CSS/JS/字体，全文无 `fetch`；偏好、选项与不超过 5 万字符的输入写入 `localStorage` 的 `codeclab.prefs.v1`（**含 HMAC / JWT 密钥明文**，公共电脑需手动清除）
- ⚠️ **不支持文本 → GBK 编码**：浏览器 `TextEncoder` 只实现 UTF-8，GBK / Big5 等只能解码不能编码
