# qianduanhtml · 前端 HTML 工具集

一个**纯前端、零依赖**的 HTML 工具合集。每个页面都是独立的 `.html` 文件（仅 `汉字转拼音` 额外带一个词典 JS），全部在浏览器本地运行，无需构建、无需后端、数据不上传，双击即可使用。

## ✨ 特性

- 🚀 **即开即用**：浏览器直接打开，或部署到任意静态托管即可
- 🔒 **本地运行**：所有处理均在浏览器端完成，隐私安全
- 📦 **单文件架构**：无构建步骤、无第三方运行时依赖，便于携带与分发
- 📱 **响应式适配**：桌面与移动端均有良好体验

## 🚀 快速开始

**方式一：直接打开**

双击任意 HTML 文件，在浏览器中打开即可。

**方式二：本地启动服务**

```bash
# Python 方式
python -m http.server 8080

# 或 Node 方式
npx serve .
```

**方式三：静态托管部署**

将本目录内容上传到 GitHub Pages、Vercel、Netlify 等任意静态平台即可。

## 📝 更新日志

### 汉字转拼音/汉字转拼音.html

**v1**

- 🔤 **四种注音样式**：带音调 `zhōng`、数字调 `zhong1`（轻声记 5）、无声调 `zhong`、首字母 `z`
- 🧩 **四种排版视图**：注音排版（`<ruby>` 上下对照）、逐格对照、逐字内联 `银(yín)`、纯拼音
- 🎯 **词组优先消歧多音字**：853 条多音词组做最长匹配，`银行行长` → `yínháng xíng cháng`、`重庆` → `chóngqìng`、`重量` → `zhòng`
- 🖱️ **多音字点击改读**：带黄色虚线的字点一下换下一个读音，按字记忆并持久化；`Alt`+`↑`/`↓` 逐个跳转
- 📏 **正词法连写**：同词组音节连写、词组间空格，符合《汉语拼音正词法基本规则》；`ü` 统一写作 `v` 便于做文件名与 URL
- 📥 **多种输入**：粘贴 / 键入 / 拖入 `.txt`（上限 4 MB），输入上限 20 万字，超 8000 字预览降级而导出仍为全文
- 📤 **多种输出**：复制纯文本、复制 `<ruby>` HTML、下载带 BOM 的 `.txt`；Web Speech 朗读纯汉字
- 🔒 **零网络请求**：词典随仓库分发；45,000 字转换实测 25.9 ms
- ⚠️ **本仓库唯一的多文件工具**：需与同目录 `拼音词典.js`（306 KB，源自 `pinyin-data@1.0.0` · ISC）一起拷贝

### 音乐播放器.html

**v1**

- 🎵 **无损格式解析**：直接读取文件头，不依赖后端
  - FLAC：STREAMINFO 取采样率/位深/声道/总采样数，VORBIS_COMMENT 取标题/艺术家/专辑，PICTURE 内联封面
  - WAV：RIFF/WAVE 遍历 `fmt ` 与 `data` 块，支持 PCM / Float / Extensible
  - AIFF：FORM/AIFF 读 COMM 块，80 位扩展精度浮点采样率
  - ALAC / M4A：MP4 `ftyp` 判定，`stsd` 取声道数、位深与 16.16 采样率，`mvhd` 取时长
  - MP3 / OGG / OPUS：ID3v2.3/2.4 标签与 APIC 封面，Ogg 页头识别 Vorbis / Opus / FLAC
  - 无法原生解码的 APE / WV / DSD / WMA 会标记并提示转码
- 📂 **多种导入方式**：点选文件、选择文件夹、拖拽文件或整个目录（递归遍历子目录）
- 📊 **波形进度条**：解码整曲生成 360 段峰值波形，已播放部分渐变高亮，可点击或拖动定位
- 🌈 **实时可视化**：频谱柱 / 示波器 / 对称频谱三种模式，对数分频 + 帧归一化，弱信号也有完整画面
- 🎚 **10 段均衡器**：32Hz~16kHz 峰值滤波，8 组预设（平坦/流行/摇滚/爵士/古典/人声/低音增强/高音增强），可手动微调
- 🎤 **LRC 歌词**：解析时间轴、逐行高亮、自动居中滚动、点击跳转，支持导入 `.lrc`
- 🖼️ **封面与元数据**：优先使用内嵌封面，无封面时显示唱片动画；展示格式、位深、采样率、声道、码率、文件大小
- 🔁 **四种播放模式**：顺序播放 / 列表循环 / 单曲循环 / 随机播放
- 🎨 **四套主题色**：青碧 / 紫霞 / 琥珀 / 海蓝，记忆到 localStorage
- ⌨️ 快捷键：空格播放暂停、←/→ 快退快进 5 秒、↑/↓ 音量、M 静音、N/P 上下曲、L 歌词、V 可视化、E 均衡器、Esc 关闭面板
- 📱 响应式布局，移动端侧栏抽屉化；支持 Media Session 系统媒体键控制

### 阅读器.html

**v1**

- 📚 **本地书架**：书籍解析后存入 IndexedDB，刷新不丢，卡片展示格式、作者与阅读进度，可单本删除
- 📥 **三种格式导入**：拖拽或点选 `.epub` / `.mobi` `.azw` `.azw3` `.prc` / `.txt` `.html`
  - EPUB：自实现 ZIP 解包（`DecompressionStream` 原生解 deflate），读 OPF spine 顺序、NCX/NAV 双目录源，图片内联为 dataURL，非 UTF-8 文件名按 GBK 兜底
  - MOBI：PalmDOC 解压、PDB 记录表、EXTH 元数据（书名/作者），DRM 与 HUFF/CDIC 给出明确提示
  - TXT：按「第X章 / Chapter N / 序言 / 楔子 / 尾声」等标题自动分章
- 📑 **目录侧栏**：章节列表 + 当前章节自动高亮，点击直达
- 📖 **滚动 / 翻页双模式**：翻页采用 CSS 多列分栏 + 位移，支持点击左右热区、滚轮、方向键、左右滑动
- ⏱ **自动翻页**：一键开启自动翻页/滚动，速度 1~10 档（约 20 秒 ~ 1.2 秒每屏），按钮底部进度条显示下一屏倒计时；手动滚轮、滑动、点击热区会自动暂停；到文末自动停止
- ✎ **粘贴文本建书**：书架上点「粘贴文本」，直接粘贴任意文字即可存为一本书，支持从剪贴板一键读取；书名可留空自动取首行，正文按章节标题自动分章
- 🔤 **排版调节**：字号 14~34px、行距 1.4~2.4、页宽 520~1100px，设置本地记忆
- 🎨 **四套主题**：纸白 / 米黄 / 护眼 / 夜间，一键轮换
- 🔊 **朗读跟读**：Web Speech 逐段朗读并从当前可视位置起读，当前段高亮
- 🖥️ 全屏沉浸、进度条与百分比、页脚时钟、内部锚点链接跳转
- ⌨️ 快捷键：翻页模式下 ←/→/空格/PageUp/PageDown 翻页，A 开关自动翻页，Esc 关闭目录并停止朗读/自动翻页
