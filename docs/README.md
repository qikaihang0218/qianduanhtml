# 操作文档索引

> 本目录是 `qianduanhtml` 前端工具集的**操作文档**集合，与仓库根目录的 [README.md](../README.md) 互补：
> 根 README 提供工具清单与版本更新日志，本目录提供**逐个工具的操作手册与开发者改造指南**。

## 通用约定

- **即开即用**：所有工具均为纯前端 HTML，双击即可在浏览器打开，无需构建、无需安装依赖。绝大多数是单文件，唯一例外是 [汉字转拼音](./汉字转拼音.md)（HTML + 同目录词典 JS）。
- **数据本地处理**：默认所有解析、转换、渲染都在浏览器内完成，文件内容不上传到任何服务器。唯一例外见各篇文档的「数据与隐私」章节。
- **浏览器要求**：推荐使用较新版本的 Chromium 内核浏览器（Chrome / Edge）或 Firefox。部分高级能力依赖较新内核：
  - `DecompressionStream`（阅读器解 EPUB ZIP 包）——需 Chromium 80+ / Firefox 113+
  - `crypto.subtle`（数字签名、编码转换台的 SHA / HMAC / JWT 验签）——需安全上下文。Chrome / Edge 把 `file://` 视为安全上下文，实测双击直开可用；若某浏览器判定为不安全，编码转换台会在标题栏徽标实时标出「WebCrypto 不可用」，此时 MD5 与全部编码功能仍正常，仅 SHA / HMAC / JWT 验签不可用
  - `TextDecoder('gbk' / 'gb18030' / 'big5' / 'shift_jis' / 'euc-kr')`（编码转换台的字节解码）——Chromium 与 Firefox 均支持；不支持的编码在该模式表格里显示为一行「浏览器不支持该编码」，不影响其余候选
  - `crypto.randomUUID`（编码转换台的 UUID v4）——缺失时自动退回 `crypto.getRandomValues` 手工构造
  - `speechSynthesis`（朗读类工具）——依赖操作系统已安装的语音包
  - `Worker` + `URL.createObjectURL`（正则测试台的防卡死计算）——`file://` 下实测可用；不可用时工具自动退回主线程同步计算
  - `canvas.toBlob` + `createImageBitmap` + `Image` + `FileReader`（图片压缩台的解码与编码）——`canvas.toBlob` 是**唯一硬依赖**，缺失则无法输出任何图片。`createImageBitmap` 缺失时自动改用 `<img>` 解码；**WebP 能否输出由浏览器决定**，图片压缩台会在标题栏实时标出「WebP 编码 不可用」，此时选 WebP 自动退回 JPEG 而非报错
  - `RegExp` 的 `d` flag / `hasIndices`（正则测试台的捕获组定位）——缺失时仅退化为「拿不到组独立位置」，功能不中断
  - `document.execCommand('insertText')`（Markdown 双栏编辑器的工具栏插入）——**唯一目的**是保留 `Ctrl+Z` 撤销栈，直接改 `textarea.value` 会清空撤销历史。该命令已废弃但 Chromium / Firefox 仍完整支持；不可用时自动降级为直接赋值，插入功能不中断，仅撤销栈丢失
  - `navigator.clipboard.writeText`（Markdown 双栏编辑器的「复制 HTML」）——`file://` 下部分浏览器不提供，缺失时自动降级到隐藏 `textarea` + `execCommand('copy')`，仍失败则提示改用「导出 HTML」
  - `AudioContext`（时间计算台的到点提示音）——用振荡器现场合成音符，**不加载任何音频文件**。缺失时到点仍会弹 toast 与写状态栏，仅没有声音；浏览器要求首次用户交互后才能出声，点过「开始」即满足
- **配置持久化**：多数工具把偏好写入浏览器 `localStorage`，书架等大数据写入 `IndexedDB`。**清除浏览器站点数据会导致配置与书架丢失**，各篇文档的「数据与隐私」章节列出了确切键名与清除方法。

## 文档结构约定

本目录所有工具文档遵循**统一的 10 个一级章节**，顺序固定。若某工具确实没有某类内容，章节标题保留并写明占位说明，不删除章节。该约定同时是本目录的**校验基准**：新增文档时必须逐章对照。

| 序号 | 章节名 | 这一章回答什么问题 |
| ---- | ---- | ---- |
| 1 | `工具简介` | 它是什么、适合谁用、什么场景不该用它 |
| 2 | `快速开始` | 最短可用路径：从打开到看到第一个结果 |
| 3 | `界面与功能分区` | 屏幕上每一块是什么，每个控件的作用与取值范围 |
| 4 | `功能操作详解` | 每个主要功能的具体操作步骤（编号流程） |
| 5 | `快捷键一览` | 有哪些键盘快捷操作，以及各自的生效条件 |
| 6 | `支持的输入 / 输出格式` | 能吃哪些格式、能吐出什么、哪些明确不支持 |
| 7 | `数据与隐私` | 是否联网、数据存在哪里、怎么清掉 |
| 8 | `常见问题（FAQ）` | 出错了怎么自助排查 |
| 9 | `技术实现要点（开发者）` | 用了哪些 Web API、数据怎么流转、关键函数在哪 |
| 10 | `二次修改指引（开发者）` | 想定制时改哪里、怎么改、有什么坑 |

每篇文档的固定元素：

- **首部引用块**：源文件相对链接（`../xxx.html`）、页面 `<title>` 原文、一句话定位、校验基准声明。
- **校验基准声明文案**（统一措辞）：
  > 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。
- **页脚链接**：`[返回文档索引](./README.md)`。

内容准确性规则：

1. 快捷键必须来自源码 `keydown` 处理函数的实际分支，不从更新日志推测。
2. 取值范围必须抄录源码中的 `min` / `max` / 代码常量确切边界。
3. 无法从源码确认的能力，标注「未在源码中确认」或不写入。
4. 与根 README 描述冲突时，以源码实际行为为准，并在文档中标注差异。

| 工具 | 外联内容 | 断网表现 |

### 唯一一个多文件工具

其余工具都是**单个 HTML 文件**，`汉字转拼音` 是**例外**：它需要一个 305 KB 的拼音词典数据文件，因此单独占一个目录，两个文件必须同目录存放。

| 文件 | 大小 | 作用 |
| ---- | ---- | ---- |
| `汉字转拼音/汉字转拼音.html` | 35 KB | 界面与全部逻辑 |
| `汉字转拼音/拼音词典.js` | 306 KB | `window.PINYIN_DB`，单字 20903 条（多音字 3050）+ 多音词组 855 条，来自 `pinyin-data@1.0.0`（ISC 许可） |

词典随仓库分发，**运行时零网络请求**；只拷走 HTML 会导致页面显示「词典缺失」。分发或部署时必须整目录拷贝。

## 按场景查找

**背口诀 / 练诵读**
→ [乘法口诀](./乘法口诀.md)（1×1–19×19）、[大成法口诀](./大成法口诀.md)（七妙法门）

**看本地电子书**
→ [阅读器](./阅读器.md)。EPUB / MOBI / TXT 均可，也能直接粘文本建书；书架存 `IndexedDB`，换浏览器需重新导入。

**本地听歌、调音、对歌词**
→ [音乐播放器](./音乐播放器.md)

**给中文加拼音 / 注音排版**
→ [汉字转拼音](./汉字转拼音.md)。带音调 / 数字调 / 无声调 / 首字母四种样式，注音排版、逐格对照、逐字内联、纯拼音四种视图；多音字点击即可改读，可导出 `<ruby>` HTML。纯本地不联网，单次上限 20 万字。

**日常开发打杂**

- 只想美化一段 JSON、展开字段里套的 JSON 字符串 → [全能格式化工具箱](./全能格式化工具箱.md)
- 要 RSA 签名验签、导出可复用工具类 → [数字签名](./数字签名.md)
- 写正则、验证匹配、预览替换 → [正则测试台](./正则测试台.md)。实时高亮 + 捕获组位置 + 替换预览，`g i m s u y` 开关一键切换，内置 27 条常用正则与 27 个元字符速查。匹配在 Web Worker 里跑，灾难性回溯也不会卡死页面。
- 算哈希、转 Base64 / Hex / URL 编码、看 JWT 内容 → [编码转换台](./编码转换台.md)。MD5 为页面内置实现（`crypto.subtle` 不支持 MD5），SHA 家族 / HMAC / JWT 验签走 Web Crypto。粘贴内容不出本机。
- 拿到一串乱码字节，不知道原始编码 → [编码转换台](./编码转换台.md) 的「字节解码」模式。同一份字节用 10 种编码并排解出，按 U+FFFD 与控制符数量打分排序并标出推荐。

**对比两份文本 / 文件改了什么**
→ [文件对比](./文件对比.md)。行级 + 词级高亮，三种查看器，可把某处差异整块搬到另一侧，导出标准 unified `.diff`。单侧上限 2 MB，纯本地不联网。

**压图片 / 转图片格式 / 一定要压到某个 KB 以内**
→ [图片压缩台](./图片压缩台.md)。批量压缩 + JPEG / PNG / WebP 互转 + 目标体积上限 + ZIP 打包。透明图自动采样识别并可填底色，大比例缩放走逐级减半降采样不糊。单次上限 200 张、单文件 50 MB。**不保留 EXIF**（含 GPS、拍摄时间），要留元数据请用 ImageMagick。

**写 Markdown / 把 `.md` 转成能发出去的网页**
→ [Markdown 双栏编辑器](./Markdown双栏编辑器.md)。左写右预览、大纲导航、标题自动编号、字数统计，导出 `.md` / 独立 `.html` / PDF。工具栏操作走 `execCommand` 保留 `Ctrl+Z`，列表回车自动续号、空项回车退出列表。原始 HTML 默认关闭，不注入脚本。**不是完整 CommonMark**，脚注 / 公式 / Mermaid 不支持。

**做设计取色、出渐变 CSS**
→ [颜色选择器](./颜色选择器.md)

**计时 / 算时间**
→ [时间计算台](./时间计算台.md)。番茄钟（25/5/15，每 4 轮长休）、自定义倒计时、两个时间点之间的天时分秒 + 工作日数、日期加减（含自然月收口与 ISO 周号）。所有计时基于 `Date.now()` 时间戳差值而非 `setInterval` 累加，**切到后台或锁屏不会走慢**；提示音由 Web Audio 现场合成，不加载音频文件。**不识别法定节假日与调休**，也不做时区换算；计时状态只在内存，刷新即重置。

**生成能直接发出去的二维码图**
→ [二维码工坊](./二维码工坊.md)

**做网页背景 / 粒子特效**

- 想要交互效果多、能导出独立 HTML 文件 → [动态离子选择器](./动态离子选择器.md)
- 想要风格预设多、能生成嵌入代码、支持文字图片粒子化 → [离子选择器](./离子选择器.md)

**管理自己的常用网址**
→ [储物间导航](./储物间导航.md)

## 维护提示

- **新增工具时**：按上面的 10 章骨架新建一篇 `docs/<工具名>.md`，并在「工具文档总表」加一行、「按场景查找」归类；不要改动其它已定稿文档。
- **移除工具时**：除删除 HTML 与对应文档外，必须同步清理三处——根 [README.md](../README.md) 的工具清单与目录结构、本文件的总表与按场景查找、以及其它文档里指向它的相对链接。
- **命名约定**：文档文件名使用中文短名，与根 README 中的工具称呼对齐。当前映射：
  - `DeepSeek-颜色选择器HTML代码.html` → `颜色选择器.md`
  - `千问代码_专属二维码工坊.html` → `二维码工坊.md`
  - 其余工具文档与源文件同名（去掉 `.html` 后缀）。
