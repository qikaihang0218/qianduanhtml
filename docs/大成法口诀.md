# 大成法口诀 · 操作文档

> 源文件：[../大成法口诀.html](../大成法口诀.html)
> 页面标题：`大成法口诀 · 七妙法门`
> 一句话定位：意拳（大成拳）七步修习口诀的静态诵读页，支持竖排诵读、逐句朗读、木鱼/古琴背景音与竖排书法风导出。
>
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

## 1. 工具简介

内容是一份**写死在源码里的固定文本**（`DATA` 常量，`大成法口诀.html:204-308`）：一个「总纲」段加八个分节，页面副标题为「七妙法门 · 站桩 试力 走步 发力 试声 推手 实作」，页脚标注「依王芗斋一脉拳论与流传歌诀整理 · 仅供研习参考」。

> 内容口径提示：副标写「七妙法门」，而 `DATA` 实际是「总纲 + 8 个编号分节（一 养生桩 … 八 实作）」。这是源码本身的表述差异，文档如实记录，不作修正。

适合谁用：

- 需要一张干净页面反复诵读、默背这些口诀的人。
- 需要**竖排右起**诵读体验的人（竖排用 `writing-mode:vertical-rl` + `text-orientation:upright`，`:94`）。
- 需要一张竖排书法风格的图片用于打印/张贴的人（`存图` 出口）。
- 需要配合木鱼或古琴节拍诵读的人（背景音由 WebAudio 实时合成）。

**不适合的场景**：

- 没有搜索、注释、译文、笔记功能；口诀文本在页面上不可编辑。
- 没有学习进度、复习计划、随机抽查。
- 想改内容只能改源码 `DATA`（见第 10 章）。

## 2. 快速开始

1. 双击 `大成法口诀.html`，用 Chrome 或 Edge 打开。
2. 页面直接显示全部口诀，无需导入。
3. 点顶栏 `▶ 朗读` 从头诵读，当前句高亮并自动居中；或**点击任意一句**从该句开始。
4. 点 `木鱼` 起背景节拍（再点依次切到 `古琴`、`静音`）。
5. 想竖排：按 `V` 或点 `竖排`。想保存：`存图` 出 PNG，`PDF` 走打印。

## 4. 功能操作详解

### 4.1 横排 / 竖排

1. 点 `竖排` 或按 `V`。
2. 版面改为右起竖列，并自动把横向滚动条拉到起始位置（`stageEl.scrollTo({ left: stageEl.scrollWidth })`，`:372`）。
3. 竖排时舞台转为横向滚动（`overflow-x:auto; overflow-y:hidden`，`:43`）。

### 4.2 字号

- 拖滑块，或按 `+` / `=`（+2px）、`-`（−2px）。
- 边界 **16–48**。注意：与「乘法口诀」不同，本页 `applyFs()` **没有内部 clamp**（`:359-363`），边界靠快捷键处显式判断 `Math.min(48, ...)` / `Math.max(16, ...)`（`:725-726`）与滑块自身 `min/max` 保证。
- 字号不持久化，刷新回到 26（移动端 CSS 默认 21，`:153`）。

### 4.3 逐句朗读

1. `▶ 朗读` 从「总纲」第一句开始；点击任意一句从该句开始（`:347`）。
2. 朗读中再点按钮 → 暂停（文案变 `▶ 继续`）；再点 → 继续。
3. `■ 停止` 或 `Esc` 终止并复位进度。
4. 语速滑块可在朗读中实时改，下一句生效（每句新建 utterance 时读取，`:449`）。
5. 语音参数固定：`lang='zh-CN'`、`pitch=0.95`（比乘法口诀页略低，`:450`）。
6. 句间固定间隔 160ms（`:456`、`:461`）。
7. 本页朗读**不做文本改写**，直接把原文交给语音引擎（`:447`），因此「半丁半八弓箭步」这类句子按字面读。

### 4.4 背景音（木鱼 / 古琴）

三态循环，按钮文案表示**下一个**状态：

| 当前状态 | 按钮显示 | 点击后进入 | 节奏 |
| ---- | ---- | ---- | ---- |
| `off` | `木鱼` | `wood` | 每 0.62 秒一击，每第 4 击为重音 |
| `wood` | `古琴` | `guqin` | 每 0.85 秒一步；偶数步从 9 音音阶随机拨一个音（`SCALE`，`:500`），每第 8 步叠一击木鱼 |
| `guqin` | `静音` | `off` | 停止 |

木鱼用三角波 + 带通滤波（`tok`，`:510`），古琴用三角波 + 二次谐波双振荡器配 2.6 秒长衰减包络（`pluck`，`:523`）。全部实时合成，不加载音频文件。首次点击时才创建 `AudioContext`（`:502-508`）。

### 4.5 导出图片（竖排书法版）

点 `存图` → Canvas 重新绘制并下载 `大成法口诀.png`（`:704-710`）：

- 排版为**右起竖列**：每列一句（或标题列/副标列），节与节之间插入更宽的间隔列。
- 字号固定 30px、列间距 24px、节间隔 56px（`:597`）；画布高度由**最长那句的字数**决定，宽度由列数决定 —— 即图会非常宽、较矮。
- 右上竖排标题「大成法口诀」＋其下「七妙」朱红印章；左下页脚落款。
- 含双线金框与纸张噪点纹理。
- **配色跟随当前主题**（`:609-614`）。
- 与页面字号滑块、横竖排状态**无关**。

### 4.6 导出 PDF

点 `PDF` = `window.print()`（`:713`）。打印样式（`:142-151`）强制 `writing-mode:horizontal-tb`（**竖排也会打印成横排**）、白底黑字、隐藏工具栏与状态条、每节 `page-break-inside:avoid`、正文 12pt。

## 5. 快捷键一览

单个 `keydown` 监听（`:716-727`），守卫为**焦点不在 `INPUT` 上**。

| 按键 | 动作 | 生效条件 |
| ---- | ---- | ---- |
| `空格` | 等同点击朗读/暂停按钮 | 已 `preventDefault` |
| `V` | 切换横排 / 竖排 | 直接调 `setOrient` |
| `T` | 切换深浅主题 | 等同点击主题按钮 |
| `F` | 切换全屏 | 等同点击全屏按钮 |
| `M` | 循环背景音（木鱼→古琴→静音） | 等同点击背景音按钮 |
| `Esc` | 停止朗读 | 调 `stopSpeak()` |
| `+` 或 `=` | 字号 +2px，上限 48 | 上限在此处显式判断 |
| `-` | 字号 −2px，下限 16 | 下限在此处显式判断 |

## 6. 支持的输入 / 输出格式

**输入**：无。文本是源码常量，不接受文件、粘贴或网络输入。

**输出**：

| 出口 | 格式 | 文件名 | 说明 |
| ---- | ---- | ---- | ---- |
| `存图` | PNG | `大成法口诀.png` | 竖排右起书法版，尺寸随内容动态计算 |
| `PDF` | PDF（经浏览器打印） | 由打印对话框决定 | 强制横排、白底黑字 |

**明确不支持**：导出 TXT/Word/SVG；只导出某一节；自定义标题或落款文字（均为源码字符串常量，`:645`、`:702`）；导出当前页面截图。

## 7. 数据与隐私

- **完全不联网**：源码中无 `<link>`、无 `@import`、无 `fetch`、无 `<script src>`、无外部域名。字体使用系统本地衬线中文字体栈（`:33`）。
- **唯一持久化**：`localStorage` 键 **`dc-dark`**，值 `"1"` / `"0"`，仅记录深色主题（写 `:383`，读 `:386`）。
- 不使用 `IndexedDB`、`sessionStorage`、Cookie。
- 朗读走系统 `speechSynthesis`，是否联网取决于浏览器所用语音实现。
- **清除方法**：删除本站点 `localStorage` 中的 `dc-dark`。横竖排、字号、语速、背景音状态本就不保存。

## 8. 常见问题（FAQ）

**点朗读没声音。**
系统缺中文语音包。确认用 Chrome / Edge，并在系统语音设置安装中文语音。`speechSynthesis` 不存在时会弹窗 `当前浏览器不支持语音朗读，请使用 Chrome / Edge。`（`:468`、`:483`）。

**背景音点了不响。**
浏览器自动播放策略要求用户手势；`背景音` 按钮本身即手势。若仍无声，检查系统音量、标签页静音；代码在 `AudioContext` 处于 `suspended` 时会尝试 `resume()`（`:558`）。

**古琴模式每次数码出来的音不一样，是 bug 吗？**
不是。古琴模式从 9 音音阶里**随机**取音（`Math.floor(Math.random() * SCALE.length)`，`:544`），所以每次不同。

**导出的 PNG 特别宽、特别矮。**
设计如此：竖排每句占一列，列数≈句子数，宽度按列数累加；高度只按最长那句的字数算。想要更接近 A4，需改 `exportImage()` 的排布逻辑（见第 10 章）。

**竖排模式下翻不动。**
竖排是横向滚动，滚动条在舞台底部；用触摸板左右滑动，或按 `V` 回横排。

**打印出来变成横排了。**
`@media print` 里有 `writing-mode:horizontal-tb !important`（`:147`）。要打印竖排必须改用 `存图` 出口再打印图片。

**深色主题导出的图看不清。**
深色导出为深底浅字，适合屏幕不适合打印。打印请切回浅色主题再导出。

## 9. 技术实现要点（开发者）

**用到的 Web API**：`SpeechSynthesis`、`AudioContext` + 振荡器/带通滤波/增益包络、`Canvas 2D` + `toBlob`、Fullscreen API、`localStorage`、CSS `writing-mode:vertical-rl` 与 `text-orientation:upright`。

**数据流**：与「乘法口诀」同构 —— `DATA` → `render()` 生成 DOM 与 `items[{el,si,li,text}]` → 点击句 → `startFrom(si,li)` → `buildQueue` 展平为线性队列 → `speakNext(runId)` 递归，`onstart` 高亮居中、`onend` 推进。区别仅在于本页 `DATA` 是手写字面量且每节多一个 `sub` 副标字段（`:336-341`）。

**并发控制**：自增 `runId` 作轮次令牌，`stopSpeak()` 使 `runId++`，在途回调比对 `myRun !== runId` 即返回（`:443`、`:452`、`:454`、`:459`）。

**背景音调度**：`setInterval(schedule, 90)` 每 90ms 预排未来 350ms 内的事件（`while (nextTime < ac.currentTime + 0.35)`，`:537`），用 `AudioContext.currentTime` 作时钟，避免 `setInterval` 抖动直接进声音。

**关键函数索引**：

| `setOrient(vertical)` | 367-372 | 切横竖排并滚到起始列 |
| `setTheme(dark)` | 377-383 | 切主题并写 `dc-dark` |

## 10. 二次修改指引（开发者）

**改口诀文本**：只改 `DATA`（`:204-308`）。每项形如 `{ title, sub, lines: [...] }`，`sub` 可省略（渲染处有 `if (sec.sub)` 判断，`:336`）。改完页面、朗读、导出、打印四处自动同步 —— 这是本页最值得注意的优点。

**改分节编号或副标风格**：编号写死在 `title` 字符串里（如 `'三 · 钩锉试力'`），没有自动生成逻辑，直接改字符串。

**改导出为接近 A4 的版式**：`exportImage()` 目前是「一句一列」的超宽布局。要变成多页/多栏，需要：
1. 在 `buildColumns()` 之后按目标高度把 `cols` 切成多组；
2. 每组各画一张画布并分别下载（或拼成一张长图）。
关键常量集中在 `:597-601`：`cs`（字号 30）、`gap`（列距 24）、`secGap`（节间隔 56）、`top`/`bottom`（上下留白 200/190）。

**改音阶**：`SCALE`（`:500`）是 9 个频率（Hz），当前是宫商角徵羽一类的五声扩展。改成任意数组即可，`pluck` 接受任意频率。

**新增第四种背景音**：三处必须同步改，漏一处会点出 `undefined`：
1. `schedule()` 加 `musicMode` 分支（`:535-554`）；
2. `setMusic()` 的按钮文案表 `{ off:'木鱼', wood:'古琴', guqin:'静音' }`（`:564`）；
3. 点击循环映射 `{ off:'wood', wood:'guqin', guqin:'off' }`（`:569`）。

**若要把字号也持久化**：仿 `dc-dark`，在 `applyFs()` 里写 `localStorage`、初始化时读回。但**先给 `applyFs` 补上 clamp**（当前没有），否则历史脏值或未来改快捷键会写出越界字号。

**打印竖排**：若确实需要竖排打印，删掉 `:147` 里的 `writing-mode:horizontal-tb !important`，并自行验证分页 —— 竖排分页在多数浏览器上表现不佳，这也是当前实现强制转横排的原因。
