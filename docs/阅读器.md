# 静读 · 本地电子书阅读器 · 操作文档

> 源文件：[../阅读器.html](../阅读器.html)
> 页面标题：`静读 · 本地电子书阅读器`
> 一句话定位：把 EPUB / MOBI / TXT 导入浏览器 IndexedDB 书架，在本地完成解析、分章、分页、自动翻页与朗读的**单文件阅读器**。
>
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

## 1. 工具简介

它是一个**两屏应用**：书架屏（`#shelf`）与阅读屏（`#reader`）。导入的书被解析成 `{title, author, type, chapters:[{title, html}]}` 后整体写入 IndexedDB，之后所有渲染、分页、进度保存都在这一个 HTML 文件里完成，**不发起任何网络请求**。

适合谁用：

- 手上只有本地电子书文件、不想装阅读器软件、也不想把书上传到任何服务的人。
- 需要**翻页模式 + 自动翻页 + 朗读**的通勤阅读场景（`A` 一键开关自动翻页）。
- 需要把网页、聊天里复制出来的长文本临时变成「一本书」来读的人（`✎ 粘贴文本` 出口）。

**不适合的场景**：

- **DRM 书籍一律打不开**（Kindle 加密 AZW、Adobe ACS 加密 EPUB 都不行），解析器只处理明文结构。
- 不支持 PDF、DOCX、FB2、CBZ。
- 没有笔记、划线、书签、高亮、搜索、导出功能。进度只有一个 0–1 的比例数字。
- 书架不能跨设备同步，也不能导出/导入书架备份文件。

## 2. 快速开始

1. 双击 `阅读器.html`，用 Chrome 或 Edge 打开（解 EPUB 依赖 `DecompressionStream`，需 Chromium 80+ / Firefox 113+）。
2. 书架屏把 `.epub` 文件**拖进虚线框**，或点框内 / 点 `＋ 导入书籍` 选文件（可一次多选）。
3. 顶部转圈显示「正在解析…」，完成后出现 `《书名》导入成功` 的 toast，书封出现在下方网格。
4. 点书封进入阅读屏，右下角显示百分比进度。
5. 点顶栏 `翻页` 切成翻页模式，然后用 `→` / `空格` / 滚轮 / 点屏幕右半侧翻页。
6. 想让它自己翻：点 `自动`（或按 `A`），用「速」滑块调速。

- `#content` 是正文容器，翻页模式下用 CSS **多列**（`column-width`）排版，再用 `translateX` 整列平移实现翻页（`:1291-1305`）。
- `#zoneL` / `#zoneR` 是覆盖左右两侧的透明点击热区：左半屏上一页、右半屏下一页。

## 4. 功能操作详解

### 4.1 导入文件

1. 拖文件进 `#drop`，或点 `＋ 导入书籍` / 点拖放区，支持**多选**。
2. 解析分派按**扩展名 + 文件头**判断（`:963-995`）：
   - 扩展名 `epub`，**或**文件头 4 字节等于 ZIP 魔数 `0x04034b50` → 走 EPUB 解析（ZIP 解包）。
   - `txt` → 按章节标题正则切分（见 4.3）。
   - `html` / `htm` → 剥掉 `<script>` / `<style>`，取 `<body>` 内容，再按 `splitMobiHtml` 切章。
   - 其余（`mobi` / `azw` / `azw3` / `prc`）→ 走 MOBI 解析器。
3. 成功提示 `《书名》导入成功`；失败提示 `解析失败：<原因>`，最常见是 `没有提取到正文内容`。
4. 文件选择框的 `accept` 是 `.epub,.mobi,.azw,.azw3,.prc,.txt,.html,.htm`，但**拖放不受 accept 限制**，任何文件都会被尝试解析。

### 4.2 粘贴文本成书

1. 书架屏点 `✎ 粘贴文本`，弹窗出现。
2. 书名**可留空**，留空时自动取第一个章节标题，再退回首行前 30 字（`:793`、`:1093`）。
3. 把文本粘进大文本框，下方实时显示「N 字 · N 行」（字数已去掉空白）。
4. 也可点 `从剪贴板读取` 让页面自己读剪贴板（走 `navigator.clipboard.readText()`，需要权限；失败会提示 `无法读取剪贴板，请手动粘贴（Ctrl+V）`）。
5. 点 `保存到书架`，提示 `已保存《书名》共 N 章`。书名超过 60 字会被截断。

### 4.3 TXT 自动分章规则

判定依据是正则 `TXT_HEAD`（`:775`），一行被认作章节标题需**同时满足**：整行长度 ≤ 40 字符，且匹配下列任一形式：

- `第X章` / `第X节` / `第X回` / `第X卷` / `第X篇` / `第X部` / `第X集`（数字支持阿拉伯数字与中文零一二三四五六七八九十百千两）
- `Chapter 12` / `CHAPTER 12`
- 独立成行的 `序章` `序言` `前言` `楔子` `尾声` `后记` `附录` `番外`

规则细节：

- 标题行**少于 2 个**时，整篇当作一章，章节名取首个非空行前 30 字。
- 第一个标题之前的内容会单独成章，标题固定为 `卷首`。
- 段落按**空行**切分（`\n\s*\n`），段内单换行转成 `<br>`。
- 空文件渲染为 `（空文件）`，无正文的章节渲染为 `（本章无正文）`。

### 4.4 滚动 / 翻页模式

1. 点 `翻页`（或 `滚动`）切换，写入 `rd-paged`。
2. 切换时**保持当前阅读比例**：先记录 `currentRatio()`，重排后 `restoreRatio()` 还原（`:1199-1205`）。
3. 翻页模式的分页是**运行时测量**出来的：列宽 = 舞台宽 − 左右各 `max(28, 5.5%)` 的留白，总页数 = `round(scrollWidth / 舞台宽)`（`:1288-1297`）。
4. 因此**改字号/行距/栏宽会重新分页**，代码通过 `afterLayoutChange()` 重测并还原比例，页码数字会变但百分比位置基本不变。
5. 翻页输入方式：`→` / `空格` / `PageDown` 下一页，`←` / `PageUp` 上一页；滚轮（`|deltaY| ≥ 8` 才响应，避免触控板抖动）；点左/右侧热区；触摸模式下横向滑动 > 55px 且水平位移 > 垂直位移 ×1.6。

### 4.5 自动翻页

1. 点 `自动` 或按 `A`。toast 会报出实际间隔：`自动翻页已开启 · 每 X.X 秒`。
2. 间隔由「速」滑块换算：`间隔 = 20000 − (速度−1) × (20000−1200) / 9` 毫秒（`:1329-1332`）。默认速度 4 → 约 **16267ms**；速度 10 → 1200ms；速度 1 → 20000ms。
3. **翻页模式**下每次翻一整页；**滚动模式**下每次平滑滚动 `视口高 × 0.86`（最小 40px，`:1344`）。
4. 朗读中调「速」滑块会**立刻重排下一次触发**（`:1397-1403`），无需重启。
5. 自动停止条件：翻页模式到末页 → `已到末页`；滚动模式到底 → `已到文末`；内容不足一屏 → `内容不足一屏`。
6. **任何手动操作都会自动暂停**：在舞台上滚动滚轮、触摸、点左/右热区，都会 `stopAuto('已暂停自动翻页')`（`:1407-1413`）。
7. 再按 `A` 或点 `暂停` 是主动暂停，提示 `自动翻页已暂停`。

### 4.6 朗读

1. 点 `朗读`（按钮变 `停止`）。
2. 朗读**从当前视口顶部那一段开始**，不是从书开头（`:1576-1580`）。
3. 朗读单位是 DOM 段落：收集 `p, h1, h2, h3, h4, li, blockquote` 中**文本长度 > 1** 的元素（`:1537-1540`）。
4. 当前段加 `.hl` 高亮；滚动模式下自动 `scrollIntoView({block:'center'})` 居中，**翻页模式下不滚动**（靠自动翻页或手动翻页推进，两者互不干扰）。
5. 每段最多读前 **400 字**（`:1562`），段间固定间隔 120ms。
6. 语音固定 `lang='zh-CN'`、`rate=1`、`pitch` 未设置。**「速」滑块不影响朗读速度**，它只管自动翻页。
7. 再点 `停止` 或按 `Esc` 结束。

### 4.7 目录跳转

1. 点 `目录`（或顶栏按钮）打开右侧抽屉，列出全部章节标题。
2. 点章节名跳转：滚动模式 `scrollIntoView` 平滑滚动；翻页模式按元素横向偏移 ÷ 页宽**换算成目标页**（`:1268-1271`）。
3. 底栏随滚动实时更新当前章节高亮。
4. 关闭方式：`×`、遮罩、`Esc`。

### 4.8 主题与进度

- 四套主题循环：`纸白 → 米黄 → 护眼 → 夜间 → 纸白`（`THEMES` / `THEME_NAME`，`:1135-1136`），实现在 `<body>` 上切 `theme-xxx` 类。
- 进度在翻页/滚动/切章/返回书架时通过 `scheduleSave()` 防抖写入，存的是 `currentRatio()`（0–1）。下次打开自动 `restoreRatio(book.progress)`。
- 删除书籍：书封上的删除按钮 → `confirm('删除《书名》？')` → 从 IndexedDB 删除 → `toast('已删除')`。**无回收站，不可撤销**。

## 5. 快捷键一览

单个 `keydown` 监听（`:1418-1431`），**两条前置守卫**：阅读屏必须可见（书架屏上所有快捷键无效），且焦点不在 `INPUT` 上（焦点在滑块上时快捷键全部失效）。

| 按键 | 动作 | 生效条件 |
| ---- | ---- | ---- |
| `→` / `空格` / `PageDown` | 下一页 | **仅翻页模式**；已 `preventDefault` |
| `←` / `PageUp` | 上一页 | **仅翻页模式**；已 `preventDefault` |
| `↑` / `↓` | 无绑定 | 滚动模式走浏览器原生滚动 |
| `A` | 开 / 关自动翻页 | 两种模式都可用；已 `preventDefault` |
| `Esc` | 关闭目录抽屉 + 停止朗读 + 停止自动翻页 | 三件事一次做完 |

注意：滚动模式下按 `→` / `←` 会被**显式忽略**（`:1428` 直接 return，既不翻页也不阻止默认行为）。

未在源码中确认的键位：`+` / `-` 调字号、`T` 切主题、`F` 全屏、`C` 目录、`J` / `K` —— 均无绑定，只能用顶栏按钮。

## 6. 支持的输入 / 输出格式

**输入**：

| 扩展名 | 解析路径 | 说明 |
| ---- | ---- | ---- |
| `.epub` | EPUB（ZIP + `DecompressionStream('deflate-raw')`） | 读 `container.xml` → OPF → spine，提取标题/作者 |
| `.txt` | `splitTxt` 正则分章 | 需 **UTF-8** 编码，见 FAQ |
| `.html` / `.htm` | 剥脚本样式后 `splitMobiHtml` | 按 `<hr class="pb">` 或 `h1`/`h2` 切章 |
| `.mobi` / `.azw` / `.azw3` / `.prc` | `parseMobi` → `splitMobiHtml` | **仅限无 DRM** 文件 |
| 任意文本 | `✎ 粘贴文本` 弹窗 | 也可从剪贴板读取 |

**输出**：

| 出口 | 形式 | 说明 |
| ---- | ---- | ---- |
| 屏幕阅读 | DOM 渲染 | 滚动或翻页两种排版 |
| 语音 | `speechSynthesis` | 逐段朗读，非音频文件 |
| 书架 | IndexedDB 记录 | 非用户可导出的文件格式 |

**明确不支持**：导出 PDF / TXT / EPUB；导出或导入书架备份；PDF、DOCX、FB2、CBZ 输入；带 DRM 的文件；修改已导入书的正文。

## 7. 数据与隐私

- **完全不联网**：源码中无 `<link>`、无 `@import`、无 `fetch`、无 `<script src>`、无任何外部域名。EPUB 内的图片若以外部 URL 引用不会加载。
- **书籍正文**存 `IndexedDB`：数据库 **`quiet-reader`**，对象仓库 **`books`**，`keyPath: 'id'`（`:860-873`）。每条记录含 `id / title / author / type / size / chapters / progress / added / lastRead`。**整本书的 HTML 全文都存在这里**。
- **偏好设置**存 `localStorage`，共 6 个键：

| 键 | 值 | 默认 |
| ---- | ---- | ---- |
| `rd-fs` | 字号，如 `"19"` | 19 |
| `rd-lh` | 行距，`"1.90"` 形式（两位小数） | 1.9 |
| `rd-pw` | 栏宽，如 `"720"` | 720 |
| `rd-theme` | `paper` / `sepia` / `green` / `night` | `paper` |
| `rd-paged` | `"1"` 翻页 / `"0"` 滚动 | `"0"` |
| `rd-spd` | 自动翻页速度 `"1"`–`"10"` | 4 |

- 不使用 Cookie、`sessionStorage`。
- **清除方法**：
  - 只清设置：F12 → Application → Local Storage → 删除 `rd-*` 六个键。
  - 清书架：Application → IndexedDB → `quiet-reader` → `books` → 删除记录；或直接在书封上点删除按钮逐本删。
  - 彻底清空：清除本站点的「网站数据 / 浏览数据」。
- **注意**：`file://` 下浏览器把每个文件视为同一来源的风险较低但存储配额受限；大文件（几百 MB 的 TXT）可能触发配额报错，`dbPut` 失败会提示 `保存失败：<原因>`。
- 朗读会把段落文本交给系统/浏览器语音实现，是否联网取决于该实现。

## 8. 常见问题（FAQ）

**EPUB 导入报「解析失败」。**
三个常见原因：① 浏览器过旧，无 `DecompressionStream`（需 Chromium 80+ / Firefox 113+），换 Chrome/Edge；② 文件带 DRM；③ EPUB 内部缺 `META-INF/container.xml` 或 OPF 结构异常。

**TXT 打开是乱码。**
解码器固定按 UTF-8（`decUTF8`）解码。GBK/GB18030 编码的 TXT 会乱码。先用编辑器「另存为 → UTF-8」再导入，或用 `✎ 粘贴文本` 把内容贴进去。

**TXT 没有分章，整本是一章。**
章节标题行必须**整行**匹配且长度 ≤ 40 字符，且至少要有 2 个标题。行首尾有多余文字（如「第三十章 夜袭 —— 本节完」超长）、或标题与正文写在同一行，都识别不到。可用粘贴文本功能先手工规整。

**翻页模式下左右出现大片空白 / 页码算错。**
分页是按 `scrollWidth / 舞台宽` 反推的近似值，字体异步加载完成前后可能差一页。等字体加载完，或随便调一下字号滑块触发重测即可校正。

**改字号后页码变了。**
这是预期行为：分页依赖排版，改字号/行距/栏宽都会重新分页。程序会保持**百分比进度**而不是页码。

**自动翻页走几下就停了。**
你不小心动了滚轮或点了屏幕 —— 任何手动操作都会暂停自动翻页（这是设计如此，避免抢你的操作）。按 `A` 重新开始。

**自动翻页太快/太慢。**
「速」滑块 1 最慢（20 秒）、10 最快（1.2 秒），默认 4 约 16.3 秒。窄屏下这组滑块被 CSS 隐藏，需拉宽窗口。

**点朗读没声音。**
系统缺中文语音包，或 `speechSynthesis` 不可用（会提示 `当前浏览器不支持语音朗读`）。另外每段只读前 400 字，超长段落会「跳字」。

**朗读时页面不跟着滚。**
翻页模式下朗读**故意不滚动**（`:1559`）。要边听边滚，请切到滚动模式，或同时开自动翻页。

**换电脑/换浏览器后书架没了。**
IndexedDB 按「来源」隔离，`file://` 与 `http://localhost` 是不同来源，不同浏览器之间更不互通。当前没有书架导出功能。

**删错了书。**
无法恢复，只能重新导入原文件。

## 9. 技术实现要点（开发者）

**用到的 Web API**：`IndexedDB`、`DecompressionStream('deflate-raw')`（EPUB ZIP 解压）、`DOMParser` / 正则解析 XHTML、`TextDecoder('utf-8')`、`SpeechSynthesis`、Fullscreen API、`navigator.clipboard.readText()`、CSS `column-width` + `translateX` 分页、`requestAnimationFrame` 环形进度。

**数据流**：

```
File.arrayBuffer()
  └─ importFile(file)（954-1019）
       ├─ 扩展名 / ZIP 魔数分派
       │    ├─ parseEpub(buf)  → {title, author, chapters:[{title,html}]}
       │    ├─ splitTxt(txt)   → chapters
       │    └─ parseMobi(buf) + splitMobiHtml(html) → chapters
       ├─ dbPut(rec) → IndexedDB quiet-reader/books
       └─ renderShelf()

openBook(id)（1589-1605）
  ├─ dbGet(id) → curBook
  ├─ applySettings()（读 6 个 localStorage 键 → CSS 变量 + body class）
  ├─ renderBook(book) → #content 内 <section id="ch{i}>
  ├─ buildToc(book)
  ├─ 等两帧 → measurePages()（多列布局 + 反推 totalPages）
  └─ restoreRatio(book.progress)
```

**并发/取消控制**：朗读用自增 `speakRun` 作轮次令牌，`stopSpeak()` 让 `speakRun++`，在途 `onend`/`onerror` 回调发现令牌不匹配即返回（`:1542-1567`）。自动翻页用 `autoTimer`(setTimeout) + `autoRaf`(rAF) 双句柄，`stopAuto()` 同时清理（`:1377-1387`）。

## 10. 二次修改指引（开发者）

**新增一种格式**：在 `importFile()` 的分派链（`:963-995`）加一个 `else if (ext === 'xxx')` 分支，产出的 `chapters` 只要满足 `[{title:string, html:string}]` 就能直接复用后续所有环节（渲染、目录、分页、朗读、进度）。同时记得给文件选择框 `accept`（`:268`）补扩展名 —— 但**拖放路径不看 accept**，两处不一致不影响可用性。

**改章节识别规则**：只改正则 `TXT_HEAD`（`:775`）。注意行长度阈值 `s.length <= 40` 是**写死在循环里**（`:783`）而非正则内，两处要一起调。想支持「Chapter 十二」这类混合写法也必须改这个正则。

**改自动翻页的速度曲线**：`AUTO_MIN=1200` / `AUTO_MAX=20000`（`:1321-1322`）是端点，`autoInterval()` 是线性插值。要「速度 5 = 5 秒」这类非线性手感，只改 `autoInterval()` 的公式即可，滑块范围不用动。

**让朗读语速跟随「速」滑块**：`speakAt()` 里 `u.rate = 1`（`:1564`）改成 `u.rate = 0.6 + autoSpeed() * 0.08` 之类的映射。**副作用**：该滑块同时控制自动翻页间隔，两者会耦合；若要解耦，需新增一个滑块与一个 `rd-speakrate` 键，并在 `applySettings()` 里回显。

**加书签/划线功能**：进度目前只是一个 ratio 数字（`book.progress`），粒度太粗。做书签需要：
1. 给记录加 `marks: [{chapterIndex, charOffset, note}]`；
2. `renderBook()` 渲染时给段落加 `data-p` 序号；
3. 跳转复用 `restoreRatio` / `gotoChapter` 的思路，按元素序号定位。
不要试图用 `Range` 序列化整个 HTML 来做锚点 —— 翻页模式会整体重写 `#content` 的 transform，锚点会漂。

**改主题**：CSS 里每套主题是一组 `body.theme-xxx` 变量块。加第五套需要同时改 `THEMES` 数组和 `THEME_NAME` 映射（`:1135-1136`）—— **两处必须同步**，否则 `THEMES.indexOf(cur)` 找不到新值会退回 `undefined`，按钮文字变空白。

**换分页实现**：当前「多列 + translateX」方案让整本书一次性排版，几十万字时排版耗时明显。若要改成按需渲染，需重写 `measurePages()` 的 `totalPages` 来源（改为按章节累计），并把 `currentRatio()` 的分母从「页」换成「字数」。注意 `gotoChapter()`（`:1271`）依赖「横向偏移 ÷ 页宽 = 页码」这个假设，一并要改。

**注意 `afterLayoutChange()`**：所有滑块 `input` 事件都会调它来重测分页。新增任何影响排版的设置项时，务必也调用它，否则翻页模式下会出现「页数没更新但内容已重排」的错位。

**注意 `applySettings()` 用 `document.body.className = 'theme-' + th`**（`:1152`）—— 这是**整体赋值**，会抹掉其它 body 类。紧接着的 `classList.toggle('paged', paged)` 才把 `paged` 加回来。若你在 `<body>` 上自行加类，会被这行清掉。
