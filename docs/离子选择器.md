# 离子选择器 · 操作文档

> 源文件：[../离子选择器.html](../离子选择器.html)
> 页面标题：`Neon Particle Studio Pro · 多风格粒子实验室`
> 一句话定位：一个**零依赖的 Canvas 粒子特效工作台** —— 12 种风格 + 8 项实时参数 + 文字/图片粒子化 + 场景 JSON/URL 分享，并能生成嵌入代码。
>
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

## 1. 工具简介

左半边是实时预览画布，右半边是 5 段控制台。12 种粒子风格（科技网络 / 霓虹光带 / 粒子漩涡 / 星河宇宙 / 炽热火焰 / 赛博雨幕 / 水墨流体 / 几何晶体 / 流体粒子 / 极光薄雾 / 行星轨道 / 数字矩阵）+ 6 个一键场景预设，配合数量 / 速度 / 尺寸 / 发光 / 主色调 / 背景 / 力场 / 拖尾 8 个参数，可以几分钟内调出一个能直接用的动态背景。

三个让它「能用而不只是好玩」的能力：

1. **文字 / 图片粒子化**：输入文字或上传 Logo，粒子会飞过去拼成形状。图片采样**在本地完成**，不上传。
2. **两种分享途径**：`导出配置` 得到 JSON 文件；`复制分享链接` 把全部参数写进 URL query —— 后者不需要传文件，粘到聊天里就能分享。
3. **导出嵌入代码**：生成一段 `<canvas>` + `new ParticleEngine(...)` 的 HTML 片段，参数是你当前调好的值。

**与「动态离子选择器.html」的关系**：这是**两个不同的工具**，不是新旧版本。名字相近容易混淆，对照如下：

| | 离子选择器（本页） | 动态离子选择器 |
| ---- | ---- | ---- |
| 风格数 | 12 种 | 21 种（含四季主题） |
| 附加功能 | 场景预设 / JSON 与 URL 分享 / 嵌入代码 | 时钟、天气、多手势、独立 HTML 导出 |
| 联网 | Google Fonts 字体 | Open-Meteo 天气 API + 定位 |
| 定位 | 做**网站背景**的调参工作台 | 炫技式的**全屏互动**演示页 |

**不适合的场景 / 明确没有的能力**：

- ❌ **不能导出视频 / GIF / 图片序列**，也没有单帧 PNG 截图。想要视频只能屏幕录制。
- ❌ **不能导出可独立运行的 HTML**（动态离子选择器可以）。本页的「嵌入代码」只给片段，且**依赖一个本仓库并不存在的 `particle.js`**，见第 6 章与 FAQ。
- ❌ **无撤销**，`R` 键重置无任何确认。
- ❌ 无逐风格独立记忆（切风格后参数保留，但没有「每个风格记住我上次调的参数」）。
- ❌ 无粒子形状自定义（无贴图粒子）、无发射器/重力/碰撞物理、无多图层。
- ⚠️ 文字/图片聚合模式下**鼠标力场失效**，火焰/赛博雨/数字矩阵三种风格也**不吃力场**（源码显式排除，`:287`）。

## 2. 快速开始

1. 双击 `离子选择器.html` 打开。**首次需联网**下载 Google Fonts（Manrope / DM Mono / Noto Sans SC），离线则回落系统字体，**功能完全不受影响**。
2. 默认是「科技网络」风格，650 粒子。左侧画布会跟随鼠标排斥粒子。
3. **换风格**：右侧 `01 选择粒子风格` 里点任意一格（3 列 × 4 行）。
4. **一键出效果**：`02 快速场景预设` 里点 `梦幻极光` 或 `深空星云` —— 这俩最讨喜。
5. **微调**：`03 粒子参数` 里拖 4 个滑块 + 选 3 个下拉，画布即时响应。
6. **拼文字**：`04` 输入框打字 → 点 `聚合`（或按回车）。
7. **炸一下**：直接**点画布任意位置**，或按 `E`。
8. **存下来**：`保存当前场景`（本机下次打开自动恢复）或 `复制分享链接`（发给别人）。
9. 想拿回原始状态：按 `R` 或点 `重置 ↺`。

⚠️ 想全屏看效果就点画布右上角 `⛶`（或按 `F`）—— 只有画布进全屏，控制台会隐藏，按 `F` 退出。

## 3. 界面与功能分区

深色霓虹风（`--bg:#060916`，双径向光晕背景，`:8`），主容器 `max-width:1600px`。整体是**两栏网格** `minmax(0,1.62fr) minmax(360px,1fr)`，间距 18px。CSS 被压缩在第 9-13 行（单行内联），可读性差但结构简单。

### 3.1 顶栏（`:36-39`）

`✳ NEON / PARTICLE` + `多风格粒子实验室` · 右侧 `● 实时渲染 | <id=fpsLabel> FPS`。

FPS 每 **700ms** 采样刷新一次（`:460`），标签页隐藏时该循环停摆（`:458`）。

> ⚠️ **暂停时 FPS 不会归零**：FPS 由独立的 `stats()` rAF 循环统计（`:457-467`），而 `_frame` 里 `if (!this.running) return` 只是不画（`:243`），rAF 本身仍在跑。所以暂停后仍显示 ~60 FPS，**它反映的是浏览器帧率，不是渲染负载**。

## 4. 功能操作详解

### 4.1 风格切换

点风格格 → `setStyle` → **清掉文字/图片目标 + 重新随机分布所有粒子**（`:171`、`:177`）。也就是说：**切风格会打断正在进行的聚合**，且粒子初始位置被打乱（参数不变）。

`modeTag` 显示 `大写风格名 / 序号`，序号来自 `STYLE_TITLES` 的键序（`:359`）。

**不吃鼠标力场的风格**：`fire`、`rain`、`matrix`、`target`（`:287` 显式排除）。前三个是物理上不合适（粒子沿固定轨迹运动），如果你在这三种风格下调力场下拉，会看到 toast 提示切换成功但**画面毫无反应**。

### 4.2 场景预设

点预设 → `applyScene`（`:371-381`）依次做 5 件事：

1. `clearTarget()` —— **先清掉文字/图片聚合**；
2. `setOptions` 覆盖 8 项参数；
3. 回写所有滑块/下拉/output；
4. 改画布 CSS 背景色（`transparent` / `#000` / 空）；
5. 高亮当前预设按钮，toast `已应用场景：xxx`。

**注意第 1 步**：正在拼文字的粒子会被预设清掉。想「极光 + 我的 Logo」，正确顺序是**先点预设，再上传 Logo**。

`applyScene` 还会把力场强制设为 `repel`、拖尾强制 96%（`:373` 的兜底），因为 6 个内置预设都没定义这两个字段。

### 4.3 参数调节（实时）

4 个滑块都是 `input` 事件 → 立即改 `engine.options` 或调 `setCount`（`:407-410`、`:414`），无延迟、无需确认。

- **数量**：`setCount` 增删粒子数组，**新增的粒子随机分布**，删减则直接截断尾部（`:161-162`）。若当前处于聚合模式，会**重新分配目标点**（`:163`）→ 已聚合的图形会重新吸附一次，视觉上有轻微抖动。
- **速度**：直接改 `options.speed`，它乘在时间累加上（`:244`），所以是**全局时间缩放**，所有风格一致生效。
- **尺寸 / 发光**：纯渲染参数，零成本。
- **发光 = 0** 时 `shadowBlur` 关闭（`:310`），性能明显变好；`matrix` 风格**始终不加 shadow**（`:310` 排除）。
- **拖尾**：语义是「画面残留程度」，不是长度。渲染时用 `rgba(背景色, (100-trail)/100)` 覆盖一层（`:251-253`）→ **75% = 每帧盖 25% 不透明（几乎无拖尾）**，**100% = 每帧只盖 4%（超长拖尾）**。最低 75 是硬下限（低于此值拖尾会短到看不出粒子本体）。
- **透明背景 + 拖尾 100** 走 `clearRect`（`:247`），完全无拖尾 —— 这是唯一能让透明背景干净的组合；透明背景 + 拖尾 <100 用 `destination-out` 擦除（`:248`），会留下渐隐残影。

### 4.4 文字聚合

`聚合` 或输入框内 `Enter`（`:419`）→ `gatherText`（`:190-200`）：

1. 空文本 → toast `先输入想要聚合的文字`，不动作。
2. 离屏 1000×420 画布，字号按文本长度自适应（上限 240、下限 36、`800` 字重 Arial），超宽时每次 -4px 直到 ≤ 90% 宽。
3. **采样步长 `step = max(4, round(9 - count/350))`** —— 粒子越多采样越密：650 → step 7；1600 → step 5；120 → step 9。
4. 只取 alpha > 80 的像素，映射到画布 `x: 8%–92%`、`y: 18%–82%` 区域。
5. 目标点按 `i * points.length / particles.length` 分配给每个粒子（`:181`）→ **粒子数 > 采样点数时会重复使用同一目标点**，粒子数少则只用到部分点。

结果：风格切到内部 `target`，标题变 `文字聚合 · 你的文字`，`modeTag` 变 `TEXT MASK / CUSTOM`，toast `文字粒子化完成`。粒子以 **0.105 的插值系数**飞向目标（`:260`），是平滑收敛不是弹跳。

**限制**：

- 上限 **36 字符**（`maxlength`），但**中文与英文一样按字符计数**，36 个汉字在 1000px 画布上会被压得很扁（自适应字号最低 36px）。
- 单行，**不支持换行**。
- 目标点**不带颜色信息**，粒子颜色仍由「主色调」决定。
- 聚合中**鼠标力场完全无效**。

### 4.5 图片 / Logo 粒子化

点虚线上传区选文件（`:420-426`）：

1. `file.type` 不以 `image/` 开头 → toast `请选择图片文件`。
2. `URL.createObjectURL` + `Image` 加载，离屏 900×500 画布，**等比缩放至 86% 内接**并居中绘制。
3. 同样的 `step` 采样，跳过 `alpha <= 45` 的像素。
4. **智能背景剔除**（`:206-220`，这段是本页最讲究的逻辑）：
   - 取四角像素，若**四角都基本不透明**（alpha > 235）且**三通道极差 < 22** → 判定为纯色背景，算出背景色；
   - 采样时凡与背景色欧氏距离 < 42 的像素**丢弃**。
   - 效果：**白底黑 Logo / 深底白 Logo 这类非透明图也能干净抠出形状**。
   - 透明 PNG 走 alpha 通道，不做颜色过滤（注释 `:207` 明确说明）。
5. 无有效像素 → toast `未采样到有效像素，换一张对比更明显的图片试试`。

**不上传**：全程 `createObjectURL` + 本地 `drawImage` + `getImageData`，无任何网络请求，`finally` 里 `revokeObjectURL` 并清空 input（可连续导入同一文件）。

**实际会失败的情况**：

- 图片主体颜色与背景色接近（如浅灰底 + 白字）→ 被当背景剔掉。
- 四角颜色不一致的照片（风景照、截图）→ **不触发背景剔除**，整张图被均匀采样成一团矩形点阵，看不出形状。
- SVG 若未声明宽高，`image.width/height` 可能为 0 → 走 `image.onerror` 或采样为空。

### 4.6 散开 / 爆发 / 清除目标

| 按钮 | 行为 | 源码 |
| ---- | ---- | ---- |
| `散开粒子` | `scatter()`：**清目标** + 把所有粒子瞬移到中心 ±12% 范围，给 ±3.5 的随机初速 → 从中心炸开再散逸 | `:226-229` |
| `粒子爆发` | `explode(画布中心)`：所有粒子受径向冲量（力 = `(2+rand*5) * min(1.8, 230/距离)`），并在爆点画一圈扩散光环 | `:230-233` |
| `清除目标` | `clearTarget()`：清目标并**回到聚合前的风格**（`previousStyle`），重新随机分布 | `:189` |

**散开 vs 清除目标**：`散开` 是一次性视觉动作（也清目标，但会保留散开的动量）；`清除目标` 是干净地回到原风格初始态。

**爆发是暂态的**：`vx/vy` 每帧 ×0.91 衰减（`:293`），约 1 秒内粒子被「拉回」该风格的解析位置。所有风格的位置都是 `t` 的纯函数（不是积分出来的），所以粒子永远不会真正飞走 —— 这是本引擎的一个架构特点，也是它稳定的原因。

### 4.7 暂停与全屏

- `Ⅱ` / `▶` / `空格`：暂停时 `_frame` 直接 `return`，**画面定格在最后一帧**（不清屏）。时间 `t` 停止累加，恢复后从原处继续，不会跳变。
- `⛶` / `F`：对 `#canvasWrap` 请求原生全屏；不支持 `requestFullscreen` 时降级为加 `.fullscreen-stage` 类（`position:fixed;inset:0`）。`fullscreenchange` 后 80ms 调 `engine.resize()` 重算位图（`:436`）。

**标签页可见性**：切走时自动暂停渲染并停掉 FPS 循环，切回自动恢复 + 重新 resize（`:469-483`）。

> ⚠️ **已知 bug：你手动暂停的状态会在切标签页后丢失。** `visibilitychange` 用 `!engine._userPaused` 判断是否要接管暂停，但**代码里从未给 `_userPaused` 赋过值**（全文只在 `:473` 读它）。因此：手动暂停 → 切到别的标签 → 切回来 → **动画自己又开始播了**。同理，系统开启「减弱动态效果」时页面启动即暂停（`:495`），切一次标签页也会开始播放。修法见第 10 章②。

### 4.8 保存 / 分享 / 导入

**`保存当前场景`** → 写 `localStorage['neon-particle-studio-preset']`，内容是 `getConfig()` + `savedAt`。成功 toast `已保存在本浏览器；下次打开仍可恢复`；被拒（无痕/配额）→ `浏览器不允许本地保存，请使用"导出配置"`。

**下次打开的加载优先级**（`:397-405`）：

1. URL 里含 `count`/`speed`/`size`/`glow`/`color`/`background` **任一** → **用 URL 参数**（忽略 localStorage）；
2. 否则读 localStorage，且**只有 `saved.style` 是合法的 12 风格之一**才应用；
3. 都没有 → 内置默认。

**`复制分享链接`** → 把 9 个参数写进当前 URL 的 query 并复制。

- `file://` 下 `navigator.clipboard` 常不可用 → 自动降级为 `window.prompt` 让你手动复制（`:394`）。
- **`style === 'target'` 时被替换成 `network`**（`:392`）→ **文字和图片聚合无法通过链接分享**，只能分享参数。
- 接收方打开链接时，所有数值都经 `clampParam` 钳制到 UI 范围，非法的 color/background/interaction 回落到默认（`:399-401`）→ **坏链接不会让页面崩**，只会退回默认值。

**`导入配置`** → 选 JSON 文件，逐字段白名单校验（`:447-449`）：不在 12 风格内的 style → `network`；color/background/interaction 走枚举白名单；4 个数值走 `clampParam`。解析失败 → `配置文件无法解析，请选择有效的粒子配置 JSON`。**多余字段被忽略，缺字段自动补默认** → 手写一个只有 `{"style":"aurora","glow":90}` 的 JSON 也能用。

导入会 `applyScene` → **同样会清掉当前聚合目标**。

### 4.9 重置

`重置 ↺` / `R`：8 项参数回默认 + `clearTarget()` + `setStyle('network')` + 输入框回到 `PARTICLE` + toast `已恢复默认参数`。**无确认、无撤销**。

> 不会清除 localStorage 里已保存的场景。重置后如果又点了保存，才会覆盖旧存档。

### 4.10 导出嵌入代码

`嵌入代码` → 下载 `particle-embed-snippet.html.txt`（`text/plain`），内容是一段带注释的 HTML：

```html
<!-- 1. 把 particle.js 和 particle.css 放到你的网站目录 -->
<link rel="stylesheet" href="particle.css">
<div class="particle-hero" style="position:relative;height:500px;overflow:hidden;background:#060916">
  <canvas id="site-particles" style="width:100%;height:100%;display:block"></canvas>
</div>
<script src="particle.js"></script>
<script>
  const particles = new ParticleEngine(document.getElementById('site-particles'), {
    style: 'aurora', // network, wave, vortex, galaxy, fire, rain, ink, geometric, fluid, aurora, orbit, matrix
    count: 900, speed: 0.8, size: 2.1,
    glow: 95, color: 'rainbow', background: 'dark', interaction: 'repel', trail: 96
  });
  // 交互：particles.setStyle('aurora'); particles.gatherText('HELLO'); particles.explode();
</script>
```

参数**全部来自当前画布状态**，`target` 风格降级为 `network`。

> ⚠️ **这段代码开箱不能用**：它引用的 `particle.js` 和 `particle.css` 在本仓库中不存在。实际做法见 FAQ 和第 10 章④ —— 你需要自己把本页 `<script>` 里的第一个 IIFE（`:113-343`，即 `ParticleEngine` 类）抽成 `particle.js`。这是本页最需要知道的一个坑。

## 7. 数据与隐私

### 7.1 网络

| 请求 | 地址 | 用途 | 可否离线 |
| ---- | ---- | ---- | ---- |
| 字体 | `@import url('https://fonts.googleapis.com/css2?family=DM+Mono…Manrope…Noto+Sans+SC…')`（`:7`） | 界面字体 | **可离线**，回落 `system-ui` / 等宽后备字体，功能零影响 |

**除字体外零网络请求**：全文无 `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` / 统计脚本；无 `<script src>`；无 favicon。

**聚合的图片确实不上传** —— 上传区的「本地采样，不上传」这句话（`:97`、`:103`）**与源码一致**：`createObjectURL` → `Image` → `drawImage` 到离屏 canvas → `getImageData`，全程内存内操作，`finally` 立即 `revokeObjectURL`。

**与根 README 的关系**：README `:51` 说「个别页面通过 `<link>` 引入 Google Fonts 字体（需联网），其余功能完全离线可用」。本页用的是 CSS `@import` 而不是 `<link>`，效果与结论一致（联网取字体、离线可用），**表述基本吻合**，仅引入方式不同。

### 7.2 存储

| 项 | 值 |
| ---- | ---- |
| 存储方式 | `localStorage`（**不用** IndexedDB / sessionStorage / Cookie / Service Worker） |
| 键名 | **`neon-particle-studio-preset`**（`:387`、`:404`） |
| 内容 | 8 个参数 + `styleTitle` + `particleCount` + `savedAt`。**不含文字内容、不含图片数据** |
| 写入时机 | **仅**手动点 `保存当前场景`（不像储物间导航那样每次改动自动存） |
| 失败处理 | `try/catch` + 明确 toast 提示改用导出配置（`:388`） |
| 清除 | **界面上没有任何清除入口**，也没有「不保存」开关。要清只能 F12 手动删键 |

**重要推论**：

- **只有 1 个存档槽**，再点一次保存就覆盖。想存多套配色请用 `导出配置` 存成多个 JSON 文件。
- 存档**不包含聚合的文字/图片**（`getConfig` 只读 `this.options`，`:339`）。保存时即便画面正拼着 `HELLO`，下次打开也只有参数没有文字。
- 同理，分享链接也不含聚合内容。
- 域名维度隔离：`file://` 与 `http://localhost` 是两个不同来源，存档互不相通。

### 7.3 其它

- **剪贴板**：只写不读（`navigator.clipboard.writeText`），内容是分享 URL。
- **不使用** `navigator.geolocation`、摄像头、麦克风、`crypto`、`navigator.share`。
- **无埋点、无分析、无广告 SDK。**
- **无 XSS 面**：所有用户输入（文字、分类名、JSON 字段）都经 `textContent` 或数值/枚举白名单处理，**没有一处把用户输入拼进 `innerHTML`**。图片文件名、JSON 任意字段都不可执行。

## 8. 常见问题（FAQ）

**点了「嵌入代码」，粘到自己网站上一片空白。**

因为导出的片段引用了 `particle.js` 和 `particle.css`，**这两个文件仓库里没有**。真正需要的引擎代码就在本页 `<script>` 的第一个 IIFE 里（`:113-343`）。最小可用做法：把 `:113-343` 那段（从 `(function (global) {` 到 `})(window);`）另存为 `particle.js`，`particle.css` 可以不引（它只影响控制台外观，画布本身不依赖 CSS 类）。详见第 10 章④。

**暂停动画后，右上角还是显示 60 FPS。**

不是 bug 也不是没暂停。FPS 由独立的统计循环算（`:457-467`），渲染循环暂停不影响它。判断是否真暂停看两点：画面是否定格、按钮是否变成 `▶`。

**我手动暂停了，切到别的标签页再切回来，它又自己动了。**

确认的 bug。`visibilitychange` 检查 `!engine._userPaused` 来决定是否接管暂停，但 `_userPaused` 从未被赋值（`:473`）→ 你的手动暂停被误判为「不是用户意图」，切回时被覆盖。临时规避：切回来后再按一次 `空格`。彻底修法见第 10 章②。

**按 `R` 直接把我调了半天的参数清空了。**

`R` 无确认弹窗、无撤销。想保住成果：调完先 `复制分享链接` 或 `导出配置`，再随便试。

**鼠标力场没反应。**

按顺序排查：

1. **当前是不是 `炽热火焰` / `赛博雨幕` / `数字矩阵`？** 这三种风格源码里显式排除力场（`:287`）。
2. **是不是在文字/图片聚合模式？** 也不生效（同上）。
3. 力场下拉是否被切到了 `关闭互动`。
4. 鼠标必须**在画布内**（`pointerleave` 会把坐标移到画布外，`:145`）。
5. 触屏设备需要**按住**才有 `pointerdown`，纯滑动在某些浏览器上 `pointermove` 不触发。

**上传 Logo 后变成一整块矩形点阵，看不出形状。**

说明**背景剔除没触发**。它要求四角都几乎不透明**且**三通道极差 < 22（`:211-212`）。风景照、渐变底、带阴影的截图都不满足 → 整张图均匀采样。

解决：① 换成透明背景 PNG（最可靠）；② 用纯色底且底色均匀；③ 自己先把主体抠出来再传。

**上传 Logo 后什么都不显示 / 提示未采样到有效像素。**

- 主体颜色和背景色太接近（欧氏距离 < 42 就被当背景剔了）；
- 图片是全透明或极淡；
- SVG 没写 `width`/`height`，`Image` 尺寸为 0；
- 提示 `无法读取这张图片` = 浏览器解不了这个格式。

**分享链接发给同事，他打开是默认效果。**

检查：

1. 链接里**至少要含 `count`/`speed`/`size`/`glow`/`color`/`background` 之一**，否则页面不认为这是分享链接，会转而去读**他自己浏览器里的存档**（`:397-405`）→ 看起来就是「我的效果没了」。
2. 聊天软件/IM 是否把 URL query 截断了（常见于富文本粘贴）。
3. 若你当时处于**文字/图片聚合**状态，`style` 会被强制写成 `network`（`:392`），聚合内容本来就不分享。

**保存的场景下次打开没恢复。**

三个原因：① 你后来用了带参数的 URL 打开（URL 优先级高于存档）；② 存档的 `style` 字段不在 12 风格白名单里 → 整份被忽略；③ 换了打开方式（`file://` vs `localhost`）或换了浏览器。另外**界面上没有清除存档的按钮**，要清只能手动删 localStorage 键。

**粒子数量拉到 1600 后很卡。**

正常。`network` / `geometric` 是 O(n × 15) 连线（每个粒子只和后面 14 个比距离，`:298`），已经优化过；但 `shadowBlur` 是主要开销。降到 800 或把**发光强度调到 0** 会明显好转（发光为 0 时 `shadowBlur` 直接关闭，`:310`）。另外画布 DPR 上限是 2（`:153`），4K 屏上开销仍不小。

**能不能导出成视频或图片？**

不能，界面无此功能。临时方案：屏幕录制（OBS / Win+G）；单帧用控制台 `window.particleStudio.canvas.toDataURL()`。想要透明视频素材，把背景设为 `透明背景` + 拖尾拉到 `100%`（走 `clearRect`，`:247`），再录制成带 alpha 的格式。

**为什么 `拖尾` 拉高之后画面糊成一片？**

拖尾的语义是「每帧残留量」，100% = 每帧只覆盖 4% 背景（`:251`）。粒子尺寸大 + 发光高 + 速度快 + 拖尾 100，四个叠起来必然糊。常规观感建议 90–96。

**手机能用吗？**

能。响应式在 720px 断点变单栏，画布用 pointer 事件（触屏 `pointerdown/move` 有效）。但注意：① 触屏没有 hover，力场只在手指按住时生效；② 移动端 DPR × 高粒子数容易掉帧，建议数量降到 400 以下。

**减弱动态效果（系统设置）会怎样？**

页面**启动即暂停**并显示 `▶`（`:495`），尊重系统偏好。但如前所述，切一次标签页会覆盖这个状态。

**粒子数量能不能超过 1600？**

UI 不行（滑块 max 1600，URL/JSON 也钳到 1600）。引擎内部允许到 1800（`:160`），所以控制台可以：`window.particleStudio.setCount(1800)`。同理可下探到 80。**但刷新就没了**，且不进存档。

**能不能记住每个风格各自的参数？**

不能。参数是全局一份，切风格只换运动方程。要「A 风格用这套参数、B 风格用那套」，只能存成多个 JSON 文件按需导入。

## 9. 技术实现要点（开发者）

**结构**：502 行。`<style>` `:6-32`（主体全部压缩在第 9 行单行内，媒体查询 `:10-13`，预设色板 `:16-30`），DOM `:34-111`，**两个独立 `<script>`**：`:112-344` 是引擎（IIFE，导出 `window.ParticleEngine`），`:345-500` 是 UI 装配（IIFE，导出 `window.particleStudio`）。

**这是全项目唯一「引擎与 UI 分离」的文件**，`ParticleEngine` 可独立复用 —— 也正是「导出嵌入代码」这个功能成立的前提。

**用到的 Web API**：Canvas 2D（离屏采样时传 `{ willReadFrequently: true }`，`:192`、`:202`）、`requestAnimationFrame`、`ResizeObserver`（不支持时回落 `window.resize`，`:139-140`）、Pointer Events、`navigator.clipboard`、`Element.requestFullscreen` + `fullscreenchange`、`URL.createObjectURL`、`Blob` 下载、`URLSearchParams`、`matchMedia('(prefers-reduced-motion: reduce)')`、`localStorage`、`document.hidden` / `visibilitychange`、`devicePixelRatio`（钳到 2）。

**不使用**：`fetch`、`IndexedDB`、`crypto`、WebGL、Web Workers、`OffscreenCanvas`、任何框架或第三方库。

### 架构核心：位置是 `t` 的纯函数

这是理解整个引擎的关键。除 `target` 模式外，**粒子坐标不由速度积分而来**，而是每帧由解析式重算：

```js
let x = p.bx, y = p.by;          // bx/by 是随机基准位，只在重置/resize 时变
if (style === 'wave')  y = h*(.5+(ny-.5)*.12) + Math.sin(nx*8.5 + t*1.3 + …) …
if (style === 'fire')  y = h - ((p.by + t*(45+95*p.depth)) % h);
// …每种风格一个公式分支（:261-286）
```

`p.depth`（0.2–1）做视差分层，`p.phase` 做随机相位，`p.arm`（0–4）做旋臂/环带分组。

**由此带来的三个行为**：

1. **爆发能自动恢复**：`explode` 给的 `vx/vy` 只是每帧额外偏移 `x += vx*3`，且 ×0.91 衰减（`:293`）→ 扰动会自然消退，粒子永远回到解析轨迹上。粒子不会真正飞丢。
2. **`resize` 需要按比例缩放 `bx/by`**（`:156`），否则窗口变化后画面会挤在一角。
3. **暂停 = 冻结 `t`**，恢复不跳帧。

### 渲染管线（`_frame`，`:241-321`）

每帧 7 步：

1. `dt` 钳制到 0.001–0.04s（`:244`）→ 掉帧不会导致粒子瞬移；`t += dt * speed`。
2. **拖尾层**：非透明背景用 `rgba(bg, (100-trail)/100)` 填全屏；透明背景按 trail 是否 100 分流 `clearRect` / `destination-out`（`:246-254`）。
3. **位置计算**：遍历所有粒子，按 style 分支算 `(x,y)` → 施加力场（半径 150px 圆形，力度按下放分 19 / 52）→ 施加爆发衰减 → 存进 `pos[]`。
4. **连线层**（仅 network/geometric）：`for i` × `for j in [i+1, i+15)`，距离 < 阈值（network 118 / geometric 94）则画线，透明度随距离衰减（`:296-302`）。
5. **环带层**（仅 vortex/orbit）：画 3 / 4 个旋转椭圆。
6. **粒子层**：`globalCompositeOperation = 'lighter'`（加色混合，`:255`）→ 按风格分派绘制形状：`rain` 画竖条 `fillRect`、`matrix` `fillText` 画 `0`/`1` 字符（0.6% 概率翻转）、`fire`/`target` 用调整后的半径、其余画圆。坐标非有限值跳过（`:307`）。
7. **柔光带**（仅 aurora/wave/ink/fluid，`_drawSoftRibbons` `:322-337`）：3–5 条 90 段正弦折线，`lineWidth` 5–27，带 shadowBlur。然后画爆发光环、衰减、过滤掉 `life<=0` 的。

**配色**（`_palette`，`:235-240`）：5 套 HSL 色相数组 + `mono` 特殊处理（饱和度 10%、亮度 82%、色相固定 205）。两个强制覆盖：

- `style === 'fire'` → **忽略 color 选择**，恒用 `[4,12,24,32,42]` 暖色；
- `style === 'ink'` **或** `color === 'mono'` → 色相固定 205。

所以「炽热火焰 + 冰川青蓝」出来的还是橙红色，这不是 bug 是设计。

### UI 层要点

- **状态单一来源是 `engine.options`**，滑块/output 只是镜像。改 `options` 不会自动同步 UI 显示（例：控制台执行 `particleStudio.options.glow=0`，滑块仍显示 70）。
- **`applyScene` 是唯一的全量同步函数**（`:371-381`）：清目标 → 设参数 → 回写全部控件 → 改画布底色 → 高亮预设。任何「批量设置参数」的需求都应该走它，别自己一个个赋值。
- **`updateStyleUI`**（`:356-360`）只改风格按钮高亮、`#styleTitle`、`#modeTag`，不碰参数。
- **`clampParam(value,min,max,fallback)`**（`:406`）是所有外部输入的统一入口，URL 与 JSON 共用。
- 事件绑定：12 个风格按钮 + 6 个预设按钮（`forEach` 批量）、11 个控件监听、8 个功能按钮、`document.keydown`、`fullscreenchange`、`visibilitychange`、`beforeunload`。
- `window.particleStudio = engine`（`:497`）→ 控制台可直接调 API 调试，这是二次开发最省事的入口。
- `beforeunload` 里 `destroy()`（`:496`），单页场景下不是必需，但让 `ParticleEngine` 可被干净地反复创建/销毁。

### 性能特征

- 位置计算纯数学、无物理积分、无对象分配（`pos[]` 每帧新建 `{x,y,p}` 数组是唯一的分配点，`:255`）。
- 连线是**近邻窗口**（15 个）而非全对，1600 粒子时约 2.4 万次距离计算，现代机器可承受。
- 最大开销是 `shadowBlur`（每个粒子一次），发光调到 0 通常能翻倍帧率。
- 标签页隐藏时渲染停摆，不耗电。

## 10. 二次修改指引（开发者）

按需求频率排序，每条都给了确切行号。

**① 加一种风格（最常见）**

三步，每步都在不同位置，**漏一步就表现为「点了没反应」**：

```js
// 1. :125-129 STYLE_TITLES 加一项 —— 这是合法 style 白名单，不加会被 setStyle 拒绝
dna: '双螺旋'

// 2. :261-286 的 if/else 链里加分支（照抄现有写法，用 p.bx/p.by/p.depth/p.phase/t/w/h）
} else if (style === 'dna') {
  const k = (p.by / this.h) * TAU * 2 + t * .5;
  const strand = p.arm % 2 ? 1 : -1;
  x = w / 2 + Math.cos(k) * w * .18 * strand;
  y = (p.by + t * 30) % this.h;
}

// 3. DOM :56-69 加一个 <button class="style-choice" data-style="dna">…</button>
```

可选第 4 步：若要连线，把它加进 `:296` 的条件；若要柔光带，加进 `:318`；若要排除力场，加进 `:287`。

**② 修「手动暂停被标签页切换覆盖」的 bug（建议优先做）**

只需两处：

```js
// :430 pauseBtn 监听里，记录用户意图
$('pauseBtn').addEventListener('click', () => {
  const running = engine.pause();
  engine._userPaused = !running;                       // ← 加这行
  …
});

// :495 减弱动态效果的启动暂停，同样要标记
if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
  engine.pause(true); engine._userPaused = true;       // ← 加这句
  $('pauseBtn').textContent = '▶';
}
```

`:473` 的判断本身是对的，缺的只是赋值。改完 `visibilitychange` 就不会再抢走用户的暂停。

**③ 让「聚合的文字」也能进分享链接 / 存档**

`getConfig`（`:339`）目前只导 `options`。加一个字段即可让存档和 JSON 带上文字：

```js
getConfig() {
  return Object.assign({}, this.options, {
    styleTitle: STYLE_TITLES[this.options.style] || this.targetLabel || '目标图形',
    particleCount: this.particles.length,
    text: this.options.style === 'target' ? this.targetLabel : undefined  // ←
  });
}
```

再在 `applyScene` 之后（`:402`、`:404`、`:448` 三处调用点）补：

```js
if (cfg.text) { $('textInput').value = cfg.text; engine.gatherText(cfg.text); }
```

**分享链接**同理：`:392` 的参数表里加 `text: o.style === 'target' ? engine.targetLabel : ''`，接收侧 `params.get('text')` 后调用 `gatherText`。注意 URL 长度与中文编码（`searchParams.set` 会自动 percent-encode，一般没问题）。图片无法这样分享（数据量太大）。

**④ 把「嵌入代码」变成开箱可用**

两条路：

- **A（推荐，一次性）**：把 `:113-343` 整段另存为同目录 `particle.js`，导出的代码就能直接用。想更彻底就同时把引擎部分从本页删掉、改成 `<script src="particle.js">`（但会破坏「单文件」属性，需权衡）。
- **B（改导出内容）**：`:451-454` 的模板里把 `<link rel="stylesheet" href="particle.css">` 删掉（画布不依赖它），并把第 1 行注释改成实际可行的说明，避免误导使用者。

**⑤ 加「单帧导出 PNG」按钮（很实用，改动小）**

```js
$('snapshotBtn').addEventListener('click', () => {
  engine.canvas.toBlob(b => {
    const a = document.createElement('a');
    a.href = URL.createObjectURL(b);
    a.download = `particle-${Date.now()}.png`;
    a.click(); setTimeout(() => URL.revokeObjectURL(a.href), 900);
  }, 'image/png');
  showToast('已保存当前帧');
});
```

配合 `背景模式 = 透明背景` + `拖尾 = 100%` 可导出**真空透明底**素材。想导出高清大图需临时提高 DPR 重绘一帧再还原。

**⑥ 加撤销（防 `R` 误触）**

在 `applyScene`、`resetBtn`、`setStyle` 三个入口前压栈：

```js
let undoStack = [];
const snapshot = () => { undoStack.push(engine.getConfig()); if (undoStack.length > 30) undoStack.shift(); };
function undo() {
  const s = undoStack.pop();
  if (!s) return showToast('没有可撤销的操作');
  applyScene(Object.assign({ title: '撤销' }, s));
}
```

`:490` 的 `r` 改成 `if (e.ctrlKey || e.metaKey) { undo(); } else { snapshot(); $('resetBtn').click(); }`，并在 `:487` 的守卫里**允许** `Ctrl+Z` 穿透 INPUT 判断。

**⑦ 数量上限想真正放开到 1800**

四处要一起改，否则 UI 与引擎不一致：滑块 `max="1600"`（`:85`）、URL 钳制 `:399`、JSON 钳制 `:448`、以及 `clampParam` 调用点的 1600。引擎侧 `:160` 已经是 1800，不用动。想更省事就把这三处 1600 抽成常量。

**⑧ 新增一个主色调**

`:117-124` 的 `PALETTES` 加一组色相数组，`:89` 的 `<select>` 加一个 `<option>`，**并且**把新 key 加进两处枚举白名单：`:400`（URL 校验）和 `:448`（JSON 校验）。漏掉白名单的话，用分享链接/JSON 设这个颜色会被静默改回 `neon`。

**⑨ 力场半径与力度可调**

`:289` 一行里硬编码了 `150`（半径）、`52`（按下力度）、`19`（悬停力度）。抽成 `this.options.forceRadius / forceDown / forceHover` 即可做成滑块。记得同步 `:287` 的排除列表。

**⑩ 别踩的坑**

- **CSS 全部压在第 9 行**（超过 6000 字符），`replace_in_file` 时 `oldString` 极易撞车。改样式建议：在 `:31` 之后**新起一行追加覆盖规则**，而不是去动第 9 行。
- **`STYLE_TITLES` 同时是「显示名表」和「合法值白名单」**（`:171` 的 `if (!STYLE_TITLES[style]) return`、`:404`、`:447`）。想加一个不显示的内部风格（如 `target`），不能塞进这张表，否则它会出现在 `modeTag` 序号计算（`:359`）和导入白名单里。
- **`applyScene` 一定会 `clearTarget()`**（`:372`）。任何「应用参数但保留聚合」的需求都不能直接复用它，要么加参数开关，要么改用 `setOptions`。
- **6 个内置预设没定义 `interaction` / `trail`**，靠 `:373` 的 `|| 'repel'` / `== null ? 96` 兜底。你新加预设时若显式写了这两项，行为会变（这是好事，但和旧预设不一致，用户会疑惑）。
- **`_resetBase` 会重洗所有粒子**（`:177`）：`setStyle` 和 `clearTarget` 都调它。所以「切风格→切回来」画面完全变样是正常的，不是 bug。
- **`setCount` 在聚合态会重新 `_assignTargetCoords`**（`:163`）→ 拖数量滑块时，聚合图形会重新吸附，看着像抖了一下。不想要就在 `:163` 加 `if (!this.targets)` 守卫。
- **`gatherText` 的字号自适应循环有下限 24px**（`:195`），36 个字符时字号已经很小、点很密。长文本建议自己限制在 12 字内。
- **`gatherImage` 的背景剔除阈值是硬编码的**（`235` alpha、`22` 极差、`42` 距离，`:211-213`、`:219`）。对低对比度图想更宽容，就调大 `42`；对渐变底想生效，得改成「多区域采样」而不是只看四角。
- **`explode` 的 `flash` 字段被赋值但从未被读取**（`:232` 写、渲染段无引用）—— 无害的死代码，二次开发时可以顺手用它做受击高亮。
- **`#center-message` 元素和 `.center-message` 样式都在，但 JS 从不写它**（`:49`、CSS 第 9 行）。想加「暂停中」大字提示是现成的。
- **`window.particleStudio` 是全局可变引用**（`:497`）。若改成多次 `new ParticleEngine` 复用引擎，记得旧实例要 `destroy()`，否则前一个 rAF 循环不会停。
- **`fullscreen-stage` 降级类只处理了 `position:fixed`**，没锁 `overflow`；`requestFullscreen` 不可用时画布外层的 `overflow:hidden` 仍在（`.canvas-wrap`），一般够用，但自定义外层容器时注意。
