# Markdown 双栏编辑器

> 源文件：[../Markdown双栏编辑器.html](../Markdown双栏编辑器.html)
> 页面标题：`Markdown 双栏编辑器 · MD Studio`
> 一句话定位：左边写 Markdown，右边即时渲染，自带大纲、字数统计与 HTML 导出，零依赖零网络单文件
> 本文所有键位、取值、存储键与语法覆盖范围均基于当前仓库源码核对。

## 1. 工具简介

写 Markdown 的场景里，最常用的两件事是「看渲染效果」和「导出成能发出去的东西」。常见的做法是打开在线编辑器——于是文档内容、甚至粘贴进去的会议纪要，都先经过了一台不知道会不会留存的服务器。

本工具把这些收进一个单 HTML 文件：**零网络请求**，无外部 CSS / JS / 字体，`file://` 双击即用。左侧输入，右侧按 CommonMark + GFM 子集即时渲染，正文与偏好只写进本机 `localStorage`。

四类能力：

| 类别 | 包含 | 说明 |
| --- | --- | --- |
| **编辑** | 双栏 / 单栏切换、工具栏插入、列表自动续行、Tab 缩进 | 工具栏走 `execCommand`，保留 `Ctrl+Z` 撤销栈 |
| **渲染** | 标题、列表、任务列表、表格、引用、围栏代码块、行内强调 | 输入后 90 ms 防抖渲染，实测 0.7 ms 完成 |
| **导航** | 大纲、标题自动编号、点击跳转 | 扫描渲染结果的 `h1`~`h6` 生成目录 |
| **导出** | 下载 `.md`、导出独立 `.html`、打印成 PDF、复制 HTML | 导出文件内嵌样式，可单独打开 |

**三个别处不容易一次做到的点**

- **工具栏操作不摧毁撤销栈**。加粗、插表格这类操作如果直接改 `textarea.value`，浏览器会把撤销历史整条清空，用户按 `Ctrl+Z` 就一路回到空白。本工具统一走 `document.execCommand('insertText')`，**每一步工具栏操作都是可撤销的**，仅在 `execCommand` 不可用时降级为直接赋值。
- **列表与 Tab 按 Markdown 的语义处理**。在列表项末尾回车会自动续上 `- ` / `2. ` / `- [ ] `；在空列表项上回车会**退出列表**而不是继续加空项；`Tab` 在单行插入两个空格，在选中多行时整体缩进，`Shift+Tab` 反缩进。
- **预览样式与导出样式同源**。`cssRules(scope, palette)` 生成一份规则，预览时套 `#mdRoot[data-theme="dark"]` 作用域，导出时套 `.md`，所以**屏幕上看到的排版和导出文件里的排版是同一份 CSS**，不会出现「预览好看、导出跑版」。

**适合谁用**

- 要写 README、接口文档、周报，想边写边看效果又不想开在线编辑器
- 手上有 `.md` 文件想快速转成一个能直接发给别人的 `.html`
- 在意隐私，不接受把未发布的文档传给陌生网站
- 需要一份能离线用、能自己改的工具

**什么时候不该用它**

- **要出版级排版**：不是完整 CommonMark 实现，嵌套强调、列表与代码块的极端交错、惰性续行等边角行为可能和参考实现有差异。要严格合规请用 `markdown-it` / `cmark`。
- **要脚注、定义列表、数学公式、Mermaid 图表**：均不支持，写了会原样显示成文本。
- **要多标签页、版本历史、协同编辑**：单文档工具，只保留最新一份自动存档。
- **要打开带图片附件的文档**：图片按 URL 加载，不做内嵌打包，离线环境下外链图片不显示。

## 2. 快速开始

1. **双击 `Markdown双栏编辑器.html`**。单文件，无同级依赖。
2. 首次打开会载入一段示例文档，右侧已渲染好。直接全选删掉即可开始写。
3. 左侧输入。右侧在停止输入 **90 ms** 后刷新，标题栏徽标显示本次渲染耗时，形如 `渲染 0.7 ms · 零上传`。
4. 需要格式时点工具栏：`B` 加粗、`</>` 行内代码、`H1`~`H3` 标题、`• 列表`、`1. 列表`、`☑ 任务`、`> 引用`、`链接`、`图片`、`表格`、`代码块`、`分隔线`。
5. 想看目录就点 **大纲**，右侧多出一列，点击标题会平滑滚动到预览里的对应位置并高亮一下。
6. 写完点 **保存 .md** 下载源文件，或 **导出 HTML** 得到可单独打开的网页。想直接出 PDF 就点 **打印**。

## 3. 界面与功能分区

自上而下五层：

```
┌─ 标题栏 ── 渲染耗时 / 零上传徽标 ─────────────┐
├─ 工具栏 ── 文件操作 │ 行内格式 │ 标题 │ 列表 │ 插入 │ 视图 ─┤
├─ 选项条 ── 同步滚动 / 允许原始 HTML / 自动编号 / 主题 ─────┤
├─ 主体 ── [Markdown 源] │ [预览] │ [大纲(可折叠)] ─────────┤
└─ 状态栏 ── 光标位置 / 字数 / 阅读时长 / 保存状态 ─────────┘
```

### 3.1 标题栏

左侧渐变方块 `M` 与工具名。右侧徽标两段信息：本次渲染耗时（毫秒，保留一位小数）、`零上传`。

### 3.2 工具栏

| 分组 | 按钮 | 行为 |
| --- | --- | --- |
| 文件 | 新建 / 打开 / 保存 `.md` / 导出 HTML / 打印 | 见 4.1 |
| 行内 | `B` `I` `S` `</>` | 加粗、斜体、删除线、行内代码 |
| 标题 | `H1` `H2` `H3` | 给选中行加 `#` 前缀 |
| 列表 | `• 列表` `1. 列表` `☑ 任务` `> 引用` | 给选中行加对应前缀 |
| 插入 | 链接 / 图片 / 表格 / 代码块 / 分隔线 | 见 4.2 |
| 视图 | 双栏 / 编辑 / 预览 / 大纲 / 帮助 | 见 4.4 |

当前生效的视图按钮会高亮（边框变蓝）。

### 3.3 选项条

| 控件 | 默认 | 作用 |
| --- | --- | --- |
| **同步滚动** | 开 | 编辑区与预览按滚动比例双向联动 |
| **允许原始 HTML** | 关 | 关闭时 `<` `>` 全部转义，不存在脚本注入 |
| **标题自动编号** | 开 | 给标题加 `1` / `1.1` / `1.2.1` 层级编号 |
| **预览主题** | 暗色 | 暗色 / 亮色，只影响预览区与导出文件 |

### 3.4 主体三栏

- **Markdown 源**：`textarea`，等宽字体，行高 1.85，`Tab` 宽度按两个空格算。右上角显示当前文件名。
- **预览**：渲染结果容器 `#mdRoot`，最大宽度 820 px 居中。右上角显示渲染耗时。
- **大纲**：默认隐藏，点 **大纲** 展开，宽 218 px。列出全部标题，按级别缩进；无标题时给出引导文案。

### 3.5 状态栏

| 位置 | 内容 |
| --- | --- |
| 左 | `行 N, 列 M`，随光标移动实时更新 |
| 左 | `N 字 · N 字符 · N 行 · N 段`，字数 = 中日韩字符数 + 拉丁词数 |
| 左 | `阅读约 N 分钟`，按中文 400 字/分、英文 200 词/分估算 |
| 右 | 保存状态：绿色 `已保存` / 红色 `未保存` / 红字 `保存失败（超出本机配额）` |

## 4. 功能操作详解

### 4.1 文件操作

- **新建**（`Ctrl+N`）：清空编辑区。当前内容非空且不是示例时会先弹确认框，提示「内容已自动保存在本机，但仍建议先保存 .md」。
- **打开**（`Ctrl+O`）：文件选择框，接受 `.md` / `.markdown` / `.mdown` / `.txt`。也可以直接把文件**拖进窗口**，拖入时全屏显示虚线遮罩。文件超过 **2 MB** 直接拒绝并提示。
- **保存 .md**（`Ctrl+S`）：下载 `<文件名>.md`，内容前加 UTF-8 BOM，Windows 记事本打开不乱码。
- **导出 HTML**（`Ctrl+Shift+S`）：生成内嵌样式的独立 HTML。标题取文档第一个 `h1`/`h2`/`h3` 的文本，没有则用文件名。
- **打印**（`Ctrl+P`）：走 `window.print()`。打印样式表已隐藏标题栏、工具栏、选项条、编辑区、大纲与状态栏，只输出预览内容，并强制白底。

文件名规则集中在 `safeBase()`：去掉扩展名、把 `\ / : * ? " < > |` 换成下划线、截断到 80 字符。所以 `我的文档.md` 保存后是 `我的文档.md`，`a/b:c.md` 保存后是 `a_b_c.md`。

### 4.2 格式插入

| 按钮 | 选中文本时的结果 | 未选中时的结果 |
| --- | --- | --- |
| `B` | `**选中**` | `**粗体**` 并选中「粗体」 |
| `I` | `*选中*` | `*斜体*` 并选中「斜体」 |
| `S` | `~~选中~~` | `~~删除线~~` |
| `</>` | `` `选中` `` | `` `代码` `` |
| 链接 | `[选中](https://example.com)` | `[链接文字](https://example.com)` |
| 图片 | `![选中](https://example.com/a.png)` | `![图片说明](...)` |
| 代码块 | 把选中内容整体包进 ```` ``` ```` | 插入含占位文本的空代码块 |
| 表格 | 插入 3 列 3 行（含表头）的 GFM 表格骨架 | 同左 |
| 分隔线 | 插入 `---` | 同左 |

标题与列表按钮作用于**光标所在的整行**（选中多行时作用于每一行）。`1. 列表` 会按行号递增编号。

### 4.3 输入增强

- **列表续行**：在 `- item` / `1. item` / `- [ ] item` 行末回车，自动补上同级标记，有序列表编号 +1。
- **退出列表**：在**空的**列表项上回车，会删掉该标记并退出列表，这是 Markdown 编辑器的通用手感。
- **Tab / Shift+Tab**：单行时插入 / 删除两个空格；选中跨多行时整体缩进 / 反缩进。
- **硬换行**：行尾两个空格或一个反斜杠，渲染为 `<br>`。
- **反斜杠转义**：`\*` `\`` `\_` `\\` 等 20 个标点前加反斜杠即输出字面字符。

### 4.4 视图与大纲

三个视图按钮互斥，`Ctrl+Enter` 循环切换「双栏 → 预览 → 编辑 → 双栏」。

- **双栏**：左右各占一半，同步滚动生效。
- **编辑**：只留编辑区，适合长文专注输入。此时预览不渲染以省 CPU。
- **预览**：只留预览区，适合通读校对。

**大纲**是独立开关，与视图正交。点击条目会 `scrollTo` 到对应标题位置（偏移 8 px），并把标题背景闪一下蓝色。开启「标题自动编号」时，大纲条目也带编号。

窗口宽度小于 900 px 时，主体自动改为上下堆叠，大纲变为底部横向区域。

## 7. 数据与隐私

### 7.1 网络

**零网络请求。** 页面无 `<link>`、无外部 `<script>`、无 `@font-face`、无 `fetch` / `XMLHttpRequest` / `WebSocket`。可以在浏览器开发者工具的 Network 面板确认：除了文档自身，没有任何请求。

唯一的例外是**你在文档里写的图片与外链**——`![](https://…)` 会按地址加载，这是 Markdown 的固有语义，不是工具在联网。离线环境下这些图不显示，属正常。

### 7.2 本地存储

两个 `localStorage` 键，都在 `file://` 下可用：

| 键 | 内容 | 写入时机 |
| --- | --- | --- |
| `mdstudio.doc.v1` | `{ text, name, at }`，正文、文件名、时间戳 | 停止输入 500 ms 后 |
| `mdstudio.prefs.v1` | `{ view, sync, rawHtml, autoNum, theme, outline, fileName }` | 每次改选项时 |

正文上限 **2 MB**（`DOC_LIMIT`）。超过后输入框仍可继续输入，但会在提示条告警，且 `localStorage` 写入可能因配额超限失败——此时状态栏显示红字 `保存失败（超出本机配额）`，不会假装保存成功。

隐私模式 / 禁用存储时，`try/catch` 静默降级：编辑与渲染全部正常，只是关掉页面后内容不保留。

### 7.3 安全

- **默认转义一切 HTML**。渲染管线的第 9 步统一 `esc()`，`<script>alert(1)</script>` 输出为可见的文本，不会执行。
- **原始 HTML 是显式开关**。勾选「允许原始 HTML」后，文档里的标签会原样进入预览与导出文件，此时脚本可以执行。这是刻意的取舍：需要嵌入 `<video>` / `<iframe>` 的用户必须有这个口子，但**只应对自己信任的内容开启**。界面上勾选时会弹一次 toast 明确提示。
- 链接统一带 `rel="noopener noreferrer"`，避免 `window.opener` 反向控制。

## 8. 常见问题（FAQ）

**Q：为什么 `**粗体**` 有时候没生效？**
A：`**` 后面紧跟空白、或 `**` 前面是空白时，按 CommonMark 的规则不算强调。`** 粗 **` 不会加粗，要写成 `**粗**`。

**Q：为什么 `snake_case_name` 里的下划线没变成斜体？**
A：这是刻意的。`_` 强调要求前后不是单词字符，`snake_case` 因此安全。要斜体请用 `*`。

**Q：粘贴一大段内容后预览卡了？**
A：渲染是同步的，9 万字文档实测约 64 ms，正常写作感知不到。如果粘贴了数 MB 的文本，每次输入都会触发全量重渲染。建议拆文件，或先切到「编辑」视图写完再切回。

**Q：导出的 HTML 里图片为什么不显示？**
A：导出只内嵌样式，不内嵌图片。图片仍是原 URL，换成离线环境就打不开。要打包图片请自行转 base64 后写进 `![]()`。

**Q：打印出来的 PDF 是黑底吗？**
A：不是。打印样式表已强制预览区白底、隐藏所有工具栏。如果仍是暗色，检查浏览器「打印背景图形」选项是否被强制开启。

**Q：`Ctrl+S` 为什么不是保存到原文件？**
A：浏览器沙箱不允许网页静默写本地文件，`Ctrl+S` 只能触发下载。想直接覆盖原文件，请在浏览器弹出的下载对话框中选同一目录并确认替换。

**Q：自动保存的内容在哪？怎么清掉？**
A：在 `localStorage` 的 `mdstudio.doc.v1`。清空方式：在编辑区全选删除后等半秒，或打开开发者工具执行 `localStorage.removeItem('mdstudio.doc.v1')`。

**Q：勾了「允许原始 HTML」，导出文件会带脚本吗？**
A：会。导出的 HTML 直接取渲染结果的 `innerHTML`，所以原始 HTML 里的 `<script>` 会进入导出文件。这是开关的预期行为，导出前请自行确认内容。

**Q：支持中文标点的自动配对、拼写检查吗？**
A：拼写检查已关闭（`spellcheck="false"`），避免中文文档满屏红波浪线。不做自动配对，`**` 需要自己收尾。

## 9. 技术实现要点（开发者）

### 9.1 渲染管线

`render()` → `parseBlocks()`（块级）→ `inline()`（行内）→ `innerHTML` 赋值 → `numberHeadings()` → `buildOutline()` → `updateStats()`。

**块级解析**是逐行扫描 + 递归：`parseBlocks(lines, ctx)` 按顺序试探围栏代码块、ATX 标题、分隔线、引用、表格、列表、缩进代码块、Setext 标题，都不匹配则收段落。引用与列表会把自己的行剥掉前缀后**递归调用 `parseBlocks`**，这是嵌套能力的来源。`ctx.nextId()` 为每个标题生成 `h1` `h2` … 的稳定 id，供大纲跳转。

**行内解析**的关键是**占位符机制**。`inline()` 里所有会产出 HTML 的结构（行内代码、转义字符、自动链接、图片、链接、强调）都通过 `put(html)` 存进数组，原位留下 `\u0001<index>\u0001` 占位。等所有替换做完，第 9 步对剩余文本整体 `esc()`，最后把占位还原成真实 HTML。

这个顺序是必须的：如果先 `esc()` 再生成标签，标签会被转义成字面文本；如果先生成标签再 `esc()`，标签同样会被转义。占位符让「生成标签」与「转义纯文本」两件事互不干扰。还原循环跑 8 轮，因为强调可能嵌套三层，每层还原后可能暴露新的占位符。

**强调解析**由 `emph(text, put, depth)` 单独负责，按 `***` → `___` → `**` → `__` → `*` → `_` → `~~` 的顺序依次替换，每层内部递归调用自身（`depth` 上限 3），因此 `~~**粗删**~~` 能正确得到 `<del><strong>粗删</strong></del>`。

### 9.2 撤销栈保留

所有文本插入走 `insertText(rep)`：

```js
ta.focus();
if (!document.execCommand || !document.execCommand('insertText', false, rep)) {
  // 降级：直接拼字符串
}
```

`execCommand('insertText')` 会走浏览器的编辑命令通道，**产生一条可撤销的编辑记录**；而 `ta.value = ...` 会清空整个撤销栈。这是工具栏按钮手感好坏的分水岭。

`wrapSel()` 在无选中时插入占位文本并重新选中它，让用户可以直接开始打字覆盖；有选中时直接包裹，不改变选择范围语义。

### 9.3 渲染样式同源

```js
cssRules(scope, palette)   // 生成一组以 scope 为前缀的 CSS 规则
previewCss()               // 套 #mdRoot[data-theme="dark"|"light"]
exportCss()                // 套 .md，附 body 背景与字体
```

`boot()` 时把 `previewCss()` 写进 `<style id="mdStyle">`，预览即生效。导出时 `exportCss()` 用当前主题的 `palette()` 重新生成。改一处排版，预览与导出同时变。

### 9.4 滚动同步

按**滚动比例**映射而非按行号锚定：

```js
pv.scrollTop = (ta.scrollTop / (ta.scrollHeight - ta.clientHeight)) * (pv.scrollHeight - pv.clientHeight);
```

双向都绑，用 `syncing` 标志 + 40 ms 定时器防止互相触发形成抖动。比例映射的代价是「编辑区第 100 行」与「预览区第 100 行」未必严格对齐（两侧行高不同），换来的是实现简单且不会跳。

### 9.6 已知限制

- **不是完整 CommonMark**。惰性续行（列表项里缩进不足的续行）不处理；表格单元格内不支持换行；HTML 块级元素不解析为块。
- **渲染是同步全量**。每次输入都重解析整篇文档，不做增量。9.5 万字 64 ms 尚可接受，再大就该拆文件。
- **滚动同步按比例**，长文档里两侧可能逐渐错位，属设计取舍。
- **单文档**。没有多标签、没有版本历史，自动存档只留最新一份。

## 10. 二次修改指引（开发者）

### 10.1 加一种块级语法

1. 在 `parseBlocks()` 的 while 循环里，按**优先级**插入分支。顺序很重要：围栏代码块必须排在列表之前，否则 `- ` 开头的代码行会被当列表。
2. 若该语法会「吃掉多行」，像表格那样自己推进下标 `i`，并在循环末尾 `continue`。
3. 若需要递归（如引用、列表），剥掉前缀后调用 `parseBlocks(sub, ctx)`。
4. 若会产生标题，记得调用 `ctx.nextId()` 给 id，否则大纲跳转会失效。

### 10.2 加一种行内语法

1. 在 `inline()` 里加一步替换，**必须用 `put()` 包住生成的 HTML**，不能直接返回标签字符串——否则会被第 9 步的 `esc()` 转义。
2. 注意顺序：行内代码与反斜杠转义必须排在前面，否则代码里的语法会被二次处理。
3. 若语法可以嵌套，参照 `emph()` 的写法递归调用自身，并设 `depth` 上限防止栈溢出。

### 10.3 加一个工具栏按钮

1. 在工具栏 `.grp` 里加 `<button data-cmd="xxx">`。
2. 在 `runCmd()` 的 `switch` 里加 `case 'xxx':`。行内包裹用 `wrapSel(before, after, placeholder)`，整行前缀用 `prefixLines(fn)`，纯插入用 `insertText(str)`。
3. 事件绑定是自动的：`bindEvents()` 用 `querySelectorAll('[data-cmd]')` 统一挂 `onclick`，不用改绑定代码。
4. 需要快捷键就在 `bindEvents()` 的全局 `keydown` 里加一条，注意 `Ctrl+Shift+*` 的判断要排在 `Ctrl+*` 之前。

### 10.4 改预览与导出样式

只改 `cssRules(scope, palette)` 一个函数。它同时服务预览与导出，改一处两边同步。颜色从 `palette(theme)` 取，不要在规则里写死色值，否则亮 / 暗主题切换会失效。

### 10.5 注意事项

- **保持零依赖零网络**。不要引入 CDN 上的 `marked`、`highlight.js`、`KaTeX`——本工具的价值就在离线可用与可审计。真要高亮，得自己写一个几十行的 tokenizer。
- **不要绕过 `put()` 直接拼 HTML**。这是渲染管线唯一的安全边界，也是防止标签被转义的唯一机制。
- **不要用 `ta.value = ...` 做文本插入**。会清空撤销栈，用户按 `Ctrl+Z` 一路回到空白。统一走 `insertText()`。
- **`DOC_LIMIT` 与 `localStorage` 配额要一起看**。多数浏览器 `localStorage` 单域上限 5 MB，正文上限设 2 MB 是留了 JSON 包装与偏好的余量。调大之前先确认目标浏览器的配额。
- **原始 HTML 开关不能默认打开**。默认关闭是本工具的安全底线；打开时必须保留界面上的明确提示。
- 任何「渲染失败」的情况必须保留**可见的错误输出**（当前是红色 `渲染出错：…`），不能静默吞掉异常让预览区空白。
