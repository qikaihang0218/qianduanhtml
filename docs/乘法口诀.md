# 大九九乘法口诀 · 操作文档

> 源文件：[../乘法口诀.html](../乘法口诀.html)
> 页面标题：`大九九乘法口诀 · 1×1 至 19×19`
> 一句话定位：把 1×1 至 19×19 共 190 句乘法口诀做成可朗读、可竖排、可导出的一张「大字口诀表」。
>
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

## 1. 工具简介

它是一个**只读的学习页面**：页面加载时在浏览器内存里生成 19 个「乘段」（`1 乘段` 到 `19 乘段`，共 190 句，见 `乘法口诀.html:195-203`），然后提供四件事——看、听、调、导出。

适合谁用：

- 需要背「大九九」（超过小九九 9×9 范围）的学生与教师。
- 需要打印/张贴一张大九九口诀表的人（`存图` 与 `PDF` 两个出口）。
- 需要「听读跟背」的人：逐句中文朗读（把 `3×7=21` 读成「三乘七等于二十一」）＋当前句高亮居中。

**不适合的场景**：

- 它不是练习题/测验工具，没有出题、答题、随机抽查功能。
- 口诀内容是代码生成的固定数据，页面上**没有**增删句子或改范围的输入口（最大乘数写死为常量 `MAX = 19`，`乘法口诀.html:195`）。
- 朗读依赖操作系统已装中文语音包，没有语音包时可能无声（见第 8 章）。

## 2. 快速开始

1. 双击 `乘法口诀.html`，用 Chrome 或 Edge 打开。
2. 页面直接显示完整口诀表，无需任何导入或点击。
3. 点顶栏 `▶ 朗读` —— 从 `1×1=1` 开始逐句朗读，当前句变红加粗并自动滚动到屏幕中央，底部进度条与 `已读 / 190` 计数同步。
4. 想听某一段：直接**点击那一句**，即从该句开始往后朗读（`乘法口诀.html:238`）。
5. 想打印：点 `PDF`；想要一张图片海报：点 `存图`。

## 3. 界面与功能分区

页面只有三层：顶部工具栏、中间舞台、底部状态条（另有页面最顶一条 2px 的滚动进度线）。

**顶部工具栏**（`乘法口诀.html:155-183`，从左到右）：

| 控件 | id | 作用与取值 |
| ---- | ---- | ---- |
| 标题区 | — | `大九九乘法口诀` + 副标 `1×1 至 19×19 · 完整版` |
| `竖排` / `横排` | `btnOrient` | 切换排版方向。按钮文字随状态互换：当前是横排时显示「竖排」，反之显示「横排」（`:263`） |
| 字号滑块 | `fs` | `min=12` `max=38`，默认 `20`；右侧数字 `fsVal` 实时显示当前值 |
| `▶ 朗读` / `⏸ 暂停` / `▶ 继续` | `btnRead` | 三态按钮，见第 4 章 |
| `■ 停止` | `btnStop` | 彻底停止朗读并清除高亮与进度 |
| 语速滑块 | `rate` | `min=0.5` `max=1.8` `step=0.05`，默认 `1` |

**中间舞台**（`#stage` / `#text`，`:185`）：19 个 `section`，每段一个标题（`N 乘段`）加该段所有句子。横排时段落纵向排列、句内横向自适应换行；竖排时整段改为**右起竖列**（`flex-direction:row-reverse`，`:82`），段落间用左侧虚线分隔。

**底部状态条**（`:187-191`）：左侧固定说明文字，中间朗读进度条 `#progBar`，右侧 `已读 / 总数` 计数 `#progTxt`。

## 4. 功能操作详解

### 4.1 切换横排 / 竖排

1. 点 `竖排`（或按 `V`）。
2. 版面重排为竖排，并**自动把横向滚动条拉到最左**（即右起的起始列，`stageEl.scrollTo({ left: stageEl.scrollWidth })`，`:265`）。
3. 竖排模式下舞台改为横向滚动（`overflow-x:auto; overflow-y:hidden`，`:40`），用鼠标滚轮横向滚动或用触摸板左右滑动查看后面的列。

### 4.2 调节字号

- 拖动字号滑块，或按 `+` / `=`（放大 2px）、`-`（缩小 2px）。
- 取值被强制限制在 **12–38**：`applyFs` 内部有 `Math.max(12, Math.min(38, +v))`（`:252`），因此快捷键连按不会越界。
- 字号只改 CSS 变量 `--fs`，不影响朗读与导出内容。
- 字号**不持久化**，刷新回到 20（移动端 CSS 默认为 16，`:141`）。

### 4.3 朗读跟读

1. 点 `▶ 朗读`：从第一句开始；或点击任意一句，从该句开始。
2. 朗读中按钮变为 `⏸ 暂停`，再点一次变为 `▶ 继续`（暂停/恢复用 `speechSynthesis.pause()` / `resume()`，`:395-401`）。
3. `■ 停止` 或按 `Esc` 结束本轮，清除高亮并把进度复位为 `0 / 190`。
4. 语速滑块可**在朗读过程中实时调节**——每句都新建 `SpeechSynthesisUtterance` 并读取当前滑块值（`:365`），所以调整在**下一句**生效。
5. 朗读文本经过中文数字转换：`3×7=21` → 「三乘七等于二十一」（`cn()` 与 `speakText()`，`:302-317`，覆盖到三位数，够用于 19×19=361）。
6. 句间固定间隔 150ms（`:372`）。
7. 朗读跑到队尾会自动调用 `stopSpeak()` 复位（`:360`）。

### 4.4 背景节拍

`节拍` 按钮是**三态循环**，按钮文案即「下一个状态」的提示：

| 当前状态 | 按钮显示 | 点击后进入 | 节奏 |
| ---- | ---- | ---- | ---- |
| `off` | `节拍` | `beat` | 每 0.55 秒一拍，每第 4 拍为重音（`tok`），其余为轻点（`blip`） |
| `beat` | `木鱼` | `wood` | 每 0.8 秒一下，仅偶数步发声，每第 8 步为重音 |
| `wood` | `静音` | `off` | 停止 |

音色由 WebAudio 实时合成（三角波 + 带通滤波），**不加载任何音频文件**（`:418-441`）。首次点击按钮时才创建 `AudioContext`，这是浏览器自动播放策略要求的（`:410-416`）。

### 4.5 导出图片

点 `存图` → 用 Canvas 重新绘制一张**独立的印刷版**（不是页面截图），然后下载为 `大九九乘法口诀.png`（`:598-604`）：

- 画布宽固定 1480px，高度按排版后的行数计算；按 `devicePixelRatio` 放大，上限 2 倍。
- 内容按「每行填满宽度」重新折行，左侧是 `N 乘段` 标签列。
- 含双线金色边框、纸张噪点纹理、标题、副标、页脚落款与右下角「大九」印章。
- **配色跟随当前主题**：深色主题导出深底图，浅色导出米黄底（`:486-492`）。
- 导出图用的是固定 22px 字号，**与页面上的字号滑块无关**。

### 4.6 导出 PDF

点 `PDF` 即 `window.print()`（`:607`）。打印样式（`:130-139`）会：隐藏工具栏/状态条/进度线、强制白底黑字、把竖排强制还原为横排、每个乘段 `page-break-inside:avoid`、句子字号固定 10pt。在打印对话框里选「另存为 PDF」即可。

## 5. 快捷键一览

源码只有一个 `keydown` 监听（`:610-621`），守卫是**焦点不在 `INPUT` 元素上**（因此焦点在两个滑块上时快捷键全部失效）。按键统一 `toLowerCase()` 后比较。

| 按键 | 动作 | 生效条件 |
| ---- | ---- | ---- |
| `空格` | 等同点击 `▶ 朗读` / `⏸ 暂停` | 已 `preventDefault`，避免页面滚动 |
| `V` | 切换横排 / 竖排 | 直接调 `setOrient`，不经过按钮 |
| `T` | 切换深浅主题 | 等同点击主题按钮 |
| `F` | 切换全屏 | 等同点击全屏按钮 |
| `M` | 循环背景节拍状态 | 等同点击节拍按钮 |
| `Esc` | 停止朗读 | 调 `stopSpeak()` |
| `+` 或 `=` | 字号 +2px | 结果被 clamp 到 38 |
| `-` | 字号 −2px | 结果被 clamp 到 12 |

未在源码中确认的键位：方向键、数字键、`P`、`S` 等均无绑定。

## 6. 支持的输入 / 输出格式

**输入**：无。内容是代码生成的常量数据，页面不接受任何文件、文本或网络输入。

**输出**：

| 出口 | 格式 | 文件名 | 说明 |
| ---- | ---- | ---- | ---- |
| `存图` | PNG | `大九九乘法口诀.png` | Canvas 重绘版，宽 1480px，DPR ≤ 2 |
| `PDF` | PDF（经浏览器打印） | 由用户在打印对话框决定 | 走 `@media print` 样式 |

**明确不支持**：导出 TXT / Word / SVG；导出当前页面截图；导出选中片段；自定义导出标题文字（标题与副标为源码内字符串常量，`:551`、`:555`、`:585`）。

## 7. 数据与隐私

- **完全不联网**：源码中无 `<link>`、无 `@import`、无 `fetch`、无 `<script src>`、无任何外部域名。字体使用系统本地字体栈（`Songti SC` / `STSong` / `SimSun` / `Noto Serif SC`，`:31`），未安装时回落系统衬线字体。
- **唯一持久化**：`localStorage` 键 **`mt-dark`**，值 `"1"` / `"0"`，仅记录深色主题开关（写 `:276`，读 `:279`）。
- 不使用 `IndexedDB`、`sessionStorage`、Cookie。
- 朗读走浏览器/系统的 `speechSynthesis`，是否联网由浏览器与语音实现决定（部分在线语音会上传待读文本）。
- **清除方法**：F12 → Application → Local Storage → 删除 `mt-dark`；或清除本站点数据。字号、语速、横竖排、节拍状态本来就不保存，刷新即复位。

## 8. 常见问题（FAQ）

**点朗读没声音。**
系统缺少中文语音包。先确认浏览器为 Chrome / Edge，再在系统「语音」设置里安装中文语音。若 `window.speechSynthesis` 不存在，点朗读会直接弹窗 `当前浏览器不支持语音朗读，请使用 Chrome / Edge。`（`:381`）。

**朗读读的是英文或把符号读成「times」。**
代码强制 `u.lang = 'zh-CN'`，但浏览器可能仍选中英文音色。在系统语音设置里把中文语音设为默认，或在浏览器朗读设置中指定中文语音。

**朗读中途卡住不动。**
Chrome 长时间 `speak` 队列偶发挂起。按 `Esc` 停止后重新开始；避免在朗读时切换标签页。

**节拍点了没响。**
浏览器自动播放策略要求先有用户手势。`节拍` 按钮本身就是手势，若仍无声，检查系统音量与标签页是否被静音；`AudioContext` 处于 `suspended` 时代码会尝试 `resume()`（`:462`）。

**竖排模式下看不到内容。**
竖排是右起横向滚动，滚动条在舞台底部。按 `V` 切回横排，或用触摸板左右滑动。

**导出的 PNG 和屏幕上不一样。**
这是设计如此：导出走独立的 Canvas 排版，固定 22px 字号、固定 1480px 宽，不受字号滑块与横竖排影响。只有深浅主题会影响导出配色。

**导出的图片里汉字变成方块。**
导出依赖系统衬线中文字体。若系统无宋体类字体，Canvas 会回落成缺字字形。换用带中文字体的环境或改用 `PDF` 出口。

**刷新后字号/语速回到默认。**
只有主题被持久化，其余设置不保存。

## 9. 技术实现要点（开发者）

**用到的 Web API**：`SpeechSynthesis` / `SpeechSynthesisUtterance`、`AudioContext` + `OscillatorNode` / `BiquadFilterNode` / `GainNode`、`Canvas 2D` + `toBlob`、Fullscreen API、`localStorage`、`URL.createObjectURL`。

**数据流**：

```
DATA（195-203 生成）
  └─ render()（219-247）→ DOM .line 元素 + 并行数组 items[{el,si,li,text}]
        └─ 点击某句 → startFrom(si,li)（380）
              ├─ buildQueue(si,li)（319）→ 线性队列 queue
              └─ speakNext(runId)（358）→ 每句一个 utterance
                    ├─ onstart → highlight()（335）→ 加 .active + scrollIntoView + updateProgress
                    └─ onend/onerror → qi++ → setTimeout 150ms → speakNext
```

**并发控制**：用自增的 `runId` 作「轮次令牌」。`stopSpeak()` 让 `runId++`，所有在途回调发现 `myRun !== runId` 就直接返回（`:359`、`:368`、`:370`），从而避免停止后旧队列继续推进。

**关键函数索引**：

| 函数 | 行号 | 作用 |
| ---- | ---- | ---- |
| `render()` | 219-247 | 生成 DOM 与 `items` 索引表 |
| `applyFs(v)` | 251-256 | 设字号，内含 12–38 clamp |
| `setOrient(vertical)` | 261-266 | 切横竖排并滚到起始列 |
| `setTheme(dark)` | 271-277 | 切主题并写 `mt-dark` |
| `cn(n)` | 303-312 | 阿拉伯数字 → 中文读法 |
| `speakText(s)` | 313-317 | `a×b=c` → 中文句子 |

## 10. 二次修改指引（开发者）

**改最大乘数**：改 `MAX`（`:195`）一处即可，句子数、段落、朗读队列、导出排版都会跟着变。但页面文案里有三处硬编码「19×19」「190 句」需要同步改：副标 `:158`、底部说明 `:188`、导出图内 `:555` 与 `:585`。

**只导出某几段**：在 `exportImage()` 的 `DATA.forEach`（`:506`）里按 `sec.title` 过滤 `rows`，不影响页面显示。

**换节拍音色/节奏**：`tok()`（`:418`）与 `blip()`（`:431`）里改振荡器类型、频率包络与带通参数；`schedule()`（`:443`）里 `nextTime += 0.55` / `0.8` 是每拍时长。

**新增三态之外的节拍**：扩展 `musicMode` 取值，在 `schedule()` 加分支，并同步 `setMusic()` 的文案表（`:468`）与 `btnMusic` 点击的循环映射（`:472`）——**两处都要改**，漏掉会点出 `undefined` 文案。

**让字号也持久化**：仿 `mt-dark` 的做法，在 `applyFs()` 末尾 `localStorage.setItem('mt-fs', v)`，并在初始化处读回并调用 `applyFs()`。注意 `applyFs` 会同时回写滑块值，不会产生不一致。

**改导出尺寸**：`exportImage()` 顶部常量集中（`:494-497`）：`W` 画布宽、`padL/padR/padT/padB` 内边距、`fsCell` 字号、`cellGapX/cellGapY` 间距、`labelW` 段标题列宽。改 `W` 会连带影响折行结果与总高，属正常。

**注意打印样式覆盖**：`@media print`（`:130-139`）用 `!important` 强制横排与固定字号。若你新增屏幕样式希望打印时保留，需要显式加打印规则，否则会被覆盖。

**注意 `e.target.tagName === 'INPUT'` 守卫**：新增 `button` / `select` 控件后，焦点停在按钮上时快捷键**仍然生效**（守卫只排除 `INPUT`）。若不希望如此，需自行扩展守卫条件。
