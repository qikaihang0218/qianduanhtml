# 颜色选择器 · 操作文档

> 源文件：[../DeepSeek-颜色选择器HTML代码.html](../DeepSeek-颜色选择器HTML代码.html)
> 页面标题：`🎨 颜色 & 渐变选择器 · 自定义色标`（页面内主标题为 `🎨 取色盘 HSV`）
> 一句话定位：一个 **HSV 圆形取色盘 + 74 个常用色板 + 可自由编辑色标的渐变生成器**，产出 HEX / RGB / `linear-gradient()` CSS。
>
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

## 1. 工具简介

它把两件相关但独立的事装在同一张卡片里：

1. **上半部分：取色。** 一个 600×600 的 Canvas 色轮，用**极坐标 HSV** 铺色 —— 角度 = 色相 H、到圆心的距离 = 饱和度 S、**明度 V 恒为 1**（`:964`）。点或拖就能取色，右侧同步显示 HEX（可反填）与 RGB，下方 74 个预设色一键取用。
2. **下半部分：造渐变。** 一个真正可编辑的 `linear-gradient` 生成器：2–8 个色标，每个色标可单独改颜色和位置（滑轨拖 + 列表滑块双入口），角度 0–360°，一键复制 CSS。

两者有一个连接点：**`＋ 添加色标` 会把上半部分「当前取到的颜色」作为新色标的颜色**（`:1331`），这是把取色结果搬进渐变的正式通道。

适合谁用：

- 写 CSS 时想快速定主色、拿 HEX/RGB 的人。
- 要做渐变背景/按钮/横幅，需要**精确控制每个色标位置和颜色**的人 —— 这是它比大多数「随机渐变网站」强的地方。

**不适合的场景**：

- ⚠️ **色轮取不到暗色和灰黑色**。V 固定为 1，圆心是纯白，圆周是纯色，**整个圆内没有任何一个像素的明度低于 1**。要黑色、深灰、暗色调，只能靠 HEX 输入框手输、或下方「暗调」预设。这是本工具最重要的一条限制。
- **不支持透明度 / Alpha**。全程只有 RGB 三通道，输出里没有 `rgba()`，色标也没有不透明度滑杆。
- **没有吸管 / 屏幕取色**。不能从网页、图片、屏幕任意位置取色（未使用 EyeDropper API）。
- **没有色阶生成、无对比度/无障碍检查、无 HSL 输出、无历史与收藏、无撤销**。
- **不保存任何东西**：刷新即回默认（`#FF4757` + 红蓝双色渐变），详见第 7 章。

## 2. 快速开始

1. 双击 `DeepSeek-颜色选择器HTML代码.html`，用 Chrome / Edge / Firefox 打开。**完全离线可用**（无任何外部资源）。
2. 页面打开即为默认状态：色块 `#FF4757`，渐变 `linear-gradient(90deg, #FF4757 0%, #4D96FF 100%)`。
3. **取色**：在色轮里点一下（或按住拖动）。左侧圆点、HEX、RGB 同步变化。
4. **取暗色**：别在色轮上找，直接在 HEX 框里输入如 `#2C3E50` 后按回车。
5. **调渐变**：点底部某个色标圆点选中它 → 在「色标编辑器」那一行点色块改颜色、拖「位置」滑块改位置。
6. 点 `＋` 加色标（新色标 = 第 3 步取到的颜色），点 `🎲` 随机一套，拖「角度」滑块转方向。
7. 点最底部的 CSS 文本或 `复制` 按钮 → 粘贴进 CSS 的 `background:` 后面。

想直接复制取到的 HEX：**双击色轮**（任意位置）即弹「📋 已复制 #XXXXXX」。

## 4. 功能操作详解

### 4.1 取色（点选 / 拖拽 / 触屏）

- **单击**：`mousedown` → 立即取该点颜色（`:1383-1388`）。
- **按住拖动**：`mousemove` 期间持续取色，`mouseup`（绑在 `window` 上，拖出画布也能松手，`:1394`）。
- **触屏**：`touchstart` / `touchmove` 走同一套逻辑，取 `touches[0]`（`:1396-1408`）。
- 取色实现是**从画布读像素**（`ctx.getImageData(x,y,1,1)`，`:997`），不是数学反算 —— 所以「看到的 = 取到的」严格一致，包括圆外的 `#12121C`。
- 坐标先归一到 0–1 再乘 600 取整（`:993-996`），因此**窗口缩放不影响取色准确性**（位置缓存见第 9 章）。
- 画布上的 `mousemove` 在不拖动时直接 `return`，不取色（`:1390`）—— 只有 `dblclick` 与拖拽会改色。

### 4.2 双击复制 HEX

`dblclick` → `copyCurrentHex()`（`:1410-1413`）。注意**双击的前两次 `mousedown` 已经先把颜色改成了双击点位的颜色**，所以复制的是「你双击的那个颜色」，符合直觉。

复制走 `navigator.clipboard.writeText`，失败或不可用时回落到隐藏 `<textarea>` + `document.execCommand('copy')`（`:1065-1079`）—— 所以 `file://` 下也能复制成功。

### 4.3 反填 HEX（唯一的精确输入入口）

`hexToRgb`（`:925-931`）接受：

- 带或不带 `#`；
- **3 位缩写**（`#F47` → `#FF4477`，`:927`）或 6 位；
- 大小写不敏感；
- 首尾空格（`trim()`）。

其它一律判为非法。三个触发时机：

| 时机 | 行为 |
| ---- | ---- |
| `input`（每敲一个字） | 若已构成合法 HEX 就**立刻应用**（`:1416-1418`）→ 输完第 6 位即生效，不用回车 |
| `Enter` | 合法则应用，非法则回滚，然后 `blur()`（`:1424-1432`） |
| `blur`（点到别处） | 同上（`:1419-1423`） |

**非法输入不会报错**，只是把输入框恢复成上一个合法色 —— 容易误以为「没反应」。

### 4.4 预设色板

点任意色块即取该色（`:1022-1025`）。悬停可读到 HEX 气泡，不必点了才知道色值。

「暗调」组是取暗色的主要途径（18 个 `#1E1E2F`–`#6B5A5A` 区间的低明度色）。

### 4.5 渐变色标：选中

三种方式选中一个色标：

1. 点滑轨上的圆点（`.stop-marker`，`:1198-1202`）；
2. 点「色标编辑器」里的整行（`:1304-1307`）；
3. 拖圆点也会顺带选中（`:1163`）。

选中态：圆点变蓝圈并放大 1.15 倍，行变蓝色高亮，右上角提示变成 `已选中 #XXXXXX @ NN%`。

**取消选中**：点滑轨的空白处或灰色滑轨本身 → `selectedStopId = null`，提示回到 `点击色标编辑颜色`（`:1446-1451`）。取消选中不影响已有色标。

### 4.6 渐变色标：改颜色 / 改位置

**每个色标有两个独立维度，且各有两个入口：**

| 维度 | 入口 A（滑轨） | 入口 B（编辑器行） |
| ---- | ---- | ---- |
| 颜色 | 无（圆点只显色） | 行首色块 → 弹出**系统原生取色器** |
| 位置 | 左右拖动圆点（整数百分比，0–100 钳制） | 拖「位置」滑块 |

- 行首色块其实是把原生 `<input type="color">` 放大到超出容器再用 `overflow:hidden` 裁切（`:556-577`），所以点上去弹的是**系统取色面板**，不是自绘色轮。取到的值会 `.toUpperCase()` 存回（`:1227`）。
- 拖动圆点时**只更新预览与 CSS 文本**，松手才 `renderGradient()` 全量重绘（`:1174-1191`）→ 拖动很顺。
- 两个入口双向同步：拖圆点会实时改写对应行里的滑块值与百分比（`:1178-1184`）。
- 位置是**整数**（`Math.round`，`:1171`），不支持 `12.5%` 这种小数。

### 4.7 添加 / 删除色标

**`＋ 添加色标`（`addStop`，`:1314-1336`）**：

1. 已有 **8 个**则拒绝并提示 `⚠️ 最多8个色标`。
2. 把现有色标按位置排序，**找相邻间距最大的一段，插到它的中点**；若最大间距 < 5% 则固定插到 50%。
3. 新色标的颜色 = **上半部分当前取到的颜色**（`:1331`）。

所以「先取色 → 再点 ＋」是加指定颜色的正确姿势；直接点 ＋ 得到的是当前色（默认 `#FF4757`）。加完自动选中新色标，可立刻在编辑器里改色。

**删除**：行尾 `✕`。**剩 2 个时按钮禁用**（`:1291`、`:1294`）—— 渐变至少保留 2 个色标，这是硬下限。删掉的是当前行对应的色标；若删的正是选中项，选中项自动跳到 `gradientStops[0]`（`:1296-1298`）。

### 4.8 角度

拖角度滑块即时生效（`:1435-1438`）。**遵循 CSS 原生约定**：`0deg` 向上、`90deg` 向右、`180deg` 向下、`270deg` 向左。范围 `0–360`，`360deg` 与 `0deg` 视觉相同。

### 4.9 随机渐变（`randomGradient`，`:1339-1357`）

一次覆盖**角度 + 全部色标**：

- 角度 = 0–360 随机整数。
- 色标数 = `2 + floor(random()*3)` → **2 / 3 / 4 个**（不会出现 5 个以上）。
- 首尾固定在 0% 和 100%，中间色标**等分**位置：3 个 → `0/50/100`；4 个 → `0/33/67/100`。
- 每个色标颜色 = `hslToHex(随机色相, 70, 60)` —— **饱和度 70%、亮度 60% 固定**，色相完全随机。

因此随机结果永远偏「中饱和中亮度」，**不会给出暗色渐变或低饱和莫兰迪渐变**；且中间色标之间色相毫无关联，撞出脏色的概率不低。不满意就多按几次。

⚠️ **随机是不可撤销的**，会直接丢掉你手调的全部色标，且**没有撤销功能**。有满意配方先复制 CSS。

### 4.10 复制 CSS

三种方式（都复制 `buildGradientCss()` 的完整结果，`:1369-1374`）：

1. 点 `复制` 按钮；
2. **直接点那行 CSS 文本**（`:1443`）；
3. 无（没有快捷键）。

输出形如：

```
linear-gradient(90deg, #FF4757 0%, #4D96FF 100%)
```

- **不含 `background:` 前缀**，粘贴时要自己补。
- 色标按位置升序排列输出（`:1107`），即使你添加顺序是乱的。
- 位置重复是允许的，CSS 里后出现的胜出（表现为「硬边」，可用来做硬切分色）。
- 预览条、CSS 文本、滑轨圆点、编辑器行四者始终同源同步（都读 `gradientStops` + `gradientAngle`）。

## 6. 支持的输入 / 输出格式

**输入**：

| 项 | 接受 | 限制 |
| ---- | ---- | ---- |
| HEX 文本 | `#RGB` / `RRGGBB` / `#RRGGBB`，大小写不限，可含首尾空格 | `maxlength="7"`；`#RRGGB` 等 4/5 位、含 `#` 以外的非法字符、`rgb()` 字符串 → 全部判非法并回滚 |
| 色轮点位 | 画布内任意像素 | 只能取到 V=1 的颜色 + 圆外 `#12121C` |
| 预设 | 内置 74 个 HEX | 不可增删 |
| 色标颜色 | 浏览器原生 `<input type="color">` 的 `#rrggbb` | **不支持 alpha**；无法手输 HEX 到色标（只能从系统面板选） |
| 色标位置 | 0–100 整数百分比 | 拖拽 `Math.round`，滑块步进 1；不支持小数 |
| 角度 | 0–360 整数（CSS deg） | 步进 1 |
| 色标数量 | 2–8 | 少于 2 禁止删除，多于 8 拒绝添加 |

**不接收**：图片文件（不能从图取色 / 不能从图取渐变）、屏幕取色、`.ase`/`.aco`/`.sketchstatus` 等色板文件、JSON 配置导入、URL 或 CSS 文本反解（**不能粘贴一段现成 `linear-gradient(...)` 让它解析**）。

**输出**：

| 输出 | 形态 | 位置 |
| ---- | ---- | ---- |
| HEX | `#RRGGBB`（**大写**，始终 6 位，不压缩成 3 位） | HEX 框；双击色轮写入剪贴板 |
| RGB | `R, G, B`（逗号+空格分隔，无 `rgb()` 包裹） | `#rgbValues`，**仅显示，无复制按钮** |
| 渐变 CSS | `linear-gradient(<A>deg, <HEX> <P>%, …)` | CSS 框；`复制`按钮 / 点文本写入剪贴板 |
| 色标提示 | `已选中 #XXXXXX @ NN%` | 编辑器右上角，仅显示 |

**没有的输出**：`rgba()` / `hsl()` / `hsla()` / CSS 变量 / SCSS 变量 / Tailwind 配置 / JSON 色板 / SVG / PNG 图片导出 / 渐变的 `background:` 完整声明 / 复制单个色标 HEX / 多段（radial / conic）渐变。

> RGB 与 CSS 都**没有独立复制按钮**，只能手动选中复制（RGB 那行是普通 `<span>`，可以正常框选）。

## 7. 数据与隐私

**这是本工具集中隐私表现最好的页面之一：零联网、零持久化。**

**网络**：全文没有 `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon`；`<head>` 里**没有** `<link>`、没有 `@import`、没有 `<script src>`（`:3-6` 只有两个 meta、title、style）。CSS 里写的 `'Inter'`、`'SF Mono'`、`'Fira Code'`、`'JetBrains Mono'` 只是 `font-family` **回退名**，未下载任何字体文件 —— 系统没装就用后备字体。

**结论：断网可用，无任何数据出本机。** 与根 README「无第三方运行时依赖」的表述**一致**（对比：同目录 `千问代码_专属二维码工坊.html` 需要 CDN，不一致）。

**存储**：

- ❌ 不使用 `localStorage`
- ❌ 不使用 `sessionStorage`
- ❌ 不使用 `IndexedDB`
- ❌ 不使用 Cookie
- ❌ 不使用 Service Worker / Cache API

**因此：刷新、关闭标签页、换浏览器、换电脑 → 取色结果与渐变配方全部丢失，回到 `#FF4757` + 红蓝渐变。** 没有「上次配方」，没有草稿，没有收藏。唯一的外传途径是你自己复制走的那段文本。

**剪贴板**：只**写**不读（`navigator.clipboard.writeText` + `execCommand('copy')` 回落）。写入内容是 HEX 或 CSS 文本，不含任何系统信息。

⚠️ **注意 `file://` 下的剪贴板行为**：`navigator.clipboard` 在非安全上下文可能不可用，此时自动走 `execCommand` 回落（`:1062`、`:1373`），实测可用；若两者都失败会提示 `❌ 复制失败`（`:1076`）—— 见到这个提示就手动选中复制。

**复制内容会进系统剪贴板**，可能被剪贴板历史/云同步记录。若你在公司管控设备上处理未发布配色，请自行评估。

## 8. 常见问题（FAQ）

**色轮上怎么都取不到黑色 / 深灰 / 暗色。**
不是 bug：色轮明度固定为 1（`:964`），圆内最暗是纯色本身。**正确做法**：① 在 HEX 框直接输 `#2C3E50` 回车；② 用「暗调」预设（18 个）；③ 想要半暗的中间灰，只能用 HEX 手输（色轮中心是纯白，不是灰）。

**双击色轮没复制成功 / 提示「❌ 复制失败」。**
剪贴板 API 与 `execCommand` 都失败了。多为浏览器隐私策略拦截。绕过：手动选中 HEX 框内容 `Ctrl+C`；或用本地 HTTP 服务打开（`python -m http.server 8080`）以进入安全上下文。

**HEX 输进去没反应，又跳回原来的值。**
说明它被判为非法。检查：是否只有 4 或 5 位、是否带了多余字符（如 `rgb(…)`、空格在中间、中文全角字符）。合法形式只有 `RGB` 三位或 `RRGGBB` 六位（`#` 可选）。

**拖动色轮取色时，取到的颜色偏了 / 拖到边缘变卡。**
先确认窗口没在缩放动画中。取色依赖缓存的画布矩形，只在 `resize` 与 `scroll` 时失效重取（`:1456-1460`）；若页面因别的原因发生布局位移（如浏览器工具栏收起、内容高度突变），缓存会短暂过期导致偏移 —— **滚一下滚轮或拉一下窗口宽度即可自愈**。

**色标位置拖到 37 又跳成 36，想要精确小数。**
位置取整数（`:1171`），滑块步进 1，界面上无法输入 `37.5%`。需要小数只能改源码（第 10 章③）。

**点了 `＋` 加出来的色标不是我想要的颜色。**
它取的是**上半部分取色盘的当前颜色**（`:1331`），不是相邻色标的中间色。两种正确姿势：① 先在色轮/预设/HEX 里取到目标色，再点 `＋`；② 直接点 `＋` 后在编辑器行里用色块改成想要的颜色。

**`＋` 点了没反应，只在底部闪了一下「⚠️ 最多8个色标」。**
色标上限 8 个。先删几个。

**`✕` 删除按钮是灰的点不动。**
只剩 2 个色标时禁用（渐变最少需要 2 个色标）。先 `＋` 再加一个才能删。

**`🎲` 把我调好的渐变冲掉了，能撤销吗？**
不能，**没有任何撤销/重做**。先点 CSS 文本复制一份再试随机。

**随机渐变总是很艳 / 很亮，出不来高级灰。**
固定 `S=70, L=60`（`:1344`、`:1348`、`:1351`），不会给低饱和或暗色。想要沉稳配色就手调：用「暗调」或「柔和」预设当色标颜色。

**复制出来是 `linear-gradient(...)`，粘进 CSS 不生效。**
它不带属性名。写成 `background: linear-gradient(...);`。

**CSS 框里显示不全，只看到一半还有省略号。**
只是显示截断（`white-space:nowrap` + `text-overflow:ellipsis`，`:692-693`），**复制的是完整字符串**。不放心就点 CSS 文本复制后粘到编辑器核对。

**渐变方向和我想的不一样。**
用的是 CSS 角度约定（`0deg` 向上、`90deg` 向右），不是数学角度。想「从左到右」就是 `90deg`（也是默认值）。

**能不能把一段现成的 `linear-gradient(...)` 贴进来让它变成可编辑色标？**
不能，没有 CSS 反解功能（第 6 章）。只能重新手动搭。

**能不能从图片取色，或者导出渐变成图片？**
都不行。没有文件输入，也没有画布导出。想要渐变图片只能自己截图。

**手机 / 窄屏上能用吗？**
能。色轮与色标圆点都绑了 touch/pointer 事件（`:1396-1408`、`:1160`，圆点 CSS 有 `touch-action:none`）。注意色轮上的 `touchmove` 会 `preventDefault()`（`:1403`），所以在色轮区域内**无法滑动页面**，需要在色轮外滑动。

**为什么我输的小写 hex 显示成大写，复制出去也是大写？**
显示大写来自 CSS `text-transform:uppercase`，而 `rgbToHex` 本身就 `.toUpperCase()`（`:922`）—— 所以复制出去的确实是**大写 HEX**。CSS 里大小写等价，不影响使用。

## 9. 技术实现要点（开发者）

**结构**：1467 行单文件。`<style>` `:7-793`（约 786 行，占了全文一半以上），DOM `:795-897`，脚本 `:899-1465`。脚本整体包在一个 IIFE 里（`:900`、`:1464`），**不向全局暴露任何变量/函数** —— 想在控制台调试只能改源码或断点。

**用到的 Web API**：Canvas 2D（`createImageData`/`putImageData`/`getImageData`，getContext 时传了 `{ willReadFrequently: true }` 优化频繁读像素，`:903`）、`navigator.clipboard.writeText` + `document.execCommand('copy')` 回落、Pointer Events（色标圆点，配合 `setPointerCapture`）、Mouse/Touch Events（色轮）、`<input type=color>` 原生取色器。

**不使用**：`localStorage`、`fetch`、`crypto`、`ResizeObserver`、`requestAnimationFrame`（色轮只画一次）、`DecompressionStream`、Web Components。

**两套状态互不知晓**（架构上最该先看清的点）：

```
取色部分                          渐变部分
currentColor {r,g,b}              gradientStops [{id,pos,color}]
  ▲                                gradientAngle (number)
  │ applyColor()                   selectedStopId (string|null)
  │                                stopIdCounter (number)
  └──── 唯一连接：addStop() 读 currentColor ────┘
```

除此之外，改渐变**不会**改 `currentColor`，改取色**不会**动渐变。

**色轮绘制**（`drawColorWheel`，`:945-989`）：600×600 = 36 万次逐像素 HSV→RGB 手工换算，`atan2` 求角度、`distance/radius` 求饱和度，`putImageData` 一次性刷上。**只在 `init()` 里调用一次**（`:1378`），之后画布内容不再变化 —— 所有取色都是读这张静态图。

**取色路径**：`clientX/Y` → 减画布左边、除画布宽 → `clamp(0,1)` → `×600` 取整 → `getImageData(1×1)` → `applyColor`（`:991-999`）。

**位置缓存**：`canvasRect` 在 `mousedown`/`touchstart` 时刷新，并在 `window.resize` / `window.scroll` 时置 `null` 惰性重取（`:1456-1460`）。**这是唯一的失效通道**，布局因其它原因位移时会短暂过期。

**渐变渲染**（`renderGradient`，`:1113-1137`）：一次刷新预览条背景、CSS 文本、角度显示与滑块、滑轨圆点（`renderStopMarkers`，重建全部 marker 并重新绑事件）、编辑器行（`renderStopsList`，`innerHTML=''` 后重建）、右上角提示。

> 注意 `renderStopMarkers` 是**销毁重建**：先 `stopsTrack.innerHTML=''`，再把 `.stops-rail` 重新塞回去（`:1141-1148`）。因此**拖拽过程中绝不能触发全量 `renderGradient()`**，否则正在被 `setPointerCapture` 的节点会被销毁 —— 源码正是靠「拖动中只改样式、`pointerup` 才 render」来规避（`:1174-1191`）。你二次开发时必须守住这条约束。

**关键函数索引**：

## 10. 二次修改指引（开发者）

按需求频率排序，每条都给了确切行号。

**① 支持暗色/灰阶（最该补的能力）**

色轮是 `V = 1` 硬编码（`:964`）。两种改法：

- **低成本**：在色轮旁加一个明度滑块，改 `drawColorWheel` 接收 `value` 参数并在每次变化时重画：

```js
function drawColorWheel(value) {   // value: 0-1
  const v = value == null ? 1 : value;
  // …把 const value = 1; 改成使用形参 v（原 :964）
}
// 滑块 input 事件里：drawColorWheel(v); applyColor(currentColor);
```

注意重画后 `canvasRect` 不需要失效（尺寸没变），但**已取的 `currentColor` 不会自动跟随新明度**，需要自己决定是保留还是按 H/S 重算。

- **零重画**：保留 V=1 的轮，另加一个 256 级灰阶条，取色时把灰阶与轮色按公式混合。逻辑更复杂，但避免 36 万像素重绘。

**② 输出 `rgba()` / 支持 alpha**

需要动 4 处，缺一不可：`currentColor` 加 `a` 字段（`:914`）、`applyColor` 写第三行显示（`:1001-1007`）、`buildGradientCss` 用 `rgba()` 拼色标（`:1108`）、`rgbToHex` 旁增一个 `rgbToRgba`。原生 `<input type=color>` **不含 alpha**，色标的 alpha 得另加滑块。

**③ 色标位置支持小数**

三处：`Math.round(percent)`（`:1171`）改成 `Math.round(percent * 10) / 10`；`posSlider.step = "0.1"` 并在 `parseInt(e.target.value, 10)`（`:1261`）改 `parseFloat`；显示 `posValue.textContent` 与 `marker.title` 里补 `.toFixed(1)`。**别忘了** `:1127`、`:1240`、`:1273` 三处提示文案的百分比格式。

**④ 增删预设色板 / 加「最近使用」**

色值全在 `initPresets()` 的四个数组里（`:1031-1051`），直接增删即可，UI 自适应换行。

「最近使用」需要新增一个容器 + `unshift` 去重逻辑。**注意**：本工具目前**零持久化**，若要让「最近使用」跨刷新存活，就在 `applyColor` 末尾写 `localStorage`，并**务必回到本文第 7 章登记新键名**。建议键名 `colorPicker.recent.v1`，上限 12–20 条，读写包 `try/catch`。

**⑤ 加撤销 / 重做（防 `🎲` 误触）**

在 `randomGradient` 前压栈即可，最小实现：

```js
let history = [];
function snapshot() { history.push(JSON.stringify({ s: gradientStops, a: gradientAngle })); }
function undo() {
  const last = history.pop();
  if (!last) { showToast('↩ 没有可撤销的操作'); return; }
  const st = JSON.parse(last);
  gradientStops = st.s; gradientAngle = st.a;
  selectedStopId = gradientStops[0]?.id || null;
  renderGradient();
}
```

在 `randomGradient()`（`:1339` 第一行）和 `addStop()`（`:1314` 第一行）前各调一次 `snapshot()`，再绑一个按钮或 `Ctrl+Z`（**新增键位记得同步本文第 5 章**）。

**⑥ 粘贴 CSS 反解成色标（很实用）**

`buildGradientCss` 的逆函数不难写，注意处理 `deg`、`rgb()`/`#hex` 混用、`to right` 关键字：

```js
function parseGradient(css) {
  const m = css.match(/linear-gradient\(\s*([^,]+?)\s*,\s*(.+)\s*\)/i);
  if (!m) return null;
  let angle = 90;
  const am = m[1].match(/(-?[\d.]+)deg/);
  if (am) angle = (parseFloat(am[1]) % 360 + 360) % 360;
  else if (/to\s+right/i.test(m[1])) angle = 90;
  const stops = [];
  m[2].split(/,(?![^(]*\))/).forEach(tok => {
    const t = tok.trim();
    const pm = t.match(/(-?[\d.]+)%\s*$/);
    const cm = t.match(/#[0-9a-fA-F]{3,8}|rgba?\([^)]+\)/);
    if (cm) stops.push({ id: genStopId(),
      pos: pm ? Math.round(parseFloat(pm[1])) : 0,
      color: cm[0].toUpperCase() });
  });
  return stops.length >= 2 ? { angle, stops } : null;
}
```

**局限**：`hsl()`、`to top left`、`radial-gradient`、`conic-gradient` 需要另外处理或直接拒绝；`rgb()` 需先转 HEX（现成的 `hexToRgb` 帮不上，得写 `rgbStringToHex`）。

**⑦ 让色标颜色也能手输 HEX**

`:1222-1244` 那段只造了 `<input type=color>`。在旁边补一个 `input[type=text]`，`change` 里复用 `hexToRgb`：

```js
const hexBox = document.createElement('input');
hexBox.type = 'text'; hexBox.value = stop.color; hexBox.maxLength = 7;
hexBox.addEventListener('change', (e) => {
  const rgb = hexToRgb(e.target.value);
  if (!rgb) { e.target.value = stop.color; return; }
  stop.color = '#' + rgbToHex(rgb.r, rgb.g, rgb.b);
  colorInput.value = stop.color; colorPickerWrap.style.background = stop.color;
  renderGradient();
});
hexBox.addEventListener('click', (e) => e.stopPropagation());  // 别冒泡到行选中
row.appendChild(hexBox);
```

**⑧ 加全局快捷键**

现无全局监听，加一个并**照抄动态离子选择器的守卫**，否则在 HEX 框里打字会误触发：

```js
window.addEventListener('keydown', (e) => {
  const t = document.activeElement;
  if (t && (t.tagName === 'INPUT' || t.tagName === 'TEXTAREA')) return;
  if (e.key === 'c') copyCurrentHex();
  else if (e.key === 'g') randomGradient();
});
```

**⑨ 去掉 `🎲` 的破坏性**

最低成本：`randomGradient()` 开头 `if (confirm('将覆盖当前渐变，确定？'))` 再往下走。更好的做法是配合 ⑤ 的撤销栈。

**⑩ 改色轮为方形（HS 矩形 + V 条）**

`drawColorWheel` 整体替换即可，取色函数 `updateColorFromPosition` **不用改**（它读像素，不关心色轮形状）。这是本文件少见的「换实现零连带」的点。

**⑪ 别踩的坑**

- **不要在 `pointermove`（`:1167`）里调 `renderGradient()`** —— `renderStopMarkers` 会销毁正在持有指针捕获的 marker 节点，拖拽立刻中断。拖动中只改 `style` / `textContent`，`pointerup` 才全量重绘。
- `renderStopsList` 里 `posValue` 在滑块监听器之后才用 `const` 声明（`:1262` 引用、`:1277` 声明）。目前靠「监听器异步执行」躲过 TDZ，**一旦有人把它改成同步调用就会 ReferenceError**，重构时留意。
- 每个色标行/圆点的监听器都是**每次渲染新建**，`removeEventListener` 只出现在拖拽的 `onUp`（`:1189-1190`）。若在行上再加长期监听，注意重复渲染不会自动帮你清理外部引用。
- `stopIdCounter` 只增不减（`:1100`、`:1102-1104`），`🎲` 按多了 id 会涨到 `s57` 之类，**无害**（仅 id 字符串变长），别拿 id 做数字解析。
- 画布位图**恒定 600×600**，不跟随 DPR。高分屏上色轮会略糊 —— 想清晰需按 `devicePixelRatio` 放大位图并同步 CSS 尺寸，同时 `CANVAS_SIZE` 参与取色换算的地方（`:995-996`、`drawColorWheel`）都要跟着改。
- `<html lang="en">`（`:2`）而正文全中文，若在意可访问性/SEO 改成 `zh-CN`。
- 色轮 `touchmove` 无条件 `preventDefault()`（`:1403`），已排在 `isDragging` 判断之前 —— 触屏上色轮区域会吞掉页面滚动。若改逻辑，把 `preventDefault()` 移到 `if (!isDragging) return;` **之后**。
