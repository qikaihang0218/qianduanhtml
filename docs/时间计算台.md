# 时间计算台

> 源文件：[../时间计算台.html](../时间计算台.html)
> 页面标题：`时间计算台 · Time Desk`
> 一句话定位：番茄钟、倒计时、时间差、日期推算四合一，全部按时间戳差值计时，切到后台也不走慢
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

---

## 1. 工具简介

「专注 25 分钟」和「这个接口超时了多久」看起来是两件事，但底层都是同一件事：**两个时间点之间差多少**。市面上的番茄钟大多不能算时间差，时间计算网站大多不能计时，于是桌面右下角常年堆着两个窗口。

本工具把四类需求合进一个单 HTML 文件，共用同一套时间格式化与差值计算代码，**零网络请求**，`file://` 双击即用。

| 分区 | 解决什么 |
| --- | --- |
| **番茄钟** | 专注 / 短休 / 长休三段循环，每 N 轮一次长休，带进度环与轮次点 |
| **倒计时** | 自定义时分秒，到点响铃，实时给出「到点时刻」 |
| **时间差** | 两个时间点差多少天时分秒，附总小时 / 总分钟 / 工作日数 |
| **日期推算** | 基准时间加减天 / 周 / 月 / 年 / 小时 / 分钟 / 秒 / 工作日 |

**三个别处不容易一次做到的点**

- **计时不靠累加，靠时间戳差值**。绝大多数网页计时器写的是 `left -= 1` 或 `left -= interval`，浏览器把后台标签页的 `setInterval` 降频到每分钟一次后，这类计时会**越走越慢**——你以为专注了 25 分钟，实际过了 40 分钟。本工具每次 tick 都算 `endAt - Date.now()`，`endAt` 是启动那一刻定下的绝对时间戳，因此切后台、锁屏、休眠都不影响准确性。切回页面时还有一次 `visibilitychange` 立即重算，不会出现「显示还剩 3 分钟、实际已经超时」。
- **提示音是现场合成的**。用 Web Audio 的振荡器按音符序列发声（专注结束上行三音、休息结束下行两音、倒计时到点单音三连），**不加载任何音频文件**，因此断网可用、不占体积、不触发额外请求。每个音符都有 8 ms 淡入与指数衰减包络，不会爆音。
- **月份加减按自然月收口**。1 月 31 日加 1 个月，直觉答案是 2 月 28 日（闰年 2 月 29 日），而不是溢出成 3 月 3 日。`addMonths()` 先把日期归到 1 号、加减月份、再取该月最后一天做 `Math.min` 收口。

**适合谁用**

- 需要番茄工作法，但不想装 App、不想注册账号、不想看广告
- 想算「这个任务从提交到现在过了几个工作日」
- 想知道「90 天后是几号星期几」「距离某个日期还有多少天」
- 在意隐私，不接受把日程交给在线服务

**什么时候不该用它**

- **要跨刷新保留计时**：计时状态只在内存里，**刷新页面即丢**。跨页面持续计时需要通知权限与 Service Worker，超出单文件工具的范围。
- **要法定节假日**：「工作日」只跳过周六周日，**不识别春节 / 国庆 / 调休**。国内精确排班请用专门的日历库。
- **要时区换算**：全部按本机本地时区计算，不显示 UTC 或其他时区时间。
- **要长期记录**：不做专注历史统计、不画周报曲线、不导出 CSV。
- **要闹钟 / 后台提醒**：页面关掉就不再计时，也不会发系统通知。

## 2. 快速开始

1. **双击 `时间计算台.html`**。单文件，无同级依赖。
2. 默认停在 **番茄钟** 分区，显示 `25:00`，点 **开始**（或按 <kbd>Space</kbd>）。
3. 顶部四个标签切换分区，也可以直接按 <kbd>1</kbd> ~ <kbd>4</kbd>。
4. **倒计时**：切到该分区，填时 / 分 / 秒或点预设按钮（1 / 3 / 5 / 10 / 30 分钟），点 **开始**。
5. **时间差**：开始已预填今天 00:00，结束预填此刻，切过去就能看到结果。改任一输入框即时重算。
6. **日期推算**：基准预填此刻，默认「之后 30 天」，点 **计算**（或在数字框里按 <kbd>Enter</kbd>）。
7. 想看能力边界与快捷键，点右上角 **帮助**。

| 时段结束自动进入下一段 | 勾选时到点自动开始下一段；取消则停在下一段起点等你点开始 |

| 标题栏显示剩余 | 控制 `document.title` 是否被剩余时间接管 |

### 3.4 倒计时分区

| 控件 | 作用 |
| --- | --- |
| 大数字 `#timerClock` | `HH:MM:SS` 完整格式（番茄钟用 `MM:SS`，因为单段不会超过 180 分钟） |
| 阶段文字 | `未开始` / `计时中 · 总长 00:05:00` / `已暂停 · 剩余 00:03:12` / `已结束 · 10:14:08 响铃` |
| 时 / 分 / 秒 | 0–99 / 0–59 / 0–59。三者全为 0 时点开始会报错，不会静默什么都不做 |

### 3.5 时间差分区

| 控件 | 作用 |
| --- | --- |
| 开始 / 结束 | `datetime-local`，精确到秒（`step="1"`） |
| **结束=此刻** | 把结束设为当前时刻，用来算「从某时刻到现在过了多久」 |
| 快捷按钮 | 今天 00:00 → 现在 / 本月 1 日 → 现在 / 今年 1 月 1 日 → 现在 / 交换两端 |
| 大字结果 `#diffBig` | 只显示最大的两级单位，如 `1天`、`10时13分`、`2天`。够用且不啰嗦 |
| 结果表 | 完整差值、总天数、总小时、总分钟、总秒数、总毫秒、**工作日**、周数、开始是（星期 + 完整时间）、结束是 |

**结束早于开始时不静默取绝对值**：顶部出现红色错误条说明「已按绝对值展示并加 − 号」，大字结果前面带 `−`。

### 3.6 日期推算分区

| 控件 | 作用 |
| --- | --- |
| 基准时间 | `datetime-local`，旁侧实时显示「星期几 · 完整时间」 |
| **设为此刻** | 一键回到当前时刻并立即重算 |
| 之后 / 之前 | 加减方向 |
| 数字 | 0–100000 |
| 单位 | 天 / 周 / 个月 / 年 / 小时 / 分钟 / 秒 / **工作日** |
| 结果表 | 结果（星期 + 完整时间）、ISO 8601、算式、相距、总天数、**当年第几天**、**是否闰年**、当月起止、**所在周（ISO 8601 周号）** |

### 3.7 错误条 `#err`

位于标签栏下方，红色背景。只在真正需要你注意时出现（结束早于开始、时长为 0、基准时间为空），**切换分区时自动清空**，不会把上一个分区的提示留在屏幕上。

### 3.8 状态栏（26 px）

左侧 `#stMain` 显示最近一次事件（`就绪 · 全部计算在本地完成` / `专注时段结束 · 10:15:05` / `倒计时结束 · 10:14:08`），右侧 `#stRight` 显示打开页面时的本地时间。

## 4. 功能操作详解

### 4.1 跑一轮完整的番茄工作法

1. 在 **番茄钟** 分区确认时长（默认 25 / 5 / 15，每 4 轮长休）。
2. 点 **开始**。进度环从满到空，徽标变为 `番茄钟 运行中 · 剩余 24:59`，浏览器标签页标题变为 `24:59 · 专注`。
3. 想中途离开，看浏览器标签页标题就够了——**标题栏倒计时不要求当前停在该分区**。
4. 25 分钟到，响上行三音，状态栏写 `专注时段结束 · 10:15:05`，自动进入 **短休息**，进度环变绿。
5. 休息 5 分钟到，响下行两音，轮次点第 1 个变实心，进入第 2 轮专注。
6. 第 4 轮专注结束，进入 **长休息 15 分钟**，四个轮次点全实心。
7. 长休结束，轮次回到 `1 / 4`，循环继续。
8. 想暂停，点 **暂停**（或 <kbd>Space</kbd>）；想重新开始，点 **重置**（或 <kbd>R</kbd>）。

### 4.2 关掉自动续接，手动控制节奏

取消勾选 **时段结束自动进入下一段**。此后到点只响铃并切换到下一段的起点，停在那里等你点 **开始**。适合「专注完想先站起来走两分钟再决定休多久」。

### 4.3 用倒计时做「只做 10 分钟」的启动法

1. 切到 **倒计时**（<kbd>2</kbd>）。
2. 点预设 **10 分钟**，或手填。
3. 点 **开始**。看 **到点时间** 知道你会在几点几分被叫停。
4. 中途想暂停按 <kbd>Space</kbd>，剩余量被固化，再按一次从剩余量继续。
5. 到点响单音三连，状态栏写 `倒计时结束 · 时间`。

### 4.4 算「这个任务从提交到现在过了几个工作日」

1. 切到 **时间差**（<kbd>3</kbd>）。
2. 开始填提交时刻，结束点 **结束=此刻**。
3. 看结果表 **工作日** 一行，形如 `1 个（跳过周六周日）`。
4. 注意：**不含端点**，只数区间内的周一到周五；且不识别法定节假日。

### 4.5 算「90 天后是几号星期几」

1. 切到 **日期推算**（<kbd>4</kbd>）。
2. 基准保持此刻（或点 **设为此刻**）。
3. 方向 **之后**，数字 `90`，单位 **天**，点 **计算**。
4. 大字给出 `2027-02-19 10:16:07`，结果表第一行给出星期，还附带当年第几天、是否闰年、所在 ISO 周号。

### 4.6 算「这个月底是几号」

用「月份收口」验证：基准填 `2026-01-31`，之后 1 个月 → `2026-02-28`（2026 非闰年）；基准填 `2024-01-31` → `2024-02-29`（2024 闰年）。**不会溢出成 3 月 3 日。**

### 4.7 用工作日推进排期

基准填周五，之后 1 个 **工作日** → 下周一（跳过周末）。之后 5 个工作日 → 正好一周后的同一天。适合粗排交付日期。

- 专注历史统计与导出
- 系统级通知 / 后台提醒

## 7. 数据与隐私

- **零网络请求**。全文无 `fetch` / `XMLHttpRequest` / `WebSocket`，无外部 CSS / JS / 字体 / 图片 / 音频。提示音由 Web Audio 振荡器现场合成。
- **不申请任何权限**。不读日历、不读定位、不申请通知权限。
- **不写 `localStorage`**。这是刻意的设计：时长设置与勾选项每次打开都是默认值，避免「上次设成 90 分钟忘了改，这次以为在跑 25 分钟」。
- **计时状态只在内存**。`pomo` 与 `timer` 是普通对象，刷新页面即回到初始状态。
- **不读文件**。没有文件输入框，也不会读剪贴板。

**清除数据**：关掉页面即清空，无需任何清理操作。

## 8. 常见问题（FAQ）

**Q：切到别的标签页 / 锁屏后，计时准吗？**
准。所有计时都基于 `endAt - Date.now()`，`endAt` 在启动那一刻就固定了。浏览器降频 `setInterval` 只影响**刷新显示的频率**，不影响剩余时间的计算。切回页面还有一次 `visibilitychange` 立即重算并刷新。

**Q：为什么没有声音？**
两个常见原因：① 浏览器要求**首次用户交互后才能出声**，点过「开始」即满足，但如果你是用脚本 / 自动刷新启动的可能被拦；② 系统或浏览器标签页被静音。检查「提示音」是否勾选，以及浏览器标签页有没有静音图标。

**Q：刷新页面后计时没了？**
是的，状态只在内存。跨刷新持续计时需要 Service Worker + 通知权限，超出单文件工具范围。刷新即重置是明确的设计取舍。

**Q：番茄钟改时长没反应？**
改数字只在「未开始且未暂停」时立即生效，正在计时或已暂停时不跳变。改完点 **重置** 按新值重来。

**Q：工作日为什么不跳过春节？**
只实现了「跳过周六周日」这一条规则。法定节假日每年由国务院公告，硬编码会过期，接入需要外部数据源，与「零网络」冲突。国内精确排班请用专门日历库。

**Q：1 月 31 日加 1 个月为什么是 2 月 28 日？**
这是自然月的正确收口语义：目标月没有 31 号，就取该月最后一天。若溢出成 3 月 3 日，做「每月同日」的排期会逐月偏移。

**Q：为什么时间差的大字只显示两级单位？**
`1天2时3分4秒` 这种全展开在视觉上太吵。只显示最大的两级（如 `1天2时`）足够抓重点，精确值在下面结果表的「完整差值」一行。

**Q：ISO 周号和日历上的周数对不上？**
用的是 ISO 8601 定义：**周一为一周第一天，含当年第一个周四的那周为第 1 周**。因此 1 月 1 日可能属于上一年的最后一周。这与 Excel 的 `WEEKNUM` 默认模式、以及美式「周日为首日」的算法都不同。

**Q：结束时间填得比开始早会怎样？**
不静默取绝对值。顶部红色错误条说明「已按绝对值展示并加 − 号」，大字结果前面带 `−`。

**Q：两个计时器能同时跑吗？**
可以，它们是独立的。但标题栏只能显示一个——两个都在跑时优先显示当前分区那一个。

**Q：能打印 / 截图存档吗？**
没有专门的导出功能，用浏览器打印（<kbd>Ctrl</kbd>+<kbd>P</kbd>）即可，深色背景可能被打印样式去掉。

## 9. 技术实现要点（开发者）

### 9.1 计时模型：时间戳差值，不是累加

```js
// 启动：定下绝对结束时刻
pomo.endAt = Date.now() + pomo.leftMs;
pomo.running = true;

// 每次 tick：算差值
var left = pomo.endAt - Date.now();
```

`setInterval(tick, 200)` 只负责**刷新显示**和**检查是否到点**，不承担计时精度。这样即使浏览器把定时器降频到 60 秒一次，剩余时间依然准确，只是刷新变粗。暂停时把 `leftMs` 固化，继续时用 `Date.now() + leftMs` 重新定 `endAt`。

`visibilitychange` 里在页面重新可见时再跑一次 `pomoTick()` / `timerTick()`，避免「切回来还显示旧值直到下一个 tick」。

### 9.2 番茄钟状态机

```
work --(到点/跳过)--> short  (round % every != 0)
work --(到点/跳过)--> long   (round % every == 0)
short|long --(到点/跳过)--> work  (round + 1，超过 every 则回 1)
```

`pomoNext(auto)` 是唯一的状态转移函数，`auto` 表示「是否由到点触发」。`pomoSkip()` 传 `false`，到点触发传 `true`，再由 `$('pomoAuto').checked` 决定要不要真的自动开跑。**跳过不计入完成**，所以 `pomoSkip` 不会触发提示音。

### 9.3 进度环

SVG 圆周长 `RING_LEN = 2π × 108 ≈ 678.58`。用 `stroke-dashoffset = RING_LEN × (1 - 剩余比例)` 控制可见弧长，`transform="rotate(-90 120 120)"` 把起点转到 12 点方向。CSS 上有 `transition: stroke-dashoffset .25s linear`，与 200 ms tick 配合形成平滑走动。

### 9.4 月份收口

```js
function addMonths(d, n) {
  var day = d.getDate();
  var r = new Date(d.getTime());
  r.setDate(1);                    // 先归到 1 号，避免 setMonth 时溢出
  r.setMonth(r.getMonth() + n);
  var last = new Date(r.getFullYear(), r.getMonth() + 1, 0).getDate();
  r.setDate(Math.min(day, last));  // 收口到目标月最后一天
  return r;
}
```

**必须先把日期设为 1 号再改月份**。直接 `setMonth(getMonth() + 1)` 在 1 月 31 日会先变成「2 月 31 日」，JS 自动溢出成 3 月 3 日，之后无论怎么 `Math.min` 都回不来了。

`new Date(y, m + 1, 0)` 取的是「下个月第 0 天」，即本月最后一天，这是 JS 里取月末的惯用法。

### 9.5 ISO 8601 周号

```js
var day = (t.getDay() + 6) % 7;   // 周一 = 0，周日 = 6
t.setDate(t.getDate() - day + 3); // 移到本周周四
```

ISO 周的定义等价于「该周周四所在的那一年、那一个周数」。定位到本周周四后，再和「当年第一个周四」比较周差。

### 9.6 工作日计算

`workdaysBetween(a, b)` 逐日推进并数周一到周五，**不含端点**。日期量级最多几万天，`while` 循环完全够用，不需要公式法。`addWorkdays(d, n)` 同理，带 `guard > 400000` 兜底防止极端输入死循环。

### 9.7 提示音

```js
var osc = audioCtx.createOscillator();
var g = audioCtx.createGain();
g.gain.setValueAtTime(0.0001, t0 + at);
g.gain.exponentialRampToValueAtTime(0.32, t0 + at + 0.008);
g.gain.exponentialRampToValueAtTime(0.0001, t0 + at + dur);
```

`exponentialRampToValueAtTime` 不能从 0 开始（指数曲线到 0 无定义），所以起点用 `0.0001`。8 ms 淡入避免起音爆点，指数衰减比线性更接近自然消散。三种场景用不同音高序列：

| 场景 | 音符序列（Hz） |
| --- | --- |
| 专注结束 | A5 880 → C#6 1108.7 → E6 1318.5（上行三音） |
| 休息结束 | B5 987.8 → E5 659.3（下行两音） |
| 倒计时到点 | C6 1046.5 ×2 → G6 1568（单音重复后上行） |

`unlockAudio()` 在每次「开始」时调用，确保 `AudioContext` 在用户手势上下文里被创建或 `resume()`。

## 10. 二次修改指引（开发者）

### 10.1 加第五个分区

1. 在 `.tabs` 里加 `<button class="tab" data-view="xxx">名称</button>`。
2. 在 `<main>` 里加 `<section class="view" id="vXxx">…</section>`。**id 必须是 `v` + view 名首字母大写**，`setView()` 靠这个规则找元素。
3. 在 `updateChip()` 里补该分区的徽标文案。
4. 快捷键 <kbd>1</kbd>~<kbd>4</kbd> 的映射数组在 `keydown` 处理里，加长即可。

### 10.2 改番茄钟默认时长

HTML 里四个 `input` 的 `value` 属性（`pomoWork` / `pomoShort` / `pomoLong` / `pomoEvery`）。`pomoDurations()` 直接读 DOM，没有第二处硬编码。改完记得同步第 3.3 节的取值范围说明。

### 10.3 换提示音

`beep(kind)` 里的 `seq` 数组，每项是 `[频率Hz, 起始延迟秒, 时长秒]`。想加音就加项，想改音色把 `osc.type` 从 `'sine'` 换成 `'triangle'` / `'square'`。**注意总时长别超过 1.5 秒**，太长会盖住下一段的开始。

### 10.4 加快捷键

`document.addEventListener('keydown', …)` 一处集中处理。加键位前先想清楚 `typing` 判断——`tag === 'input' || 'select' || 'textarea'` 时必须让位，否则用户在输入框里打字会误触发。

### 10.5 改工作日规则

`workdaysBetween()` 与 `addWorkdays()` 两处，判断条件都是 `wd !== 0 && wd !== 6`。若要支持节假日，需要引入一张日期表——但**这与「零网络」冲突**，除非接受把表硬编码进文件（每年需要更新）。更现实的做法是接受这个限制并在帮助面板里写清楚。

### 10.6 注意事项

- **保持零依赖零网络**。不要引入 `dayjs` / `moment` / `date-fns`——原生 `Date` 足够，且本工具的价值就在离线可用与可审计。
- **不要改成累加式计时**。`left -= 200` 这种写法在后台标签页降频时会走慢，是这类工具最常见的隐性 bug。
- **不要在 `addMonths` 里省掉「先设为 1 号」那一步**。省掉后 1 月 31 日加 1 个月会溢出成 3 月 3 日。
- **不要给 `exponentialRampToValueAtTime` 传 0 作为起点**。会抛异常或静默失效，用 `0.0001`。
- **`TICK_MS` 不要调太小**。200 ms 已经足够平滑（配合 CSS transition），调到 16 ms 会让 CPU 无谓空转，尤其是有两个计时同时跑的时候。
- **`localStorage` 是刻意不用的**。如果真要加，请同时加一个「恢复上次设置」的显式开关，而不是默默记住——计时工具的「以为在跑 A 其实跑的是 B」比丢设置更糟。
