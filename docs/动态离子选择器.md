# 动态离子选择器 · 操作文档

> 源文件：[../动态离子选择器.html](../动态离子选择器.html)
> 页面标题：`⚡ 动态离子选择器 · 交互粒子实验室`
> 一句话定位：21 种可交互 Canvas 粒子效果的**实时调参工作台**，调好后一键导出成独立的单文件 HTML 背景。
>
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

## 1. 工具简介

它是一台**粒子效果配参器**：中间一块 Canvas 舞台实时预览，下方一整排滑块/按钮改参数，满意后把「当前这套参数 + 渲染引擎」打包导出成一个全新的单文件 HTML，直接拿去当网页背景。

架构上分两层（这是理解本工具的关键）：

- **引擎层 `ENGINE_SRC`**（`:244-623`）：一段完整的粒子渲染 IIFE，以模板字符串的形式内嵌。它从 `window.__ION__` 读配置，**页面预览和导出文件用的是同一份字符串**，所以「所见即所得」在导出这条路上是成立的。
- **工作台层**（`:625-973`）：13 套主题色、7 个滑块、21 个效果按钮、预设存取、导出。它通过覆盖 `window.__ION` 并**派发一个假的 `resize` 事件**来让引擎重读参数（`applyConfig`，`:683-689`）。

适合谁用：

- 想给个人主页 / 落地页 / 大屏做动态背景，又不想自己写粒子算法的人 —— 调完点「⤓ 独立HTML」就能拿走。
- 想要**能落盘复用**的调色台：预设系统会把整套参数存进浏览器，下次打开还在。
- 顺手当**全屏时钟 + 天气挂件**看（顶栏有实时时钟与天气）。

**不适合的场景**：

- **它不是绘图/画板工具**。除了「文字粒子」能把你输入的字变成粒子，你无法在画布上画任何东西。
- **粒子效果不可编程扩展**：21 种是硬编码的 `if/else` 分支（`P.prototype.update`，`:289-373`），没有自定义运动方程的入口。
- **顶栏天气会联网**（`fetch` 到 `api.open-meteo.com`，并可能申请**地理位置权限**）。若你需要「绝对零外联」，请看第 7 章的关闭方法 —— 粒子部分本身确实完全离线。
- 统计栏的「粒子」「线条」两项**恒为 0**（已知缺陷，见 3.3），别拿它当性能面板用。

## 2. 快速开始

1. 双击 `动态离子选择器.html`，用 Chrome / Edge 打开。
2. 舞台默认播「⚡ 连线网络」。把鼠标移进画布 —— 粒子会被推开，鼠标位置有一圈柔光。
3. 在「效果模式」网格里点任意一个（如 `☄️ 彗星拖尾`），画面立刻切换。
4. 拖「粒子数量」「运动速度」滑块看变化（注意：每次改参数粒子会**重新随机分布**，见 4.3）。
5. 在「主题配色」13 个色块里挑一个；或「自定义颜色」取色后点「应用」变纯色。
6. 点 `⤓ 独立HTML` → 下载得到 `离子_<效果名>.html`，双击它就是一个全屏动态背景。

只想快速出惊喜：按 `R` 随机组合一整套参数。

## 4. 功能操作详解

### 4.1 效果模式

点网格中任一按钮即可，**即时生效、无确认**。切换时：

- 高亮搬到新按钮，`statE` 更新。
- **四季效果会自动换配色**：`spring→春樱`、`summer→夏萤`、`autumn→秋枫`、`winter→冬雪`（`:707-716`）。若你刚手工选了别的配色，切四季效果会**覆盖**它。
- 触发 `applyConfig()` → 粒子全部重建。

各效果的运动逻辑要点（源码事实）：

| 效果 | 行为要点 |
| ---- | ---- |
| `network` | 唯一画连线的效果；粒子间距离平方 < 阈值² 就连线，透明度 `1-d²/max²`，固定用 `palette[0]` 单色描边（`:486`） |
| `comet` / `meteor` | 向下飘落，出界从顶部重生；阻尼 0.996；`comet` 透明度随速度 0.3→1.0 |
| `vortex` | 以画布中心做切向加速，`min(s,2.2)` 限幅 + 微弱向心项 |
| `gravity` | 向心吸积，力 `min(0.05*d/400*SPEED+0.002, 0.12)`；**粒子不反弹、不重生**，久看会糊在中心 |
| `ripple` | 每帧 3% 概率随机位置自发生涟漪；鼠标移动也生涟漪 |
| `snow` | 缓慢下落 + `sin(age*0.03)` 横向飘；越过下边界回到顶部 |
| `attract` | 鼠标力场方向**反转**（`pw=-0.9`）→ 粒子被**吸向**指针 |
| `burst` | 鼠标**每次移动**都放一次 50 粒爆散 + 涟漪（`:591`），移动越快越热闹 |
| `nebula` | 每帧给粒子加微小正弦位移；**清屏用不透明底色**，所以看不到残影 |
| `bounce` | `O(n²)` 两两排斥，且只有 20% 概率真正施力（`Math.random()<0.2`）→ 表现为松散的「挤开」 |
| `halo` | 位置由 `age` 直接算出（`x=cx+cos(t)*min(W,H)*0.32`），**不受鼠标与速度阻尼影响** |
| `pulse` | 心形参数方程采样 + 心跳节拍（一次快收缩 + 一次弱收缩，周期 `time*0.045*SPEED`）；粒子数被强制 `max(COUNT,520)` |
| `bubble` | 向上漂，越过顶部回到底部；鼠标斥力减到 0.25；画成描边圆 |
| `kaleido` | 位置由 `age` 算，`y` 用 `sin(t*1.7)` 形成利萨如图形；**颜色按角度映射色板** |
| `text` | 见 4.2 |
| 四季 | 各自的花瓣/光点/叶片/六角雪花形状 + 摆动，见 `:518-545` |

> `halo` 与 `kaleido` 的位置是纯函数计算，**不受「鼠标作用半径」影响**，也不参与边界反弹。

### 4.2 文字粒子

1. 在「文字粒子内容」输入框里写文字（**最多 40 字**）。
2. 点 `应用`。若当前不是文字粒子效果，会**自动切到** `🅰️ 文字粒子`（`:670`）。
3. 选 `🔤 字符粒子`（每个粒子渲染成文字里的一个字符）或 `🔸 光点粒子`（普通圆点铺成字形）。
4. 光标在输入框里时按快捷键会失效；按 `T` 是「切到文字粒子并聚焦输入框」，输完仍需点 `应用`。

实现细节（`computeTargets`，`:405-438`）：

- 在一张 **主画布 1/4 尺寸**（`W*0.5 × H*0.5`）的离屏画布上画白字，字号 = 离屏高 × 0.62；若文字宽度超过离屏宽 90% 则**等比缩小字号**（最小 8px），避免长文被裁。
- 逐行扫描 alpha > 128 的像素作为目标点，**行间隔 = `粒子尺寸 × 1.3`**（取整，最小 1），列间隔固定 1 像素。→ **粒子尺寸越大，采样越稀**。
- 粒子数被强制为 `max(你设的数量, 700)`（`:383`）—— 文字效果下「粒子数量」滑块低于 700 时看不出差别。
- 目标点**随机抽取**（不是按顺序），粒子从目标点 ±40px 的随机位置开始，以 `0.055×速度` 的缓动飞向目标 + 常驻微小正弦抖动。
- 鼠标在作用半径内会把目标点**再推开** `MRAD*0.9`（`:295-301`）→ 表现为「指针划过时字被顶开，移开后回弹」。
- 输入框留空点应用 → 回落为默认文案 `动态离子背景`（`:669`）。

### 4.3 参数滑块与「参数一改就重建」

`applyConfig()` 的做法是**派发一个假的 `window.resize` 事件**，引擎的 `resize()` 从 `window.__ION` 重读全部参数，然后调 `rebuild()`（`:440-453`）。

后果：**动任何一个滑块，所有粒子都会重新随机分布**。所以「先调好数量再欣赏」比「边播边微调」体验更好；`gravity` / `vortex` 这类需要时间积累形态的效果尤其明显。

另外「拖尾/残影」三按钮**不触发** `applyConfig`（`:719-722`），它只改工作台里的 `FADE` 变量，要等下一次别的操作才带进引擎。

### 4.4 鼠标与触摸手势

| 手势 | 效果 | 源码 |
| ---- | ---- | ---- |
| 移动（`pointermove`） | 力场交互；`burst` 放爆散、`ripple` 放涟漪 | `:590-592` |
| 按下（`pointerdown`） | **任何效果**都放一次涟漪 + 一次局部爆散（`burst` 除外，避免重复） | `:593-597` |
| 双击（`dblclick`） | 连放 **3 次**爆散 + 涟漪 | `:600-601` |
| 滚轮 | 粒子数 ±20，范围 **20–800**（见 3.4 的上限冲突） | `:603-607` |
| 双指捏合 | 速度乘性缩放，钳制 **0.1–4** | `:610-619` |
| 移出画布 | 力场关闭（`mouse.active=false`） | `:598` |

> 源码注释写「双击：切换暂停 / 中心爆发」（`:599`），但实现里**只有爆发，没有暂停**。以源码为准。

### 4.5 随机组合 / 重置 / 暂停

**`🎲 随机组合`**（或按 `R`，`:742-767`）随机整套：效果（21 个里任取）、数量 60–360、速度 0.4–3.0、连线 60–220、鼠标半径 60–260、尺寸 1.0–6.0、拖尾三选一、连线模式二选一、主题色 13 选 1。

> 注释写「随机一个不是 network 的效果，避免背景过暗」（`:745`），但代码 `rand(EFF_KEYS)` 从**全部 21 个**里取，`network` 也在其中。注释与实现不符。

**`↺ 重置`**（`:728-735`）只复位这 7 项：数量 120、速度 1、连线 130、鼠标半径 120、尺寸 2.2、拖尾「短」、连线模式「全连接」。

> ⚠️ **不复位**：效果模式、主题配色、自定义颜色、透明度、光晕、文字内容、文字显示方式、预设。想彻底回到初始状态请刷新页面。

**`⏸ 暂停`**：按钮文案会切成 `▶ 继续`，也会弹 toast —— 但**画面实际不会停**。原因是引擎判断的是闭包里的 `CFG.paused`（`:464`），而页面把 `paused` 写到了 `window.__ION`（`:771-772`），引擎启动时读的是 `window.__ION__`（双下划线，页面从未设置，见第 9 章），两者不是同一个对象。**这是本工具当前最明确的失效功能**，修复方法见第 10 章。

### 4.6 导出与分享

| 按钮 | 产物 | 说明 |
| ---- | ---- | ---- |
| `⤓ 独立HTML` | `离子_<效果英文名>.html` | 完整可运行单文件：内嵌引擎 + `window.__ION__` 配置 + 一个左上角说明角标。`title` 为 `动态离子 · <中文名>` |
| `📸 截图PNG` | `离子_<效果英文名>.png` | `canvas.toDataURL('image/png')`，**只有画布**，不含控件/时钟/天气；含深色背景，透明区不存在 |
| `⧉ 复制JS` | 剪贴板文本 | 意图是「当前效果的纯 JS」，**实际有缺陷**，见下 |

**`复制JS` 的缺陷**（`currentJS`，`:862-865`）：它用 `ENGINE_SRC.replace(/window\.__ION__=CFG/, 'window.__ION__='+json)` 注入配置，但 `ENGINE_SRC` 里的原文是 `var CFG=window.__ION__||{...}`（`:251`），**不含 `window.__ION__=CFG` 这段子串**，正则永远匹配不到。因此复制出来的是**默认参数（连线网络 / 120 粒 / 霓虹）**的引擎代码，不含你当前调的任何参数。

绕过办法：用 `⤓ 独立HTML` 下载，再用文本编辑器打开，把文件里这一行整段抄走即可（它是有效的注入）：

```
window.__ION__={"effect":"…","count":…,"speed":…,"link":…,"mouseRad":…,"size":…,"fade":…,"mode":"…","palette":[…],"pColor":"…","text":"…","alpha":…,"glow":…,"textStyle":"…"}
```

**导出文件里的可交互性**：导出的 HTML 保留了完整的鼠标/滚轮/双指手势（因为是同一份引擎），也保留了「粒子数 20–800」的滚轮范围。左上角角标 `pointer-events:none`，不会挡住交互；不想要可以直接在导出文件里删掉 `<div class="badge">`。

### 4.7 预设保存（存本地浏览器）

1. 调好一套参数 → 点 `＋ 保存当前`。
2. 弹系统 `prompt`，默认名 `我的预设N`，改名后确认。名字**可重复，重复即覆盖**。
3. 从下拉框选中一条 → `↩ 载入`（`applyParams`，`:803-827`，会把 14 个参数与所有按钮高亮、色块高亮、滑块位置全部同步）。
4. `✕ 删除` 删掉选中项。空列表时下拉框显示 `(暂无预设)`。

`applyParams` 会同步效果按钮、拖尾、连线模式、文字显示方式、主题色块高亮 —— 但**不同步**「自定义颜色」取色器的当前值（若你保存的是单色预设，载入后色块不高亮任何主题，「着色」正确显示 `单色`）。

### 4.8 顶栏时钟与天气

- **时钟**：本机系统时间，每秒刷新，不联网。
- **天气**（`:930-969`）：
  1. 若浏览器提供 `navigator.geolocation`，**打开页面就会弹出定位授权请求**（`timeout:6000`，`maximumAge:600000`）。
  2. 授权成功 → 用经纬度请求 Open-Meteo；**拒绝或超时 → 回退到北京坐标 `39.9042,116.4074`** 并标注「北京」。
  3. 显示：`城市/天气 温度°C · 体感X°C · 湿度X%`，鼠标悬停 `title` 显示风速与「数据来源 Open-Meteo」。
  4. 天气码按 WMO 表映射成 emoji + 中文（45/48 雾、71–77 雪、95–99 雷雨等）。
  5. 请求失败 → `🌡️ 天气暂不可用（离线或网络受限）`。
  6. 若 9 秒后仍停在「天气加载中…」→ 显示按季节的兜底提示（`今日X季 · 天气信息需联网获取`），季节按 12/1/2 冬、3–5 春、6–8 夏、9–11 秋。

> 天气与粒子**完全无关**，只是装饰。想彻底不请求网络：拒绝定位授权，且断网时会走失败分支；或在源码里删掉 `:939-969` 整段（见第 10 章）。

## 7. 数据与隐私

**⚠️ 本页是本工具集中少数会联网的页面之一**，与根 README「数据不上传」的总述存在差异：

- **外部请求**：`fetch('https://api.open-meteo.com/v1/forecast?latitude=…&longitude=…&current=…&timezone=auto')`（`:941-943`）。
- **地理位置**：`navigator.geolocation.getCurrentPosition`（`:962-967`）。**打开页面即触发浏览器定位授权弹窗**。拒绝后改用**硬编码的北京坐标**。
- 除天气外无任何外部资源：无 `<link>`、无 `@import`、无 `<script src>`、无字体 CDN、无埋点、无 `XMLHttpRequest`。
- **粒子部分 100% 本地**：Canvas 渲染、参数、预设、导出全在浏览器内。

**持久化：只有 1 个 `localStorage` 键**

| 键 | 值 | 写 | 读 |
| ---- | ---- | ---- | ---- |
| `ionPresets.v1` | JSON 对象 `{预设名: {effect,count,speed,link,mouseRad,size,fade,mode,palette,pColor,text,alpha,glow,textStyle}}` | `:790`（保存/删除时） | `:789`（启动 `refreshPresetList` 与每次读改写） |

读写均包在 `try/catch` 里，隐私模式或配额满时静默失败（表现为「预设保存了但下次没有」）。

**不持久化**：当前参数、效果、主题色、暂停状态、天气结果。刷新后除预设外全部回默认。

不使用 `IndexedDB`、`sessionStorage`、Cookie、Service Worker。

**隐私提醒与关闭方法**：

- 定位坐标属于敏感信息。若不愿提供：在浏览器弹窗里选「拦截/拒绝」，此时发给 Open-Meteo 的是**北京**这个公开坐标，不含你的位置；但你的 IP 仍会到达该第三方服务。
- 彻底断外联：删除 `:930-969`（`WMO` 常量到那个 `setTimeout` 兜底）整段，并把顶栏 `#wthBox` 的 HTML（`:91`）一并删掉。第 10 章给了具体位置。
- **清除数据**：删 `localStorage` 里的 `ionPresets.v1` 即可；或直接在预设面板里逐条 `✕ 删除`。
- **导出文件不含任何个人数据**：只有你选的效果名与参数，以及固定角标文案「来源于 动态离子选择器」。文字粒子会把你的文字**明文写进**导出文件的 `window.__ION__`，分享前留意内容。

## 8. 常见问题（FAQ）

**按空格/点暂停，画面还在动。**
已知缺陷（见 4.5）：`paused` 写到了 `window.__ION`，引擎判断的却是另一个对象。修一行即可，见第 10 章第一条。

**「粒子」「线条」两个统计一直是 0。**
正常 —— 源码里从未给 `statN`/`statL` 赋值。想看真实粒子数，看「粒子数量」滑块（或按滚轮后 toast 里的数字）。想看 FPS，看 FPS 项。

**每拖一下滑块，画面就炸开重来。**
设计如此：参数经「假 resize 事件」下发，引擎收到后 `rebuild()` 重建全部粒子（`:448-452`）。

**光晕调回 0 了但还在发光。**
已知缺陷：引擎里是 `GLOW = c.glow || GLOW`（`:445`），传 0 会被当成「没传」而保留旧值。**刷新页面**是唯一彻底的关闭方式。同理，`↺ 重置` 也不复位光晕。

**滚轮把粒子推到 600、800，滑块却停在 500。**
滑块 `max=500`，滚轮上限是 800（`:604`），两者不一致，引擎按实际值渲染。拖一下滑块或点「↺ 重置」即可回到 ≤500。

**文字粒子看不清 / 是糊的一团。**
按顺序查：① 「粒子尺寸」太大会让采样间隔变成 `尺寸×1.3` 像素，采样点变稀 —— 调到 1–2 试试；② 「文字显示方式」选 `光点粒子` 比 `字符粒子` 更易辨认；③ 文字过长会被整体缩到很小（按 90% 宽度自适应）；④ 改完文字必须点 `应用`，只按回车无效。

**改了文字但没反应。**
必须点 `应用` 按钮。`T` 键只负责切效果 + 聚焦输入框。

**切到春夏秋冬，我选的配色没了。**
四季效果会强制套用对应主题（`:707-716`）。想保留自定义配色：先点四季效果，**再**去点色块/自定义颜色。

**打开页面就弹「允许查看你的位置」。**
那是天气功能。点「拦截」即可，粒子完全不受影响；想永久去掉请看第 10 章删天气代码。

**天气一直显示「北京」，我不住北京。**
定位被拦截或 6 秒内没返回时的兜底坐标（`:965`）。允许定位，或改源码里的兜底经纬度。

**「复制JS」粘出来的代码是默认效果。**
已知缺陷（见 4.6），正则没匹配上。改用「⤓ 独立HTML」后从文件里抄 `window.__ION__=…` 那一行。

**截图是黑的 / 只截到一半画面。**
`toDataURL` 抓的是**当前帧**。若刚重建粒子（刚改过参数），粒子还在初始随机位置。等一两秒再截。另外截图只有画布，不含控件与时钟。

**页面很卡 / 风扇起飞。**
主要开销来源：① 粒子数过高（滚轮可到 800）；② `network` 与 `bounce` 是 `O(n²)` 两两遍历（`:470`、`:485`）；③ 光晕 `shadowBlur` 很贵（`:521` 等）；④ 文字粒子强制 ≥700 粒。建议：关掉光晕、粒子数压到 200 以内、避开 `network`+`bounce`。

**导出的 HTML 双击打开是一片黑。**
检查是否用 `file://` 打开的其它工具干扰 —— 本工具导出的文件**不需要**安全上下文，纯 `file://` 就能跑。若确实全黑，多半是复制/改动时破坏了 `window.__ION__` 那一行的 JSON 语法（末尾少逗号或引号），用浏览器控制台看报错。

## 9. 技术实现要点（开发者）

**用到的 Web API**：Canvas 2D（含 `devicePixelRatio` 缩放、`createRadialGradient`、`ellipse`、`quadraticCurveTo`、`shadowBlur`、`getImageData` 像素采样、`toDataURL`）、`requestAnimationFrame`、Pointer Events（含 `setPointerCapture`）、`wheel`（`passive:false`）、`touchmove` 双指、`Blob` + `URL.createObjectURL` + `<a download>`、`navigator.clipboard.writeText`、`navigator.geolocation`、`fetch`、`localStorage`、`new Function()` 执行内嵌引擎字符串。

**双层结构**（务必先理解这个再改代码）：

```
工作台 IIFE（:237-974）
 ├─ ENGINE_SRC：模板字符串，内含完整粒子引擎（:244-623）
 ├─ window.__ION      ← 工作台写入的「当前配置」（单下划线）
 ├─ window.__ION__    ← 引擎期望读取的「启动配置」（双下划线）
 │                       ⚠ 工作台从未设置它！
 └─ new Function(ENGINE_SRC)()  启动引擎（:973）

引擎 IIFE（ENGINE_SRC 内）
 ├─ var CFG = window.__ION__ || {默认对象}   ← 实际拿到的是默认对象
 ├─ resize()  ← 读 window.__ION（单下划线）同步参数 + rebuild()
 └─ render()  ← rAF 自续帧；读 CFG.paused 判断暂停
```

**这就是暂停失效的根因**：`CFG` 是引擎启动时的默认对象字面量，`togglePause` 写 `window.__ION.paused`，而 `render()` 判断 `CFG.paused`（`:464`）。参数能同步是因为 `resize()` 读的是单下划线，唯独 `paused` 只在 `CFG` 上读。

**配置注入协议**（`currentParams` / `applyConfig` / `exportHtml` 三处字段完全一致，`:685`、`:801`、`:863`、`:905`）：

```js
{ effect, count, speed, link, mouseRad, size, fade, mode,
  palette, pColor, text, alpha, glow, textStyle }
```

**数据流**：

```
滑块 input ─▶ bind()（692）改局部变量 COUNT/SPEED/…
              └─▶ applyConfig()（683）→ window.__ION = {...}
                    └─▶ dispatchEvent(new Event('resize'))
                          └─▶ 引擎 resize()（440）逐字段 c.x||旧值 同步
                                └─▶ rebuild()（378）清空并按 effect 重建粒子

效果按钮 click ─▶ effect=… （四季则顺带换 palette）─▶ applyConfig()
画布手势 ─▶ 引擎内部直接改 COUNT/SPEED ─▶ window.__wheelCb / __pinchCb
            ─▶ 工作台回写 window.__ION + 弹 toast（680-682）
render()（455）每帧：
  清屏（solid 效果用不透明底；stepped 用 FADE；其余 0.25）
  → CFG.paused? 直接返回
  → 逐粒子 update() → updateBursts()
  → 效果专属逻辑（bounce 排斥 / nebula 涌动 / network 连线 / arc 电弧 / ripple 画圈）
  → 逐粒子绘制（四季专属形状 → text 字符 → 圆点）
  → drawBursts() → 鼠标光斑 → requestAnimationFrame(render)
```

**清屏策略**（`:459-462`）决定残影是否存在：

- `stepped`（`comet` `attract` `burst` `arc` `meteor`）→ 用 `FADE` 清屏，**残影受「拖尾」按钮控制**。
- `solid`（`network` `gravity` `vortex` `snow` `ripple` `bounce` `halo` `kaleido` `pulse` `bubble` `nebula` `spring` `summer` `autumn` `winter`，共 15 个）→ **完全不透明清屏，「拖尾」按钮无效**。
- 其余（只有 `text`）→ 固定 `0.25`，也不受拖尾按钮控制。

## 10. 二次修改指引（开发者）

**① 修「暂停无效」（最该修的一处）**

`render()` 里把判断改成读实时配置对象：

```js
// 原：464 行
if(CFG.paused){requestAnimationFrame(render);return;}
// 改为
var _c=window.__ION||CFG;
if(_c.paused){requestAnimationFrame(render);return;}
```

这样与 `resize()` 的读法（`:441`）保持一致，空格键立刻生效。若希望暂停时连清屏也停住（画面定格而非淡出），把这一行移到 `ctx.fillRect(0,0,W,H)`（`:462`）**之前**。

**② 修「光晕无法关闭」**

`:445` 的 `GLOW=c.glow||GLOW;` 改成：

```js
GLOW=(c.glow==null)?GLOW:c.glow;
```

同文件里 `COUNT/SPEED/LINK/MRAD/PSIZE/FADE` 都是 `||` 写法，只是它们的合法值都非 0 才没暴露；新增可归零的参数时请一律用 `==null` 判断。

**③ 修「复制 JS 注入失效」**

`:865` 的替换目标不存在。两种改法：

- 稳妥：把 `ENGINE_SRC` 里 `:251` 改成 `var CFG=window.__ION__=window.__ION__||{…};`，原正则即可命中。
- 直接：改用与 `exportHtml` 相同的思路，在返回的字符串前面拼一行 `window.__ION__=<json>;`：

```js
function currentJS(){
  const json=JSON.stringify(currentParams());
  return 'window.__ION__='+json+';\n'+ENGINE_SRC;
}
```

**④ 修「滚轮 800 vs 滑块 500」**

二选一：把滑块 `max` 改成 800（`:147`），或把 `:604` 的 `800` 改成 `500`。建议前者并在 `randomize` 里同步上限。

**⑤ 修「统计栏粒子/线条恒为 0」**

`resize()` 末尾与 `rebuild()` 末尾各加一次 `if(window.__stat2)window.__stat2(particles.length)`；`network` 连线分支把 `lineCount` 也回传。最省事是在 `render()` 的每秒节拍块（`:456-457`）里补：

```js
if(window.__stat2){window.__stat2(particles.length,lineCount);}
```

并在工作台加 `window.__stat2=(n,l)=>{$('statN').textContent=n;$('statL').textContent=l;};`（注意 `lineCount` 是 `render` 内局部变量，需在同一作用域内引用）。

**⑥ 加一种新效果**

需要动 4 处（缺一不可）：

1. `:109-129` 的 `.effect-grid` 里加按钮，`data-eff="你的key"`。
2. `:910` 的 `EFFECT_NAMES` 加映射（否则随机组合与预设载入后「效果」栏显示英文 key）。
3. `P()`（`:266-288`）按需初始化粒子属性；`P.prototype.update`（`:289-373`）加运动分支 —— **如果它不该在边界反弹，记得把 key 加进 `:369` 那一长串排除条件**。
4. `render()` 的清屏分类：决定你的效果属于 `stepped`（`:459`，受拖尾控制）还是 `solid`（`:460`，无残影），都不加则落到 `0.25` 固定残影。

**⑦ 增删主题色**

只改 `PALETTES`（`:626-640`）即可，UI 会自动生成色块。注意：数字快捷键只覆盖 `1`–`9`（`:855`），加到 10 个以上要么改正则 `/^[1-9]$/`（配合 `Shift` 等），要么接受无快捷键。

**⑧ 去掉天气（彻底离线）**

删除 `:930-969` 整段（`const WMO=` 到 `setTimeout(...fallbackWeather(),9000);`），并删掉顶栏 `:91` 的 `<div class="wth" id="wthBox">…</div>`。若只删 JS 不删 DOM，胶囊会永远显示「天气加载中…」。想保留但换数据源：`loadWeather` 只有一个 `fetch` 和一个 WMO 映射表，替换 URL 与字段读取即可。

**⑨ 让预设支持导入/导出**

`readPresets`/`savePresets` 已经是纯 JSON，加两个按钮即可：

```js
// 导出
download('离子预设.json', JSON.stringify(readPresets(),null,2), 'application/json');
// 导入：加 <input type=file accept=".json">，change 里
//   const o=JSON.parse(await f.text()); savePresets({...readPresets(),...o}); refreshPresetList();
```

注意当前 `prompt()` 命名允许重名（覆盖语义），导入合并时同名同样覆盖。

**⑩ 改导出文件的样式/角标**

`exportHtml()`（`:888-909`）是一段模板字符串，改 `<style>` 里的 `body` 背景色即可换底色 —— 但**画布每帧仍会用 `rgba(5,8,18,…)` 覆盖**（`:461`），所以改 CSS 背景对动画区域无效。想要透明背景需把 `:461-462` 的清屏改为 `ctx.clearRect(0,0,W,H)`，并让 `html,body` 背景透明 —— 代价是残影类效果全部失效。

**⑪ 改文字粒子的采样密度**

`:425` 的 `var step=PSIZE*1.3;` 是唯一控制点。改成固定值（如 `1.6`）可让密度与「粒子尺寸」解耦。`step` 同时决定采样行数，越小粒子越多、`rebuild` 越慢。

**⑫ 注意 `applyConfig` 会重建粒子**

任何想「运行时改参数但不打断动画」的改动，都不能走 `applyConfig`。正确做法是在引擎里加一个只改数值、不调 `rebuild()` 的同步分支，例如给 `resize()` 加参数 `resize(rebuild=true)`，参数类改动传 `false`。

**⑬ 别在 `ENGINE_SRC` 里用反引号或 `${}`**

它是模板字符串（`:244` 起）。内部若要写模板字符串，必须用 `\`` 转义，`${` 必须写成 `\${`，否则会被外层插值吃掉。同理 `<\/script>` 的转义（`:907`）是防止提前闭合标签，别「顺手」改回 `</script>`。

**⑭ 死代码与误导注释**（改前留意，别被带偏）

- `:526` `if(GLOW>0||true)` —— 恒真，`summer` 的径向渐变永远画。
- `:456` `getElementById('fpsEl')` —— 元素不存在，靠 `try/catch` 吞掉。
- `:599` 注释「双击：切换暂停」—— 实现里没有暂停。
- `:745` 注释「随机一个不是 network 的效果」—— 实现里没有排除。
- `:476-480` `nebula` 分支里 `var pulse=Math.sin(time*0.02)*0.25+0.75;` 计算后**从未被使用**。
- `:459-460` 两条超长的效果分类白名单是硬编码的，新增效果时**必须同步**，否则会静默落到错误的清屏策略。
