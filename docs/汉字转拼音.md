# 汉字转拼音

> 源文件：[../汉字转拼音/汉字转拼音.html](../汉字转拼音/汉字转拼音.html)
> 页面标题：`汉字转拼音 · 注音工具`
> 一句话定位：给中文标注拼音，词组优先消歧多音字，四种注音样式 + 四种排版，可点击改读、复制 Ruby 标注、导出 txt
> 本文所有键位、取值范围、格式清单与存储键均基于当前仓库源码核对。

---

## 1. 工具简介

给一段中文，输出带拼音的结果。核心解决的是**多音字定音**问题：同样一个「长」，在「银行行长」里读 `xíng cháng`，在「长跑」里读 `cháng`，靠单字表做不到，必须结合上下文。

本工具的做法是**词组优先**：先用 853 条多音词组表做最长匹配（`银行` `行长` `重庆` `重量` `成长`……），命中就整体采用词表读音；没命中的字退回单字表的第一读音。剩下的模糊情况交给用户——所有存在多个读音的字在结果里带黄色虚线下划线，点一下换下一个读音。

**适合谁用**

- 做课件、儿童读物、古诗文注音，需要「字 + 拼音」对齐排版
- 写代码 / 起文件名 / 设计 URL slug，要无声调或首字母缩写
- 给一段文本做拼音速记、检索缩写

**什么时候不该用它**

- **需要 100% 准确的多音字标注**：词表只有 853 条，覆盖不了所有语境（如「六安」「单县」这类地名专名）。工具提供的是「多数情况正确 + 一键改读」，不是人工审校
- **需要繁简转换、注音符号（ㄓㄨㄥ）**：词典只有汉语拼音，不做这些
- **超长文档批量处理**：单次输入上限 20 万字，且预览只渲染前 8000 字。整本书建议分段处理

## 2. 快速开始

1. **双击 `汉字转拼音/汉字转拼音.html`**。该目录必须整体存在——`拼音词典.js` 要和 HTML 放在**同一个文件夹**里，否则页面顶部会显示红色「词典缺失」，无法转换。
2. 点工具栏右侧的**「示例」**按钮，左侧填入一段含大量多音字的样例文本。
3. 右侧立刻出现注音结果（无需点任何按钮，输入后约 0.22 秒自动转换）：

   ```
   yínháng xíng cháng shuō： chóngqìng de dōng tiān hái xià yǔ，…
   银 行 行 长 说：重 庆 的 冬 天 还 下 雨，…
   ```

4. 把「注音」下拉换成**数字调**，得到 `yin2hang2 xing2 chang2 shuo1： chong2qing4 …`。
5. 点**「复制」**，结果进入剪贴板（注音排版会自动退化为拼音行文本，见 6.3）。
6. 看到带黄色虚线的字（如「行」），**点它一下**，全文该字的单字读音同步切换，底部状态栏显示「手工改读 1 字」。

## 3. 界面与功能分区

页面自上而下分四块：标题栏、工具栏、左右双栏主体、状态栏。

### 3.1 标题栏

| 元素 | 说明 |
| ---- | ---- |
| `汉字转拼音` + 副标题 | 副标题固定为「词组优先 · 多音字可改读 · 纯本地」 |
| 右侧词典胶囊 | 词典就绪时显示 `词典 20903 字 · 多音 3050 · 词组 853`；未加载成功时显示红色「词典缺失」 |

> 胶囊里的词组数是 **853** 而不是词典文件头注释的 855：`loadDict()` 会丢弃音节数与字数不一致的条目（上游 `pinyin-data` 有 `一撮 => yī,zuǒ,máo` 和 `众行 => zhòngxíng` 两条脏数据），避免错位。

### 3.2 工具栏

| 控件 | 取值 / 默认 | 作用 |
| ---- | ---- | ---- |
| **注音** | `带音调 zhōng`（默认）/ `数字调 zhong1` / `无声调 zhong` / `首字母 z` | 拼音的呈现样式，四种都参与复制与导出 |
| **视图** | `注音排版`（默认）/ `逐格对照` / `逐字内联` / `纯拼音` | 结果区排版方式，见 3.4 |
| **字号** | `小 14` / `中 16`（默认）/ `大 20` / `特大 26` | 只改**汉字**字号（CSS 变量 `--fs`）；拼音行固定 11px（`--rt`），不随字号放大 |
| **词组优先** | 开（默认） | 关闭后逐字独立取第一读音，`银行行长` 会全读成 `yín háng háng cháng` |
| **保留标点** | 开（默认） | 关闭后输出剔除标点与符号（`\p{P}` 与 `\p{S}`），汉字、英文、数字、空白保留 |
| **大写** | 关（默认） | 把拼音字母转大写，作用于**无声调 / 数字调 / 首字母**三种样式；**带音调**样式不受影响 |
| **↑多音 / ↓多音** | 无多音字时禁用 | 在结果区循环跳转并高亮下一处多音字 |
| **重置改读** | 无手工改读时禁用 | 清空全部手工改读记录 |
| **朗读** | —— | 用系统语音朗读**纯汉字部分**（跳过标点、英文、数字），按钮变「停止」 |
| **复制** | —— | 复制当前视图的纯文本结果，见 6.3 |
| **复制 Ruby** | —— | 复制 `<ruby>…<rt>…</rt></ruby>` HTML 片段 |
| **下载** | —— | 下载 `拼音_YYYYMMDD-HHmmss.txt`，UTF-8 带 BOM |
| **示例 / 清空 / 帮助** | —— | 填入内置样例 / 清空输入 / 弹出说明面板 |

### 3.3 左侧「原文」

普通多行文本域，支持直接粘贴、键盘输入，也支持**把 `.txt` 文件拖到页面上**载入（单文件，上限 4 MB，含 `\u0000` 的二进制会被拒绝）。右上角实时显示字符数。

### 3.4 右侧「注音结果」

四种视图的实际差别：

| 视图 | 形态 | 复制出的是什么 |
| ---- | ---- | ---- |
| **注音排版** | `<ruby>` 上下对照，拼音在上、汉字在下 | 退化为**拼音行**（等同「纯拼音」） |
| **逐格对照** | 每字一格，上拼音下汉字，可自由换行 | `字 拼音` 两列，字间两个空格 |
| **逐字内联** | `银(yín)行(háng)` | 同屏文本 |
| **纯拼音** | 只有拼音与保留下来的原字符 | 同屏文本 |

状态标记：

- **黄色虚线下划线** = 该字有多个读音，可点击切换
- **红色拼音 `?`** = 该汉字未收录进词典
- **灰色字符** = 非汉字、原样透传的标点 / 英文 / 数字

### 3.5 状态栏

`汉字 81 · 词组命中 8 字 · 可改读多音字 36 处 · 未收录 1 ｜ 手工改读 1 字 ｜ 25.9 ms`

- **汉字**：判定为汉字的字符数（覆盖 CJK 基本区 U+4E00–9FFF、扩展 A U+3400–4DBF、兼容表意文字 U+F900–FAFF、扩展 B–F U+20000–2FA1F，以及数字零 U+3007）
- **词组命中**：被词组表吃掉并采用词表读音的字数
- **可改读多音字**：出现次数（不是字数）
- **耗时**：不足 1 ms 时留空

## 4. 功能操作详解

### 4.1 给一段文字注音并导出

1. 粘贴文本到左侧（或拖入 `.txt`）。
2. 「注音」选 `带音调`，「视图」选 `注音排版`。
3. 需要图片就整屏截图；需要文本就点**「复制」**——注意此时复制的是拼音行，不是带 `<ruby>` 的代码。
4. 要嵌进网页，点**「复制 Ruby」**，得到：
   ```html
   <ruby>银<rt>yín</rt></ruby><ruby>行<rt>háng</rt></ruby>…<br>
   ```
5. 要落地文件，点**「下载」**。

### 4.2 修正一个多音字

1. 在结果里找到带黄色虚线的字（或按 `Alt`+`↓` 逐个跳过去看）。
2. 点击该字 → 读音切到词典里的下一个读音，提示条显示如 `「行」→ háng（仅单字生效，词组读音仍按词表）`。
3. 再点继续轮换下一个读音，循环回到第一个。
4. 改读按**字**记录，全文所有「以单字身份出现」的该字一起变；已经被词组表命中的字**不受影响**（词表更权威）。
5. 改读会存进 `localStorage`，下次打开仍生效。要撤销，点**「重置改读」**。

### 4.3 生成 URL slug / 文件名

1. 「注音」选 `无声调`，打开**「大写」**（如需 `YINHANG`）。
2. 关闭**「保留标点」**，去掉中英文标点。
3. 「视图」选 `纯拼音`，复制。
4. 需要极短缩写就换 `首字母`，得到 `yhxcs：cqddthxy` 这类连写串（关掉「保留标点」则连标点也去掉）。

### 4.4 朗读

点**「朗读」**，系统按 `zh-CN` 读**纯汉字序列**（标点不读，故长句无停顿）。再点一次或读完自动恢复。依赖操作系统已装的中文语音包，没有语音包时读不出声音。

### 4.5 处理超大文本

粘贴超过 8000 字符时，结果区顶部出现提示：

> 文本较大，预览只显示前 8,000 个字符，复制与下载仍是全文结果。

此时**「↑多音 / ↓多音」跳到预览范围外会提示**「该处超出预览范围」。超过 200,000 字符则直接截断并提示。

全部由 `document` 上的 `keydown` 处理（源码 `:843`），在输入框内同样生效。

| 快捷键 | 作用 | 生效条件 |

## 6. 支持的输入 / 输出格式

### 6.1 输入

| 来源 | 支持情况 |
| ---- | ---- |
| 直接粘贴 / 键入文本 | 支持，含中英数混排 |
| 拖入文件 | 支持，按 UTF-8 读取，单文件上限 **4 MB**；含 NUL 字节的文件被判定为非文本并拒绝 |
| 字符上限 | **200,000** 字符，超出截断并提示 |
| 预览上限 | **8,000** 字符，超出只渲染前段 |

### 6.2 词典覆盖范围

| 项 | 数量 / 范围 |
| ---- | ---- |
| 单字条目 | 20,903 |
| 其中多音字 | 3,050 |
| 多音词组 | 853（有效条目，词典原始 855，2 条脏数据被丢弃） |
| 最长词组 | 4 字 |
| 码位覆盖 | U+3007 与 U+3400–40869 区间内的汉字 |

未收录的字（如扩展区生僻字 `𠮷`）在结果里显示为红色 `?`，并计入状态栏「未收录」。

### 6.3 四种注音样式的输出对照

同一句 `银行行长说：重庆的冬天还下雨`：

| 样式 | 输出 |
| ---- | ---- |
| 带音调 | `yínháng xíng cháng shuō： chóngqìng de dōng tiān hái xià yǔ` |
| 数字调 | `yin2hang2 xing2 chang2 shuo1： chong2qing4 de5 dong1 tian1 hai2 xia4 yu3` |
| 无声调 | `yinhang xing chang shuo： chongqing de dong tian hai xia yu` |
| 首字母 | `yhxcs：cqddthxy`（关闭「保留标点」后为 `yhxcscqddthxy`） |

**分词连写规则**（带音调 / 数字调 / 无声调）：同一词组内音节**连写**（`yínháng`、`chóngqìng`），词组之间**空一格**，与《汉语拼音正词法基本规则》一致。**首字母**样式整体连写不空格。

**轻声**在数字调下记作 `5`（如 `de5`、`yu5`、`li5`），遵循常见数字调标注习惯。

**`ü` 的写法**：统一用 `v`（`绿 → lv4`、`略 → lve4`、`女 → nv3`、`人 → ren2`），不用 `ü` 也不写 `u:`，方便直接用作文件名和 URL。

### 6.4 输出

| 出口 | 内容 |
| ---- | ---- |
| 复制 | 当前视图的纯文本；**注音排版视图特殊**：复制的是拼音行（等同纯拼音） |
| 复制 Ruby | 每行 `<ruby>字<rt>拼音</rt></ruby>…`，行间用 `<br>` |
| 下载 | `拼音_时间戳.txt`，UTF-8 **带 BOM**，内容与「复制」一致 |

**明确不支持**：注音符号（ㄓㄨㄥ）、威妥玛拼音、粤拼 / 台罗、繁简转换、自动分词（只有词组表匹配，不是通用分词器）、PDF / DOCX / SRT 等格式导出。

## 7. 数据与隐私

- **零网络请求**。词典随仓库分发在 `汉字转拼音/拼音词典.js`，页面不发任何 `fetch` / `XHR`，不引用 CDN、不加载外部字体。
- **文本不出浏览器**。没有上传、没有日志、没有埋点。
- **唯一的本地存储**：`localStorage` 键 `hzzp.prefs.v1`，内容是
  ```json
  {"tone":"tone","view":"ruby","size":"16","word":true,"punct":true,"upper":false,"over":{"行":1}}
  ```
  `over` 就是手工改读表（字 → 读音下标）。**你改读过哪些字会长期留在浏览器里**，如果不想让别人看到你调整过的默认读音，点「重置改读」即可清空。
- 清除方式：点工具栏**「重置改读」**（只清改读），或在浏览器开发者工具 Application → Local Storage 删除该键（清全部偏好）。
- `file://` 下 `localStorage` 与剪贴板 API 均可用（已实测），无需起本地 HTTP 服务。
- 词典数据许可：`pinyin-data@1.0.0`，ISC License。

## 8. 常见问题（FAQ）

**Q：页面显示「词典缺失，无法转换」？**
`拼音词典.js` 必须和 `汉字转拼音.html` 在**同一个文件夹**。你只拷了 HTML 就会这样。整个 `汉字转拼音/` 目录一起拷走。

**Q：明明是多音字，为什么点了没反应 / 提示「只有单一读音」？**
该字的读音是**词组表**给的，不是单字表给的。词组表优先级更高且不可点击覆盖——比如「重庆」的「重」不该被单独改成 `zhòng`。要改，关掉**「词组优先」**按钮，让它退回单字模式。

**Q：改了「行」的读音，为什么「银行」里的「行」没变？**
同上，「银行」是词组命中。手工改读**只作用于以单字身份出现的字**，这是有意设计。

**Q：「很」之前输出 `hen5`（轻声）而不是 `hen3`？**
这是本会话修掉的一个真实缺陷：第三声的 NFD 组合符是 U+030C，最初代码里写成了 U+02C7（独立的ˇ符号），导致所有第三声都掉进默认轻声分支。**当前版本已修复**，如再遇到请检查 `TONE_MARK`（`:352`）是否被改回。

**Q：`绿` 输出成了 `lu4` 而不是 `lv4`？**
同类缺陷，也已修复。NFD 分解会把 `ü` 拆成 `u` + U+0308，代码需要把 U+0308 还原成 `v`（`:369`）。

**Q：相邻两个词组粘在一起了，比如「银行行长」成一串？**
早期版本按「前后都是词组字」判断连写，会把两个不同词组误连。现在给每个词组分配了编号 `gid`，只有**同一个词组内部**才连写（`:567`）。

**Q：复制出来的为什么不是我在屏幕上看到的注音排版？**
注音排版依赖 `<ruby>` 渲染，纯文本无法表达。所以「复制」和「下载」在注音排版视图下退化为拼音行。要 HTML 请用**「复制 Ruby」**；要 `字(pīn)` 这种形式请切到**「逐字内联」**视图再复制。

**Q：朗读没有声音？**
检查系统是否装了中文语音包（Windows：设置 → 时间和语言 → 语音）。本工具只调 `speechSynthesis`，不带音频文件。

**Q：结果区跳不到某处多音字？**
该处超出 8000 字预览范围。缩短文本，或关闭「保留标点」减少占用。

## 9. 技术实现要点（开发者）

### 9.1 文件构成

```
汉字转拼音/
├── 汉字转拼音.html   889 行，界面 + 全部逻辑
└── 拼音词典.js      305.6 KB，window.PINYIN_DB = Object.freeze({ char, word })
```

`拼音词典.js` 由脚本从 npm 包 `pinyin-data@1.0.0` 自动生成，**不要手工编辑**。HTML 用 `<script src="拼音词典.js">` 同步加载，词典未加载成功时 `loadDict()` 返回 `false` 并在页面给出错误提示，不会抛异常。

### 9.2 关键常量（`:318`–`:320`）

```js
var RENDER_LIMIT = 8000;   // 注音节点数上限，超出只渲染前段，复制/导出仍用全文
var INPUT_LIMIT  = 200000; // 输入字符上限
var PREF_KEY     = 'hzzp.prefs.v1';
```

另外拖入文件大小上限 `4 * 1024 * 1024` 写在 `readFiles()` 内（`:854`）。

### 9.3 数据流

```
输入文本
  → annotate(text)              :433   切 token + 定音
      ├─ 词组优先：从当前位置取 min(MAXW, 剩余) 长的片段，
      │  在 WORD 里做「最长匹配优先」，命中则整词采用词表读音并分配 gid
      ├─ 未命中 → CHAR[ch].split(',')，按 prefs.over[ch] 选下标，
      │  alt.length > 1 即标记 poly
      └─ 词典没有 → miss = true
  → compute()                   :608   统计 + 渲染 + 状态栏
      ├─ 视图分派 render*()     :511 / :526 / :542 / :558
      └─ polyIdx[] 记录多音字下标，供 Alt+↑↓ 跳转
  → plainText() :578 / rubyHtml() :594   复制与导出走纯文本路径，不受预览上限影响
```

### 9.4 声调解析（最容易出错的地方）

```js
var TONE_MARK = {};
TONE_MARK['\u0301'] = 2;
TONE_MARK['\u0300'] = 4;
TONE_MARK['\u030C'] = 3;   // 必须是组合符 U+030C，不是 U+02C7
TONE_MARK['\u0304'] = 1;

function deTone(syl) {      // :369
  var decom = syl.normalize('NFD');
  // 遍历：命中 TONE_MARK 记声调；命中 U+0308（分音符）且前一个是 u → 还原成 v
  // 其余字符查 BASE 表归一化（āáǎà→a、ǖǘǚǜ→v、ńň→n、ḿ→m）
  // 未命中任何声调符 → tone = 5（轻声）
}
```

`fmt(syl, mode)`（`:385`）按 `tone` / `num` / `plain` / `first` 四种模式格式化。

### 9.5 汉字判定

`isHanCp(cp)`（`:396`）用码位区间判定，覆盖基本区、扩展 A、兼容表意区、扩展 B–F 及 U+3007。**不用** `/[\u4e00-\u9fa5]/` 这种只覆盖基本区的写法，否则扩展 A 的字会被当标点吞掉。

`RE_PUNCT`（`:403`）优先用 `new RegExp('[\\p{P}\\p{S}]','u')`，不支持 Unicode 属性转义的旧内核退回一个手写字面字符集。

### 9.6 渲染与跳转的定位方式

每个可交互节点带 `data-i`（token 在 `tokens` 数组中的下标）和 `data-ch`（字符）。

- 点击改读用 `data-ch` 查词典
- `jumpPoly()`（`:738`）用 `out.querySelector('[data-i="…"]')` 定位

**必须用 `data-i` 而不是节点序号**：关闭「保留标点」后，被过滤的标点不产生节点，节点序号与 token 下标会错位。

### 9.7 复制的兼容处理

`copyText()`（`:687`）优先 `navigator.clipboard.writeText`，失败或非安全上下文时退回 `fallbackCopy()`（`:693`）——临时 textarea + `document.execCommand('copy')`。两条路径都有成功/失败提示。

### 9.8 性能

实测 45,000 汉字（3,000 行 × 15 字）的 `annotate` 耗时 **25.9 ms**，瓶颈在渲染而非算法；渲染上限 8000 字符时节点数约 5,800，交互仍然流畅。输入防抖 220 ms。

## 10. 二次修改指引（开发者）

### 10.1 换 / 扩充词典

词典结构极简，两个平铺字典：

```js
window.PINYIN_DB = Object.freeze({
  char: { "长": "cháng,zhǎng", "中": "zhōng,zhòng", … },        // 汉字 → 逗号分隔带调拼音
  word: { "重庆": "chóng,qìng", "银行": "yín,háng", … }          // 词 → 逐字逗号分隔拼音
});
```

**加一个词组**：直接往 `word` 里加一行 `"六安": "lù,ān"`。要求**音节数必须等于字数**，否则 `loadDict()` 会静默丢弃它（页面无报错，但胶囊里的词组数不增加——这是排查入口）。

**加一个字的读音**：在 `char` 对应值末尾追加 `,"lù"`，注意第一个读音是默认读音，顺序有意义。

**整体换数据源**：重新生成 `拼音词典.js` 即可，HTML 侧只要保持 `char` / `word` 两个键名不变。生成时**沿用原始 JSON 文本**、不要重新 `JSON.stringify`，否则中文被转成 `\uXXXX`，文件体积会翻倍以上。

### 10.2 新增一种注音样式

在 `fmt()`（`:385`）加分支，例如威妥玛或「ü 写成 ü」：

```js
if (mode === 'umlaut') return d.plain.replace(/v/g, 'ü');
```

再在 `<select id="toneSel">` 加 `<option value="umlaut">`。`prefs.tone` 会自动持久化，无需改存储逻辑。注意 `renderPy()`（`:558`）里对 `first` 模式有特殊连写处理，新样式若也要连写需一并判断。

### 10.3 调整词组优先策略

`annotate()`（`:433`）里的匹配循环是**最长匹配优先**：

```js
for (var L = Math.min(MAXW, n - i); L >= 2; L--) {
  var w = arr.slice(i, i + L).join('');
  if (WORD[w]) { hit = WORD[w]; hitLen = L; break; }
}
```

想改成「最短匹配优先」把循环反向即可。**`L >= 2` 的下界不要改成 1**，否则单字也会走词组分支，`gid` 语义会乱，连写规则随之失效。

### 10.4 让手工改读也覆盖词组

当前点击改读只写 `prefs.over[ch]`，而词组命中的 token 根本不查 `prefs.over`。若要覆盖，在词组分支取 `hit[j]` 后插一层判断：

```js
var ov = prefs.over[arr[i + j]];
res.push({ ch: arr[i + j], syl: ov !== undefined && altFor(arr[i+j]) ? … : hit[j], … });
```

**代价**：会破坏「重庆」这类正确词组读音的可预测性，不建议默认开启。若要加，建议做成第三个开关按钮而不是改掉现有行为。

### 10.5 常见改造点位速查

| 想改什么 | 改哪里 |
| ---- | ---- |
| 预览 / 输入上限 | `:318` `RENDER_LIMIT`、`:319` `INPUT_LIMIT` |
| 拖入文件大小 | `readFiles()` `:854` 内的 `4 * 1024 * 1024` |
| 输入防抖时长 | `bindUI()` 内 `setTimeout(compute, 220)` |
| 内置示例文本 | `SAMPLE` 变量 |
| 下载文件名前缀 | `download()` `:705` 的 `'拼音_' + stamp()` |
| 是否带 BOM | 同函数内 `new Blob(['\uFEFF' + txt], …)`，去掉 `\uFEFF` 则无 BOM |
| 朗读语言 / 语速 | `speak()` `:748` 内 `u.lang = 'zh-CN'`，可自行加 `u.rate` |
| 存储键名 | `PREF_KEY`（改名会让老用户偏好失效） |
| 配色 | `:root` 里的 CSS 变量，`--poly` 是多音字标记色，`--miss` 是未收录色 |

### 10.6 两个坑

1. **CSS 变量 `--fs` 挂在 `document.documentElement` 上**，字号下拉通过 `setProperty('--fs', …)` 改它。若把字号改成只作用于 `#out`，`renderPair` 的格子宽度会失配。
2. **`keep()`（`:494`）判定顺序不可调换**：先放行汉字，再放行空白与英文数字，最后才用 `RE_PUNCT` 判标点。若把 `RE_PUNCT` 提到最前，某些 Unicode 属性把部分汉字归入 `\p{P}` 边界情况时会误删汉字。
