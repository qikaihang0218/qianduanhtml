编码转换台 · 使用说明

四类模式

  • 编码：Base64、Base64URL、URL 百分号、Hex、\uXXXX、HTML 实体，以及「字节解码」——把一份 Hex/Base64 字节同时用 UTF-8 / GBK / GB18030 / Big5 / Shift_JIS / EUC-KR / UTF-16 / windows-1252 解出来对比，专治乱码。
  • 摘要：MD5（页面内置实现）与 SHA-1 / SHA-256 / SHA-384 / SHA-512（Web Crypto），另有 HMAC 带密钥摘要。
  • JWT：拆 header 与 payload、人性化 exp / iat / nbf，并用 HMAC 密钥本地验签。
  • 随机：crypto.getRandomValues 生成密码 / Token（无偏取值）与 UUID v4。

快捷键

  • 空格 切换编码 / 解码方向（输入框内无效）
  • Alt+1…4 切换四类模式
  • Ctrl+Enter 立即重算
  • Ctrl+Shift+C 复制结果
  • Ctrl+S 下载结果
  • Ctrl+K 聚焦输入框
  • Esc 关闭弹层

能力边界（不做的事）

  • GBK 只能解码不能编码：浏览器 TextEncoder 只有 UTF-8，所以「文本 → GBK 字节」做不了，反向可以。
  • 非对称 JWT 无法验签：RS / ES / PS 需要导入公钥，本工具只解析内容并明确标注未验签。
  • 命名实体只内置 56 个：未收录的 &xxx; 原样保留，不猜。
  • MD5 / SHA-1 已不安全：仅在对接旧系统时使用，不要用于新设计的完整性校验。
  • 输入上限 20 万字符；字节类输入解码后上限 4 MB；结果超过 30 万字符时只截断显示，复制与下载仍是完整内容。

隐私

零网络请求。所有内容只在浏览器内存中处理；模式、选项、密钥与不超过 5 万字符的输入会写入本机 localStorage 的 codeclab.prefs.v1，清除浏览器站点数据即可抹掉。密钥会以明文留在本机 localStorage，公共电脑上请清空或使用后即删。
